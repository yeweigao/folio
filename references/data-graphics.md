# 图表纪律 —— SlideDSL 环境下的编辑级数据图形

**唯一规则：图表是论点，不是容器。** 只画读者看清结论所需的标记与标注；每个面板、边框、图例、网格线都要挣得自己的位置。

## 1. 两条实现路线（按图表类型选）

### 路线 A：原生 Chart 组件（柱 / 折线 / 面积）

- `background` 设为页面底色（如纸面 `#F7F5F0` 或 navy `#071C2C`），图表不放进任何卡片/圆角容器——白底绘图板即违规。
- `showLegend={false}`（≤3 系列）：系列名与终值用独立 Text 在折线末端/柱端直标，16–18px Bold；`showDataLabels` 或独立 Text 标数值。
- `axisColor` / `dataLabelColor` 用墨色或墨的不透明度（不用独立灰值），文本颜色只用纯色。
- 网格只留横向、≤6 条；组件不可控的细节改走路线 B。
- 饼/圆环不用：占比问题用条形直接比较回答。

### 路线 B：SVG 形状骨架 + 可编辑文字层（瀑布 / 气泡 / 点图 / 哑铃 / 记分账本 / 结构图）

- 形状（柱、连线、圆点、坐标轴）用 SVG；**所有文字（节点名、数值、轴名、标签）是独立 Text 元素**，与内置"文图分离"一致，禁整块含字 SVG。
- 坐标轴 1px 发丝线（`#D5DCE1` 或 40–60% 墨色），无外框。
- 点、气泡、哑铃逐个直标 16–18px Bold，不靠尺寸图例。

## 2. 按信息关系选语法

| 关系 | 语法 | 关键约束 |
|---|---|---|
| 变化（有序维度） | 折线 | 2–4px 线宽，末端标系列名+终值；无图例时 ≤2–3 系列 |
| 桥接两个总量 | 瀑布 | 仅当"桥"本身是论点；首末实心柱，中间浮空 |
| 量级对比 | 柱/条 | 同一基线、同一柱宽，端部直标 |
| 位置/范围/前后 | 点图、哑铃 | 比柱更省墨，逐个标值 |
| 三维组合 | 气泡 | 面积=第三量，每个气泡标注，留足间距 |
| 记分/复盘 | 排版账本 | 数字+基线+进度刻度+目标+负责人+发丝线，**不是六块 KPI 卡** |

## 3. 语义色与数字纪律

- 语义色固定（boardroom：navy=基准/决策，cyan=推荐/进度，red=风险/负向，steel=次级证据）；一个展品一个强调色；cyan 不标负向，red 不标推荐。
- 颜色不作唯一编码：配合直标、位置或线型。
- 单位、期间、基线、来源贴近展品标题写一次；同系列精度一致；直标已表达的值，轴不必重复。
- 演示数据标 `illustrative`；不把假设装扮成测量，不为凑结论编数字。

## 4. 表格也是数据图形

开放横线、无竖线、无外框；数字右对齐，单位写表头；推荐列浅底是唯一允许的填充，且必须来自真实选择任务。

## 5. 交付前复核

重开成品确认：绘图区没有回潮出白底/边框/图例；直标仍落在标记上；字体替换没有撞歪对齐。图表不得由生成图片冒充——图片提供情境，不提供数据。
