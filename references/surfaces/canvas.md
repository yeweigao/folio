# 表面：canvas（无限画布 / 设计板）

> 节奏单位是**帧（frame）**，不是页。一帧 = 一个主意；一板 = 一组帧的空间关系。
> 画布不是"把页面撒在无限大平面上"，它是**用位置表达关系**的介质。位置本身就是信息。

## 1. 画布与空间网格

- 空间网格 **8pt**（位置、间距、帧尺寸取 8 的倍数）；缩放只改变观看，不改变坐标。
- 帧内可用 **12 列 × 20 槽**（模块网格）；板面边距 **50**；帧与帧之间按 §1 的 80/160/240 规则。
- 主阅读轴默认**从左到右**，纵向分组向下；同一板只用一个主导方向。
- 帧间距 **≥80pt**；同组 ≤160pt；跨组 ≥240pt。**间距差就是分组**，不靠彩色分组框。
- 帧与帧之间**至少共享一条对齐线**（顶边、左边或中心线）。自由散布是失控，不是自由。
- 板面留白 ≥ 画布内容包围盒的 20%，否则缩到总览时没有呼吸。

## 2. 标准帧（一板最多三种）

| 用途 | 尺寸 | 说明 |
|---|---|---|
| Web 桌面 | 1440×900 | 首屏与关键屏；断点版另起小帧 390×844 |
| Deck | 1280×720 / 1920×1080 | 一帧一页，按 `deck.md` 执行 |
| A4 文档 | 1240×1754 | 150dpi 预览；印刷另按 `handbook.md` 的 mm 值 |
| 社交方图 | 1080×1080 | 单主张；不塞论证 |
| 总览帧 | 2560×1440 | 只放标题、编号、缩略关系，不放大段正文 |

**帧不是容器，是构图。** 建帧前先回答：这一帧的读者、距离、一个主意是什么。空白帧加一句 TODO 不算设计。

## 3. 缩放与字号

字号在**帧坐标系里声明**，以 100% 缩放为准；缩放不改变排版。

| 缩放 | 看到什么 | 必须可读 |
|---|---|---|
| 25%（总览） | 分组、密度、节奏 | 帧标题（≥32pt） |
| 50%（导航） | 区块结构 | 帧标题 + 模块标题（≥20pt） |
| 100%（阅读） | 全部细节 | 正文（14–16pt） |
| 200%（校对） | 字距、标点、对齐 | 全部 |

帧内阶梯：帧标题 **32–64** / 模块标题 **20–24** / 正文 **14–16** / 标签与注释 **12–14**。总览帧用 28–40 的编号与标题，不写正文。
若一张板在 25% 缩放下只剩灰糊，说明帧标题太小或帧数过多——先删帧，不缩字。

## 4. 板面结构（三种合法骨架）

1. **线性**：一列或一行帧，阅读顺序唯一。适合流程、故事板、版本对比。
2. **分区**：2–4 个横向泳道，每条泳道一个主题，帧在泳道内推进。适合多角色 / 多场景。
3. **地图**：中心一个总览帧，四周放射 3–6 个详情节。适合系统总览与产品架构。

一板只用一种。混合骨架 = 读者不知道从哪看起。

**标题区**：板面左上角一个板标题（40–64）+ 一行说明（16–18）+ 版本日期（12–14）。不居中、不加底框。

## 5. 帧内构图

- 每帧一个主张：一句标题 + 一个证据（图 / 数 / 表 / 界面）+ 至多三条注。
- 帧内边距 **48–64**；内容不得贴边；帧底色默认纸色，不逐帧换底色。
- 一板一个信号色。状态色只在**图例存在**时使用，且 ≤3 种，写进板标题区。
- 图像按列宽裁切；同一板统一比例与色温；截图必须真实，不用假 UI 充数。
- 帧编号放左上或右上，同板同侧；编号是导航，不是装饰。

## 6. 连接件纪律

- 只用**正交折线**（横—竖—横），圆角 ≤4；斜线仅用于非流程的"影响/关联"，且全板 ≤2 条。
- 线宽两档：**1pt** 关系线 / **2pt** 主流程；箭头 8pt，同板同款。
- 线从帧边缘中点出，不从文字上穿过；跨帧线不得穿过其他帧。
- 同一对帧之间只画一条线；双向关系用无箭头线 + 标签，不画两条。
- 线越少越好：能用对齐与间距表达的关系，不画线。**连接线是最后手段。**

## 7. 层的命名与交付

- 图层命名：`帧号 / 区块 / 元素`（例：`03 / 证据 / 柱图`）。交付前无 `Frame 12`、`Group 8`、`Rectangle`。
- 分组按帧，不按元素类型；一帧一个顶层组。
- 导出：PDF（审阅）· PNG 2x（演示）· SVG（矢量交接）。导出前隐藏草稿层与参考线。
- 交付说明写：帧数、阅读顺序、缩放基准、信号色与状态色语义、字体是否嵌入。

## 8. 反模式（本表面增补）

- 便利贴墙：彩色方块 + 手写体冒充"工作坊"。
- 无限画布当仓库：几十个未命名帧、无阅读顺序、无对齐。
- 每帧一个底色 / 每帧一个强调色 → 板面变成糖果盘。
- 用缩放掩盖密度：100% 能读，25% 全糊。
- 连接线蜘蛛网：所有东西连所有东西，等于什么都没说。
- 假设备框：用灰色圆角矩形 + "Mobile" 字样代替真实断点设计。

## 9. 交付前复核

- [ ] 帧数 ≤ 12（超过拆板）；每帧一个主意
- [ ] 8pt 网格对齐；帧间距符合 80/160/240 规则
- [ ] 25% 缩放下帧标题可读；板面有明确入口
- [ ] 一板一个信号色；状态色有图例
- [ ] 连接线正交、两档线宽、无穿越
- [ ] 图层命名可读；导出格式与缩放已核对
