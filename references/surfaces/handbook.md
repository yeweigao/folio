# 表面：handbook（手册 / 画册 / 印刷品）

> 节奏单位是**跨页（spread）**与**页（page）**。印刷品的读者会停留，密度可以高，但**每一页都要有入口**。
> 本文件用 mm / pt；像素只用于屏幕预览。印刷件以打样为准，不以屏幕为准。

## 1. 开本与网格

**A4（210×297mm）· 默认**

- 页边距：上 **18** / 下 **21** / 内 **21** / 外 **15** mm（装订侧加大）。
- 版心：**174 × 258mm**。12 列 × **9mm** + 11 槽 × **6mm** = 174mm。
- 基线：**21pt**（≈7.41mm，每页约 34 行）；正文 10.5pt / 18.4pt 行距，落在基线上。
- 跨页视为一个 348mm 宽的画布；跨页图必须跨过订口，且主体避开内侧 5mm。

**A5（148×210mm）· 轻量版**

- 页边距：上 **15** / 下 **18** / 内 **18** / 外 **13** mm；版心 **117 × 177mm**。
- 6 列 × **14.5mm** + 5 槽 × **6mm** = 117mm；基线 **18pt**；正文 9.5pt / 15.2pt。
- 图注、脚注不小于 **8pt**；A5 不放三栏。

**其他开本**：先算版心（成品宽 − 内 − 外），再定列数；列宽不得小于 8mm，槽宽为列宽的 55–70%。

## 2. 排印阶梯（A4）

| 角色 | pt | 行距 | 用途 |
|---|---|---|---|
| D · 展示 | 48–84 | 0.98–1.08 | 章扉、跨页金句 |
| H1 · 章标题 | 24–32 | 1.15 | 每章首页 |
| H2 · 节标题 | 15–18 | 1.3 | 节内分断 |
| H3 · 小标题 | 11.5–13 | 1.35 | 段前小标 |
| B · 正文 | **10.5** | **18.4pt** | 默认正文 |
| Bs · 紧凑正文 | 9.5–10 | 15–16pt | 表注、侧栏、图注块 |
| C · 图注 | 8.5–9 | 12–13pt | 图 / 表下方 |
| A · 脚注 / 页脚 | **8–8.5** | 11–12pt | 脚注、页码、来源（下限 8pt） |

- 一本册子最多 **4 级标题 + 正文 + 图注**；超过说明结构没想清。
- 正文衬线或无衬线均可，但**正文与标题必须同一系统**（见方言文件）；中文正文用 `Hiragino Sans GB` / `Source Han Serif SC` 一类有真实字重的字族。
- 行宽：中文 **28–40 字**；西文 **60–75 字符**。A4 单栏正文建议 10.5pt 时 26–32 字，双栏时每栏 18–22 字。
- 左齐右不齐；**禁止两端对齐**（中文会产生字距裂缝）。段落间距与首行缩进**二选一**：缩进 1em 或段距 6pt。

## 3. 页面的四种基本型

1. **章扉**：大号章号 + 章名 + 一句导语；留白 ≥60%；可满版信号色。
2. **正文页**：单栏或双栏；页眉 / 页脚；图注随图。
3. **图版页**：图占 ≥70%，文字只留标题、图注、来源；图不进栏，按版心裁切。
4. **表格 / 数据页**：开放横线，无竖线；表头与单位；数字右对齐；不得跨页断行（必要时整表移到下页）。

**跨页**：左页收、右页放；大图与章扉优先放右页（翻页后第一眼）；避免文字跨订口。

## 4. 版口与页码

- 页眉：左页放书名 / 章名，右页放章名 / 节名；**不得同时出现三级以上信息**。
- 页码：外下角，距裁切线 ≥10mm；字号 8–9pt；章扉与满版图页可省页码。
- 页眉线：0.5pt，仅在需要分断时使用；不画装饰性双线。
- 脚注：8–8.5pt，上方 30mm 细分隔线（0.5pt），编号与正文一致；一页脚注 ≤ 版心高度的 25%。

## 5. 色彩与印刷

- 纸、墨、一个信号色；中间调由墨的网点 / 透明度派生，不新增灰 hex。
- 四色黑：正文黑用 **K100**；大面积实黑用富黑 **C60 M40 Y40 K100**；总墨量 ≤**300%**。
- 信号色必须给 CMYK 值；屏幕 hex 只作参考。专色仅在品牌规范要求时使用，并注明 Pantone 号。
- 图像：**300dpi**（成品尺寸）、CMYK、嵌入 ICC（FOGRA39 或 GRACoL）；线条图 600–1200dpi 位图或矢量。
- 出血 **3mm**，安全边 **5mm**；跨页图出血按跨页总尺寸算，订口留 5mm 安全。
- 纸：正文 80–120gsm 胶版 / 轻型纸；封面 250–300gsm；同一册只用一个纸白，不混暖白与冷白。

## 6. 装订与拼版

- 胶装 / 锁线胶装：内边距已含装订补偿；页数 ≥64 页时内侧再加 1–2mm。
- 骑马钉：页数必须为 4 的倍数；**爬移（creep）**按纸张厚度补偿，中缝页外移。
- 书脊：页数 ÷ 2 × 纸厚 + 封面厚度；书脊文字仅在 ≥5mm 时使用。
- 印刷前导出 **PDF/X-4**：嵌入字体、保留专色、裁切标记、出血、无 RGB、无透明拼合问题。

## 7. 图像与图表

- 图像是证据或气氛：纪实用真图；无真图用色块 / 几何 / 纯文字，不生成假场景。
- 图注五要素：**谁 / 什么 / 何时 / 何地 / 来源**；至少写清主体、时间、来源。
- 图表用矢量；轴、网格、图例按 `../craft/data.md`；图上文字用真实字体，不烤进位图。
- 表格：8.5–9.5pt；表头信号色仅作块面；行高 ≥1.5 倍字高；跨页表重复表头。

## 8. 反模式（本表面增补）

- 假书感：每页加纸纹、阴影、胶带、手写批注。
- 装饰性大写的章节号占半页，却没有章节内容。
- 每章一个主题色 → 全书失去统一。
- 正文两端对齐 + 字距拉伸；中文出现"孤字成行"。
- 图注缺失来源；跨页图主体被订口吃掉。
- 用 72dpi 网页图印刷；用 RGB 黑当正文黑。
- 为了凑页数加大行距 / 加空白页；为了省页数把正文压到 9pt。
