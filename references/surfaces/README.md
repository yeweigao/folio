# 表面（surfaces）—— 同一套哲学落到不同介质

## 1. 不变量 vs 表面特定

| 全表面共享（不随介质变） | 由各表面文件声明（数字住这里） |
|---|---|
| 七条铁律（`SKILL.md §1`） | 画布单位与网格数学（列数 / 槽宽 / 基线 / 边距） |
| 硬禁令（`SKILL.md §2`） | 排印阶梯与介质最小字号、最小对比度 |
| 八形态路由（`../form-routing.md`） | 动效政策（有 / 无、时长上限、是否尊重 reduced-motion） |
| 风格 DNA 四槽（`../styles/folio.md`） | 输出格式、工程门禁、与生成引擎的边界 |
| 反模式登记册（`../anti-patterns.md`） | 该表面特有的反模式增补 |
| 优先级链、起飞检查 | 该表面的节奏单位（页 / 屏 / 幅 / 视图） |

**铁律约束，表面执行。** 表面文件必须带数字；没有数字的表面文件等于没写。

## 2. 新表面接入十步清单

1. **读者与观看距离** —— 谁看、多远看、看多久（决定最小字号与密度）。
2. **画布单位** —— px / pt / rem / 无限坐标；固定尺寸还是响应式。
3. **网格数学** —— 列数、槽宽、基线单位、外边距，给出可算的公式。
4. **排印阶梯 + 介质最小值** —— 各角色取值，以及**不可谈判的下限**（最小字号、最小对比度）。
5. **节奏单位** —— 页 / 屏 / 幅 / 视图；同一语法连续出现几次要换。
6. **动效政策** —— 允许哪些、时长上限、有没有"必须有职责"的要求、是否支持 reduced-motion。
7. **输出格式与工程门禁** —— 交付什么文件、谁能验证、哪些门禁是硬限制。
8. **反模式增补** —— 该表面特有的 AI 味（写进 `../anti-patterns.md` 并标表面）。
9. **最难的一页做样本** —— 用最难的页面实测，跑不通就改数字，不降标准。
10. **登记** —— 建 `surfaces/<name>.md`，在 `SKILL.md §5` 路由表加一行，在 `../EVOLUTION.md` 记一条。

## 3. 已落地

- **`deck.md`** —— 16:9 幻灯片。1280×720 / 12 列 ×73+24 / 8px 基线；含全部生成引擎事实（唯一收容所）。
