# 表面（surfaces）—— 同一套哲学落到不同介质

## 1. 不变量 vs 表面特定

| 全表面共享（不随介质变） | 由各表面文件声明（数字住这里） |
|---|---|
| 七条铁律（`../../SKILL.md §1`） | 画布尺寸、网格数学、边距与基线 |
| 硬地板（`../../SKILL.md §2`） | 排印阶梯、介质最小字号、最小对比度 |
| 八形态路由（`../form-routing.md`） | 节奏单位（页 / 屏 / 帧 / 跨页 / 幅） |
| 方言 DNA 四槽（`../styles/`） | 动效政策、输出格式、工程门禁 |
| 破格协议（`../variations.md`） | 该表面特有的反模式 |
| 优先级链、完成定义 | 该表面与生成引擎的边界 |

**铁律约束，表面执行。** 表面文件必须带可复算的数字；没有数字的表面文件等于没写。

## 3. 表面之间怎么迁移

同一内容换介质，**不是缩放，是重排**：

1. 保持铁律、形态、方言、三声与母题不变。
2. 重算网格与阶梯（列宽、基线、最小字号）。
3. 重排单位：deck 一页 → web 一屏；handbook 一跨页 → canvas 一组帧。
4. 重选图像裁切与观看距离；同一张图在不同介质上不是同一个构图为。
5. 重新过该表面的交付检查；不能拿 deck 的检查表交网页。该表面的追加验收项见 [`../engines/acceptance.md §8`](../engines/acceptance.md)；12 项共用地板不覆盖键盘、出血、预检、25% 缩览与逐页打开。

完整的五个表面迁移示例（含不变量 / 变量表与失败模式）：[`../examples/grid-lecture.md`](../examples/grid-lecture.md)。它是占位项目，演示判断，不是模板。

## 4. 新表面接入（十步）

1. **读者与观看距离** —— 谁看、多远、看多久；决定最小字号与密度。
2. **画布单位** —— px / pt / mm / rem / 无限坐标；固定还是响应式。
3. **网格数学** —— 列数、槽宽、基线、边距，给出可复算公式与一组示例值。
4. **排印阶梯 + 介质下限** —— 各角色取值；最小字号与对比度不可谈判。
5. **节奏单位** —— 页 / 屏 / 帧 / 跨页 / 幅；同一语法连续几次要换。
6. **动效政策** —— 允许什么、时长上限、是否必须承担职责、是否尊重 reduced-motion。
7. **输出格式与工程门禁** —— 交付什么、谁验证、哪些是硬限制。
8. **反模式增补** —— 该表面特有的 AI 味，写进 `../anti-patterns.md` 并标表面。
9. **用最难的一页实测** —— 跑不通就改数字，不降标准。
10. **登记** —— 建 `surfaces/<name>.md`；在 `../../SKILL.md §7` 加路由；在 `../../EVOLUTION.md` 记一条。

## 5. 待补（未实测前不要照抄）

| 表面 | 节奏单位 | 关键差异 | 待定数字 |
|---|---|---|---|
| **video / motion** | 镜（shot） | 时间轴代替空间轴；字幕安全区；节奏以秒计 | 镜头时长、字幕字号与行宽、安全区、转场上限 |
| **social** | 幅（单张 / 轮播） | 首帧即主张；缩略图可读性 | 1:1 / 4:5 / 9:16 的安全区、最小字号 |
| **email** | 屏（单列） | 600px 窄画布；字体不可控；暗色模式 | 单列宽度、字号、图片替代文本 |

遇到未登记表面：按七铁律 + 最接近的表面类比推导，在 DESIGN.md 记下本次取值；这次记录就是新表面文件的素材。
