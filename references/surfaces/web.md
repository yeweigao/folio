# 表面：web（网页 / 落地页 / 应用界面）

网页不是一张拉长的海报。它要能被读、被点、被键盘操作、被慢网加载。

## 1. 网格

- 内容宽 = `min(1440, 视口宽 − 2 × max(24px, 5vw))`；12 列；槽 **24**；边距 `5vw`（最小 24）。视口宽不含滚动条。
- 1440 视口 → 内容 **1296**、列宽 **86**；≥1600 视口 → 内容封顶 **1440**、列宽 **98**。**1440 是内容上限，不是视口宽。**
- 断点：390 / 768 / 1024 / 1440。
- 列坍缩：12 → 8 → 6 → 4；坍缩后仍有明确列线与槽。
- 图片轨道 `minmax(0, 1fr)`；展示标题 `overflow-wrap: break-word; min-width: 0`。
- `overflow-x: clip` 放在 `html` 与 `body`；不用 `100vw`。

## 2. 排印

- 正文 16–20px；行高 1.5–1.7；行宽 ≤65ch（CJK 25–35 字）。
- 标题用 `clamp()`：H1 `clamp(2.5rem, 6vw, 5rem)`；H2 `clamp(1.75rem, 3vw, 3rem)`；H3 `clamp(1.25rem, 2vw, 1.75rem)`。
- H1 上限 80px；展示数字 / 单词可到 112px（folio 展示档），但必须在 DESIGN.md 声明为展示图形，不与 H1 混用。
- 一个展示族 + 一个正文族 + 一个标签族，最多三个角色。
- 标签：正文族小一档、句首大写或中文正常；不做 10px 全大写宽字距。
- 正文不用纯黑 `#000`；用墨 `#111`；暗色模式反转场，不换信号。

## 3. 首屏

- 1280×800 内可见：标题、一句支撑、一个主动作。不用滚动才看到动作。
- 标题 ≤2 行；一句支撑 ≤12 词 / 30 字；一个主动作，动词开头。
- 首屏放真实产品、真实数字或一个可操作的东西；不放三张同构卡片。
- 不用 eyebrow（小号彩色标签）建立层级；标题自己站得住。
- 首屏文字总量 ≤80 词；多出来的进下一屏。

## 4. 页面结构

- 6–9 个 section（含首屏与页脚）；每个 section 一个主意。
- 每个 section 有明确标题；标题是判断句或明确的对象名，不是"解决方案"。
- 至少两个 section 展示真实材料（产品截图、照片、数据、引文）；没有就减少 section，不填。
- 页脚：来源、许可、联系、隐私；图库图与外部照片必须署名。
- 一个页面只有一个主 CTA；次动作视觉上明显次一级。

## 5. 设计 token

- `--paper` / `--ink` / `--signal` / `--muted` / `--rule` / `--focus`。
- 颜色与字体只在 token 块声明；组件只引用 token。
- 间距用 4 / 8 的倍数：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128。
- 圆角：**0**；不做圆角卡片；头像等必须为圆的元素用正圆。
- 阴影：**无**；层级用 1px 边框、底色或留白，不用投影。

## 6. 可访问性

- 对比：正文 ≥4.5:1；大字 ≥3:1；非文字 ≥3:1。
- 语义 HTML：`header` / `nav` / `main` / `section` / `footer`；标题层级不跳级。
- 每个交互元素有 `:focus-visible`，2px，立即出现，不被 `outline: none` 抹掉。
- 图片有 `alt`；装饰图 `alt=""`；图标按钮有 `aria-label`。
- 表单：`label` 与输入框关联；错误信息与字段关联；不用 placeholder 当标签。
- 键盘可达：tab 顺序符合阅读顺序；模态框有焦点陷阱与 Esc。
- 跳转链接（skip link）；语言 `lang`；减少动态 `prefers-reduced-motion`。

## 7. 动效

- 只解释状态：展开、切换、反馈、连续性。
- 100–300ms；只动 `transform` / `opacity`；不用 `transition: all`；不动宽高与 top/left。
- 内容默认可见；脚本关闭也能读；reveal 最多一次。
- 不做视差、滚动劫持、无限背景动画、逐字飞入。
- `prefers-reduced-motion` 下改为即时或 ≤100ms 淡入。

## 8. 图像与性能

- 真实材料优先；不用 AI 假照片、假产品、假人物。
- `<img>` 写 `width` / `height`；首屏图 `fetchpriority="high"`；其余 `loading="lazy"`。
- AVIF / WebP，JPEG 兜底；2x 图；压缩后回看文字边缘与天空。
- 目标：LCP <2.5s、CLS <0.1、INP <200ms（中端手机，4G）。
- 字体：`font-display: swap`；自托管或明确许可；不加载用不到的字重。
- 第三方脚本：能不加载就不加载；必须加载的延迟到首屏之后。

## 9. 页面 vs 应用界面

- **页面**：读与滚动；首屏有主张；section 有节奏；一个主 CTA。
- **应用界面**：工作；信息密度高；表格、筛选、状态是常态；安静的 1px 边框是合法的；KPI 磁贴与渐变仍然禁止。
- 应用界面先设计空状态、加载态、错误态；不要只设计"数据齐全"的完美屏。
- 应用界面的表格：数字右对齐、单位在表头、行高 ≥40px、hover 与 focus 可辨。

## 10. 测试

- 1440 / 768 / 390 三个宽度实际打开看；不靠"应该没问题"。
- 键盘走一遍：tab、shift+tab、enter、esc、焦点可见。
- 屏幕阅读器抽读：标题层级、表单标签、图片 alt。
- 慢网 / 离线：首屏内容是否仍可读；错误是否有说明。
- Lighthouse / axe：性能、可访问性、最佳实践；不追求满分，追求无阻断问题。
- 浏览器：Safari、Chrome、Firefox 各一次；移动端至少一次真机。

- [ ] 对比、焦点、键盘、alt、表单标签达标
