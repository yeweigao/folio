# 表面：deck（16:9 幻灯片）

> 本文件是**唯一允许出现生成引擎命令与引擎事实的地方**。`SKILL.md` 与 `references/` 其他文件保持引擎无关。
> 换引擎时只改本文件的引擎事实段，哲学层不动。

## 1. 画布与网格数学

- 画布 **1280×720**；外边距 70；内容宽 1140；**12 列** × 73 + 槽 24（12×73 + 11×24 = 1140）。第 n 列起点 = `70 + 97n`。
- 垂直节奏以 **8px** 为基线单位；margin / gap / 行高取 8 的倍数（行高容差 ±2px）。
- 母版四段（可按需调整，但全册一致）：页眉刻度条 y26–32 → kicker y50–70 → 标题 78–141 → 内容 157–653（496 高）→ 页脚 688–708。
- 阅读动线全篇固定：kicker → 标题 → 发丝线 → 导语 → 证据 → 决策带 / 页脚。变的是展品语法，不变的是轴线。

## 2. 排印阶梯（两种观看距离）

**桌面型**（自己看、会后翻阅）：

| 角色 | px | 行高 | 用途 |
|---|---|---|---|
| D · 展示 | 60–140 | 1.0–1.12 | 封面主张、章节巨字、核心大数字 |
| T · 页标题 | 44–60 | 1.12–1.18 | 每页 Action Title |
| L · 导语 | 22–28 | 1.38–1.45 | 导语、提要、pull quote |
| B · 正文 | 18–22 | 1.48–1.55 | 论证正文、表格正文 |
| Bs · 紧凑正文 | 16–18 | 1.42–1.48 | 三栏、侧栏、账本单元格 |
| C · 注释 | 13–16 | 1.35–1.4 | kicker、图表标题、直标 |
| A · 参考 | 12–13 | 1.35 | 轴刻度、来源、页码（**底线 12px**） |

**投影型**（观众 ≥3m，教室 / 会场）整档上调：D 96–160 · T 48–64 · L 32–36 · B 26–32 · Bs 22–26 · C 18–22 · A 16–18。
判据只有一条：**最后一排能不能看清正文**。一册只选一种距离。

**硬线**：导语比正文大 ≥5–6px；正文行宽 45–68 字符、左齐不两端对齐；可读文字 ≥12px（投影 ≥16px）。
**标题不是正文的放大版**：D/T 级比不超过 4×；D ≥96 时 T 必须 ≥56（投影 ≥60）——否则标题会被读成图注。

### 2.1 密度耦合

| 页型 | 正文预算 | 视觉锚点 |
|---|---|---|
| 论证页 | 300–450 字（单栏 30–42 汉字/行） | 1 个大数字或大图 |
| 数据页 | ≤120 字 + 图 | 主图 ≥50% 内容区 |
| 封面 / 收束 | ≤40 字 | 主张本身 |
| 账本 / 表格页 | 每行 ≤14 字 | 数字列 |

字号变大，字数必须跟着减。

## 3. 引擎事实（实测，换引擎须重测）

### 3.1 字重：只认两个值

| 写法 | 实际效果 |
|---|---|
| `fontWeight: 'bold'` | 粗体，约 700 |
| `fontWeight: 'normal'` | 常规 400 |
| `fontWeight: 'thick'` | **反而更细**（退回常规），陷阱值，禁用 |
| `fontWeight: 700/800/900`（数字） | **被静默忽略**，与 bold 等价，拿不到 Black 字面 |

结论：**要"粗壮"只有一个办法——换带 Black/Heavy 字面的字族**，调数字无效。

### 3.2 字族可用性（macOS，slidep → OOXML → LibreOffice 渲染核对）

| 字体 | 调用写法 | 结果 | 用途 |
|---|---|---|---|
| Helvetica Neue | `'Helvetica Neue'` + bold / normal | ✅ 400 / 700 | 正文、标题（瑞士骨架默认） |
| Avenir Next Heavy | `'Avenir Next Heavy'` + `'normal'` | ✅ ~900 | **D 档默认**（巨字、封面、金句） |
| Avenir Next Condensed Heavy | 同上 | ✅ ~900 且窄 | 长标题、窄栏（省 12–15% 宽度） |
| Arial Black | `'Arial Black'` + `'normal'` | ✅ 900，气质偏美式 | 兜底，不首选 |
| Helvetica Neue Condensed Black | 任何写法 | ❌ 静默回退成常规 | 禁用 |
| Futura / DIN Condensed | 任何写法 | ❌ 回退 | 禁用 |

**不用 Arial**：它是 Helvetica 的克隆，笔画与字宽更粗笨，瑞士语境里"像但不正"，只作最后回退。
**不用 Inter**：通用 UI 默认，写出来等于没选过（见 `../anti-patterns.md` AP-018）。
**换字体 = 重排版面**：三者字宽差 10–25%，换行点完全不同，标题换行与卡片高度必须在渲染里核过。

### 3.3 中文字体必须栈首

`"Helvetica, Arial, 'PingFang SC', sans-serif"` → 中文走系统回退，**bold 不生效**（实测渲染成常规）。
`" 'Hiragino Sans GB', 'PingFang SC', sans-serif"` → bold 正常。
规则：**含中文的文本，中文字体放栈首**；中英混排最稳的做法是拆成两个文本元素各控字重。
`Hiragino Sans GB` bold 最壮、汉字方正，**中文标题首选**；`PingFang SC` 字面偏圆。`Heiti SC` 本机常缺失。

### 3.4 容器高度

**按 `fontSize × 1.6` 预留**——引擎的 lineHeight 在包含检测里几乎不生效，按 1.15 算必报 child-containment。

### 3.5 双声部与字体栈

```
证据声部（T / L / B / C / A）：'Helvetica Neue', Helvetica, sans-serif         —— 400 / 700
主张声部（仅 D ≥96）：        'Avenir Next Heavy', 'Avenir Next', sans-serif   —— normal
中文（栈首）：                'Hiragino Sans GB', 'PingFang SC', sans-serif    —— bold / normal
```

主张声部只在 D 档出现，一页最多一处；T 及以下一律回证据声部。

### 3.6 三套 W(S) 预设（一册只能一个）

- **A · 重压型（默认）**：D 900 · T 700/900（同页有巨字上 900）· L 400–500 · B 400 · C 600–700 · A 400–600。适合决策文档；每页超 2 处重压开始喊叫。
- **B · 反压型（画册 / 封面主导）**：D 900（≥76px）· T 400–500 · L/B 400 · C 600–700（唯一加重区）· A 400。硬条件：字距 -0.5%~-2.5%、行距 1.0–1.08、对比 ≥7:1。
- **C · 均质型**：全册 400 或 700，层级只靠字号比 ≥1.6× 与留白；要 900 就全册 900。

## 4. 并列页：模块网格（Bento 的瑞士化）

判据：**内容之间是"并列"还是"推进"？并列才切块。** 一册最多 1–2 次。

- 块面 = 纯色块（信号色满版 / 墨 / 纸），**无圆角、无阴影、无灰底**。
- 跨度取 12 列整数倍（3 / 4 / 6 / 12）；行高 160 或 340；**块间槽 20**（不是 40，大缝隙造卡片感）。
- 层级只有三档：实色块 > 3px 墨线 > 1px 墨线。
- 每块只放三样：kicker（编号 + 名称）、一句标题、可选一个数字或注释。块数 4–7，超过就该拆页。
- 需要第四种层级时改线宽或跨度，**不加色**。

## 5. 图表：两条实现路线

**唯一规则：图表是论点，不是容器。** 每个面板、边框、图例、网格线都要挣得自己的位置。

- **路线 A（原生 Chart，柱 / 折线 / 面积）**：`background` 设为页面底色，不放进卡片或圆角容器；`showLegend=false`（≤3 系列），系列名与终值用独立文本在末端直标 16–18px Bold；网格只留横向 ≤6 条；轴色用墨或墨的不透明度。
- **路线 B（SVG 形状 + 独立文字层，瀑布 / 气泡 / 点图 / 哑铃 / 账本 / 结构图）**：形状用 SVG，**所有文字必须是独立文本元素**，禁整块含字 SVG；坐标轴 1px 发丝线无外框；逐个直标不靠尺寸图例。
- 表格也是数据图形：开放横线、无竖线、无外框；数字右对齐、单位在表头；推荐列浅底是唯一允许的填充。
- 单位 / 期间 / 基线 / 来源贴近展品标题写一次；演示数据标 `illustrative`；图表不得由生成图片冒充。

## 6. 影像：四把锁

顺序不能反：先判页型 → 再判等级 → 最后才碰开关。多数翻车是"先选了生图，再给每页找理由用图"。

| 页型 | 论证角色 | 影像等级 | 怎么办 |
|---|---|---|---|
| 封面 / 章节扉页 | 定调 | L1 | 生图；或满版信号色块 + 反白巨字（二选一，不并用） |
| 论证页（数据 / 比较 / 拆解） | 证据 | L0 | **不放图**。数据本身就是图 |
| 案例 / 场景页 | 情境 | L1 / L2 | 生图 |
| 流程 / 架构 / 时间线 | 结构 | L0 | 用几何组件画，不用图 |
| 团队 / 客户 / 产品实拍 | 真实性 | L2 | 只用真图；没有就砍掉这一栏，**不占位、不生成** |
| 纯文字主张页 | 宣言 | L0 | 巨字 + 留白 |

硬规矩：**一册的 L1 影像 ≤3 页**。超过 3 页说明图片在代替论证，该删的是图片。

1. **媒介锁**：全册一种 —— 高对比黑白摄影 / 单色 duotone（信号色）/ 硬边几何，三选一。
2. **裁切锁**：比例对齐列宽，不写"16:9"这种随手值。4 列 = 364×273、8 列 = 752×423、满版 = 1280×720。**图进列，不是列迁就图。**
3. **构图锁**：主体偏置 ≥1/3 画幅，指定文字安全区在哪一侧（AI 最爱怼正中）。
4. **色温锁**：全册一个色温、一个对比度，写进 prompt 末尾，逐张目视核对。

prompt 固定四段：`[媒介] 高对比黑白摄影，硬光，深阴影，胶片颗粒 / [主体] 主体置于画面右侧 1/3，左侧大面积极简负空间 / [情绪] 克制、纪实、无笑容、非商业图库感 / [技术] 裁切 4:3，no text, no watermark, no border, no logo`。
生成后**逐张目视核对**，不合格宁可换色块占位。

**占位框**（引擎灰底虚线圆角改不了像素）三种合法用法：① 信号色 8–30% 不透明度满格块 + 左上角标 `L1 · 4:3 · 主体偏右`；② 1px 信号色十字 + 四角 L 形测绘角标；③ 直接升级成构图（满版信号色 + 反白巨字）。禁止灰底、虚线、圆角、图标占位符。

## 7. 教学课件叠加层（K12 讲课场景）

选定风格后追加，不换风格，只加教学语法。源自 Grammar Explorer 与 Think 两套教材的架构拆解：**学的是信息架构，不是视觉系统**。

八条改造：
1. **阶段词进 kicker** —— `READ / LOOK / LEARN / PRACTICE / CHECK / WORDS`，每页顶部告诉学生这一页在干什么。
2. **✓/✗ 对照** —— 纪律禁红绿，用浓淡：✓ 墨色实心，✗ 45% 墨。
3. **表头信号色底** —— 表格头块面 + 黑字（信号色仅块面）。
4. **示例题 00** —— 练习从 0 题开始，第 0 题是已完成样例。
5. **SAY IT 固定互动位** —— 内容页右下固定标签 + 一句指令；练习页不放。
6. **斜体焦点词** —— bold 指令 / regular 题干 / italic 焦点词，零色相成本。
7. **候选词容器** —— 墨 5% 淡面底条 + 内嵌标签 + 词 24px。
8. **每页一个信号色锚点（≥1.5%）** —— 防白纸黑字出厂。场反转：纸/墨底 → 信号色标签 + 墨字；信号色满版 → 墨标签 + 信号色字。

页型总纲：READ=推进 · LOOK=展品 · LEARN=对照/并列 · PRACTICE=演练（选项 ≥24px、行高 ≥82px、一页一大题）· CHECK=演练答案（墨满版、独立页）· WORDS=并列词卡 · SAY=宣言。
节奏：章内 `内容 → 内容 → PRACTICE → CHECK` 四页一循环；章扉满版起，答案页墨满版收。

**明确不借鉴**：教材字号（8–10pt 是纸距）、多色区分信息、一课多练、装饰插图、暖白纸面、四格漫画（除非素材真是连续照片）。

## 8. 与生成引擎的共存

**引擎决定"有没有"，本契约决定"要多少、要哪种、要多统一"。**

| 决策 | 归属 |
|---|---|
| 这页放不放图片框、生不生图 | 引擎开关，不推翻，只给判据（§6） |
| 图长什么样、是不是一套 | **本契约全权** |
| 用哪个风格预设 | 引擎入口，不抢目录 |
| 预设里的网格 / 动线 / 排印 / 图表 | **本契约全权** |

不硬刚"命中预设时禁止另生成 DESIGN.md"这类门禁：改落 **`ART-DIRECTOR.md`**（风格增量单），六行——外观取自 / 结构取自 / 网格 / 声部 / 影像 / 禁区。

**工程门禁**（语法、溢出、包含关系、画布、组件能力）无条件服从，那是印刷厂的机器限制。
**审美门禁**（"留白 / 失衡"启发式意见）不是法令，处置协议见 `../review.md`。

## 10. 已知边界

引擎的像素改不了（占位框渲染、组件能力上限），能提升的是**这些开关被使用的判断质量**：少用、用对、用统一。审美提升来自克制与一致，不来自把每个选项都打扮一遍。
