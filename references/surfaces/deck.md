# 表面：deck（16:9 幻灯片）

> 本文件只管设计与工艺；引擎命令与实测事实住 `../engines/`。换引擎时网格、阶梯、判断不动。

## 1. 画布与网格

- 画布 **1280×720**；外边距 70；内容宽 1140；**12 列** × 73 + 槽 24（12×73 + 11×24 = 1140）。第 n 列起点 = `70 + 97n`。
- 垂直基线 **8px**；边距、间距、行高取 8 的倍数（行高容差 ±2px）。
- 母版四段（全册一致）：页眉刻度 26–32 → kicker 50–70 → 标题 78–141 → 内容 157–653（496 高）→ 页脚 688–708。
- 阅读动线固定：kicker → 标题 → 发丝线 → 导语 → 证据 → 决策带 / 页脚。变的是展品语法，不变的是轴线。

## 2. 观看距离与排印

**桌面型**（自己看、会后翻阅）：

| 角色 | px | 行高 | 用途 |
|---|---|---|---|
| D 展示 | 60–140 | 1.0–1.12 | 封面主张、章节巨字、核心数字 |
| T 页标题 | 44–60 | 1.12–1.18 | 每页动作标题 |
| L 导语 | 22–28 | 1.38–1.45 | 导语、提要、引文 |
| B 正文 | 18–22 | 1.48–1.55 | 论证、表格正文 |
| Bs 紧凑正文 | 16–18 | 1.42–1.48 | 三栏、侧栏、账本 |
| C 注释 | 13–16 | 1.35–1.4 | kicker、图表标题、直标 |
| A 参考 | 12–13 | 1.35 | 轴刻度、来源、页码（底线 12） |

**投影型**（观众 ≥3m）：D 96–160 · T 48–64 · L 32–36 · B 26–32 · Bs 22–26 · C 18–22 · A 16–18。
判据只有一条：**最后一排能不能看清正文**。一册只选一种距离。

**硬线**：导语比正文大 ≥5–6px；行宽 45–68 字符（CJK 28–40 字/行）；左齐；可读文字 ≥12px（投影 ≥16px）。
**标题不是正文的放大版**：D/T 级比 ≤4×；D ≥96 时 T 必须 ≥56（投影 ≥60）。

## 3. 密度耦合

| 页型 | 正文预算 | 视觉锚点 |
|---|---|---|
| 论证页 | 300–450 字 | 1 个大数字或大图 |
| 数据页 | ≤120 字 + 图 | 主图 ≥50% 内容区 |
| 封面 / 收束 | ≤40 字 | 主张本身 |
| 账本 / 表格 | 每行 ≤14 字 | 数字列 |

字号变大，字数必须跟着减。密度不是信息量，是信息量除以面积。

## 4. 节奏

- 封面（宣言）→ 章节扉页（转场）→ 内容（论证 / 展品 / 对照 / 推进 / 演练）→ 收束（宣言终局）。
- 同一语法连续不超过两页；每 5–7 页有一次场反转（纸 ↔ 墨 ↔ 信号）。
- 一个 deck 只有一个第一主张；每章只回答一个子问题。
- 收束只回收、不新增。

## 5. 并列页：模块网格

判据：**内容是"并列"还是"推进"？并列才切块。** 一册最多 1–2 次。

- 块面 = 纯色块（信号满版 / 墨 / 纸），无圆角、无阴影、无灰底。
- 跨度取 12 列整数倍（3 / 4 / 6 / 12）；行高 160 或 336（42×8）；**块间槽 24**（不是 40）。
- 层级只有三档：实色块 > 3px 墨线 > 1px 墨线。
- 每块只放三样：编号 + 名称、一句标题、可选一个数字或注释。块数 4–7。
- 需要第四层时改线宽或跨度，不加色。

## 6. 图表

**图表是论点，不是容器。** 每个面板、边框、图例、网格线都要挣得位置。

- **原生图表**（柱 / 折线 / 面积）：背景设为页面底色；不放进卡片；≤3 系列时不出图例，系列名 + 终值末端直标 16–18px Bold；横向网格 ≤6 条；轴色用墨或墨的不透明度。
- **形状 + 独立文字层**（瀑布 / 气泡 / 点图 / 哑铃 / 账本 / 结构图）：形状层只画几何，所有文字独立；坐标轴 1px 发丝线无外框；逐个直标。
- 表格：开放横线、无竖线、无外框；数字右对齐；单位在表头。
- 单位 / 期间 / 基线 / 来源贴近图题写一次；演示数据标 `illustrative`。

## 7. 影像

顺序不能反：先判页型 → 再判职责 → 最后才决定用不用图。

| 页型 | 职责 | 等级 | 怎么办 |
|---|---|---|---|
| 封面 / 章节扉页 | 定调 | L1 | 真实照片 / 满版信号 + 反白巨字 / 代码绘制几何（三选一） |
| 论证页（数据 / 比较 / 拆解） | 证据 | L0 | 不放图；数据本身就是图 |
| 案例 / 场景页 | 情境 | L1 / L2 | 真实照片；没有就改用文字 + 几何 |
| 流程 / 架构 / 时间线 | 结构 | L0 | 几何图形，不用照片 |
| 团队 / 客户 / 产品 | 真实性 | L2 | 只用真图；没有就删这一栏，不生成 |
| 纯文字主张页 | 宣言 | L0 | 巨字 + 留白 |

硬规矩：**一册的 L1 影像 ≤3 页**。超过 3 页，说明图片在代替论证。

1. **媒介锁**：全册一种——高对比黑白 / 单色 duotone / 硬边几何。
2. **裁切锁**：4 列 = 364×273、8 列 = 752×423、满版 = 1280×720。图进列，不是列迁就图。
3. **构图锁**：主体偏置 ≥1/3；指定文字安全区。
4. **来源锁**：图注 + 来源全册统一；没有来源的图不用。

**占位**三种合法用法：① 信号色 8–30% 不透明度满格块 + 左上角标 `L1 · 4:3 · 主体偏右`；② 1px 信号色十字 + 四角 L 形测绘角标；③ 升级成构图（满版信号 + 反白巨字）。禁止灰底、虚线、圆角、图标占位符。

## 8. 教学叠加层（K12）

选定方言后追加，不换方言，只加教学语法。

1. **阶段词进 kicker**：`READ / LOOK / LEARN / PRACTICE / CHECK / WORDS`。
2. **✓/✗ 对照**：不用红绿，用浓淡——✓ 墨色实心，✗ 45% 墨。
3. **表头信号色底**：块面 + 黑字；信号只做块面。
4. **示例题 00**：练习从第 0 题开始，第 0 题是已完成样例。
5. **SAY IT 固定互动位**：内容页右下固定标签 + 一句指令；练习页不放。
6. **焦点词**：bold 指令 / regular 题干 / italic 焦点词，零色相成本。
7. **候选词容器**：墨 5% 淡面底条 + 内嵌标签 + 词 24px。
8. **每页一个信号锚点（≥1.5%）**：纸/墨底 → 信号标签 + 墨字；信号满版 → 墨标签 + 信号字。

页型总纲：READ=推进 · LOOK=展品 · LEARN=对照/并列 · PRACTICE=演练（选项 ≥24px、行高 ≥82px、一页一大题）· CHECK=演练答案（墨满版、独立页）· WORDS=并列词卡 · SAY=宣言。
节奏：章内 `内容 → 内容 → PRACTICE → CHECK` 四页一循环；章扉满版起，答案页墨满版收。

**明确不借鉴**：教材字号（8–10pt 是纸距）、多色区分信息、一课多练、装饰插图、四格漫画（除非素材真是连续照片）。

## 10. 已知边界

引擎的像素改不了（占位框渲染、组件能力上限）。能提升的是**开关被使用的判断质量**：少用、用对、用统一。审美提升来自克制与一致，不来自把每个选项都打扮一遍。引擎事实见 `../engines/`。
