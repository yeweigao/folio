# 设计哲学 —— 一套哲学，多种方言

本文件是 ppt-art-director 的总纲，来源是 ppt-master-themes 的 `framework/PHILOSOPHY.md` 与 `EDITORIAL_RHYTHM.md`。它解释：为什么四套主题看起来不同、却必须是同一套系统；以及这套系统落到内置 PPT 管线（DESIGN.md + SlideDSL）时，哪些东西不能变。

## 1. 四传统合成一句话

**瑞士国际主义的网格秩序 × 先锋编辑叙事 × 有控制的解构切分 × 克制的新粗野结构感。**

- **网格秩序**：数学化的多轨对齐、非对称平衡、极端尺度对比；留白是结构，不是剩余空间。
- **编辑叙事**：每页一个任务；主张 → 证据 → 含义的阅读动线；整本在"静读 / 影像 / 证据 / 深色转折"之间交替。
- **有控制的解构**：只在转折页打破对称——切分、蒙版、错位、裁切；破坏必须可解释，不能成为新的装饰。
- **克制的新粗野**：裸露的发丝线/粗框、零圆角色块、坐标刻度，替代阴影与卡片；结构诚实，不伪造材质。

术语上这是"编辑设计"（editorial design），不是纯瑞士国际主义——纯 Swiss 是无衬线、少层级、公理化网格的另一支。两者共享网格与动线，不共享声部。

**默认与方言**：包级默认底是**白**，黑字，一个按内容选的主题色（红/蓝/黄之一）；主题色满版承担封面与转折页。暖纸、米白、衬线都不是默认，也不再作为方言常量；把某套皮肤反推成全局默认，是这套系统最容易犯的错。

## 2. 三层结构（映射到内置管线）

| 层 | 原仓库 | 内置 PPT 管线里落到哪 |
|---|---|---|
| 包级哲学 | PHILOSOPHY.md | 本文件 + `design-constitution.md`：写进每个项目的 DESIGN.md |
| 结构层 | Layout（六轨网格、33/17 个原型） | 内置组件（Slide/Box/Text/Chart/SVG）+ DESIGN.md 的页面映射表与 12 列网格 |
| 方言层 | Theme（Style spec + Theme DNA） | `references/designs/design-principle.<id>.md` |

**主题不是皮肤，是同一套哲学的不同方言。** 判断一个模块是否合格：遮住颜色和字体，它的网格、动线、标题制度、图表纪律是否仍与其它模块同源。

## 3. Theme DNA：四件事全篇不变

每个方言必须写清四个槽位，各一句话：

1. **底场组**：主阅读纸面色 + 转折深色底场 + 唯一高对比强调色。
2. **双声部**：主张声部（标题、导语、大数字、引语）与证据声部（kicker、刻度、直标、表头、来源）；不混入第三种展示字体。
3. **唯一结构母题**：从题材里只取一种贯穿全篇的微结构动作（刻度标尺、三级叠透、裸露粗框、四角测绘括号、切角等择一）。
4. **节奏**：在哪几种"温度"之间交替（满版影像 / 多栏精读 / 透明证据 / 深色转折）。

**Extension Rule**：没有样本可照的页面，只允许改跨度、尺度、图片状态、密度、底场温度；不得新增字体声部、不得换母题、不得引入新的色彩角色。

## 4. 六个提升杠杆

1. **精确参数**：网格、页边距、字号阶梯、W(S)、对比度阈值——全部落成数字。
2. **结构原型**：内置没有本包的 33/17 个 Layout 原型，用"页面映射表 + 组件能力"重建：每页先定页型与展品语法，再写 DSL。
3. **校准样本**：每个方言至少给一个"好的样子"（示例 SVG / 成品页），学尺度极差、换行节奏、叠透，不抄文案。
4. **整本节奏**：四种温度交替；全册至少 2 次由论证驱动的尺度突变；同构最多连续 3 页。
5. **具名反默认**：白卡片、KPI 瓷砖、图标墙、渐变阴影、米白底、斜体强调词、"01/02/03"编号标签、胶囊按钮——点名禁止，不写"避免 AI 感"。
6. **评审→修正**：四视角提问 + "成因 → 改哪个变量"的对照，而不是打分。

## 5. 两级写法：契约层与判断层

- **契约层**（可物理验证）：路径、溢出、裁切、碰撞、对比度、数字真实、字体回退。精确执行，违反即返工。
- **判断层**（论证、排印、节奏、构图）：给默认值与判据，写成"默认 / 若…则…"。**偏离要计费**：在交付说明里写偏离了什么、为什么、代价是什么。
- 把判断层当法令逐条执行，只会得到合规而平庸的稿子；用品质条目否定一个自己没读懂的系统，同样算失败。

## 6. 不变量与品质分开

**不变量（与风格无关，违反即返工）**：可读（目标介质下读得出、灰度能分级）、无损（零溢出/裁切/遮挡/碰撞）、真实（数字有来源与基线，缺数据标 illustrative）、语义（强调色稳定、对比度 ≥4.5:1）、可编辑（文字是文本、图表是原生对象）、推进（每页有可指认的证据，删了论证会断）。

**品质（按本册声明的设计系统判定）**：一致（像同一本出版物）、标题（制度与页型匹配）、尺度与字重（全册一个 W(S)、一页一个极值轴）、动线（20% 缩略图第一眼落在计划元素上）、节奏（至少 2 次尺度突变、无连续 3 页无升级的同构）。

注意：**"填满画布""四角均衡""留白率"不在不变量里**——它们是启发式偏好，不是设计法则。见 `vlm-review.md`。

## 7. 四视角评审（提问，不是清单）

| 视角 | 提问 | 常见成因 → 改什么 |
|---|---|---|
| 网格与动线（Müller-Brockmann） | 缩到 20%，第一眼落在计划的元素上吗？边缘对得上同一网格吗？ | 落错 → 移动重物或拉大尺度极差；不齐 → 回网格轨道 |
| 排印与微观阅读（Ruder） | 灰度打印还分得出层级吗？导语/正文/注释各守 W(S) 吗？ | 层级糊 → 拉字号比（≥1.6×）而不是加颜色；孤字 → 重断行 |
| 证据与图表（Tufte） | 每个数字有来源与基线吗？有没有不承载信息的墨水？ | 白底卡片、图例色块、多余网格 → 删；双轴 → 拆两个图 |
| 节奏与张力（Brodovitch） | 联系表上整本有呼吸吗？转折页感觉得到吗？ | 连续同构 → 换温度或换载体；全册太平 → 加一次论证驱动的尺度突变 |

按成因一次只改一个变量；跨页结构变了才重排联系表。

## 8. 没有现成方言时：派生

1. 找最近的主题当底（瑞士风最近 fashion，战略类最近 boardroom），沿用其网格、阶梯与评审标准；
2. 只重填四个基因槽位；
3. 把方言写进 DESIGN.md 的本册设计系统与模块选择，不新增平行体系；
4. 值得复用时再固化成新的 `design-principle.<id>.md`。

### 派生示例：英语学习单元课件（16:9，课堂投影）

现有四方言都不合适——boardroom 是决策稿、natgeo 是摄影叙事、fashion 是作品集、brand-geometry 是品牌几何。按四槽派生：

- **底场组**：**白 `#FFFFFF`**（Swiss 默认，不加纸色）+ 黑 `#111111` + 一个主题色（瑞士红 `#E2231A` 或亮蓝 `#0057FF`，二选一）；答案页才用满版黑或满版主题色反转。**只有这三个色相**，中间调由墨的不透明度派生，不用灰面分区。
- **双声部（按语言分）**：英文用 **`'Helvetica Neue'`**（瑞士骨架，不用 Arial——它是 Helvetica 的克隆），D 档巨字用 `'Avenir Next Heavy'` 补 900 重量；中文用 `'Hiragino Sans GB'` 并放在栈首；**不引衬线**。层级靠字号与字重，不靠换字体家族。
- **唯一结构母题**：**课段刻度**——顶部 01–06 进度刻度，每页只高亮当前段；学生永远知道自己在哪。
- **解构几何**：只在 2 个转折页出现（单元开篇、答案页前）：红或黑半透明矩形（12–18%）切分版面，几何不压字、不承载信息、对齐网格。
- **影像**：封面或故事页需要具象情境时，在页面映射表标 L1，**先问用户是否用 ImageGen**；用了就统一一种风格（如 duotone 摄影），存 `assets/`，标注为生成图；不用图库插画。
- **节奏**：讲解（静读）↔ 例文（情境）↔ 练习（互动）↔ 答案（黑场反转）四种温度交替；答案页是全册唯一的深色页。

排印用**讲授型**阶梯（B 26–32、T 48–64），不是阅读型的 18–22；每页正文 80–150 词。禁区：暖纸/米白、渐变、卡片、卡通贴纸、彩虹色、单词卡片墙、双语逐字堆叠。

这说明一条判据：**方言由"读者 + 观看距离 + 证据形态"决定，不由题材标签决定**。"英语学习"不是一个风格，先问是课堂投影（≥3m）、会议室屏幕，还是自己在电脑上翻——三种距离，三套字号。

## 9. 影像与解构几何层

- **几何不是装饰**：解构几何全册只允许 1–2 个转折页；形态限于矩形、条带、裁切蒙版、叠印；透明度 8–30%；必须对齐网格；不得压字、不得承载信息；禁止渐变、阴影、3D。**必须有构图职责**（切分、遮挡、导流、承托证据）；没有职责就不画，不要用半透明色块当背景框。
- **摄影可以出现**：瑞士不是"不能有照片"，照片承担情境或证据，不承担装饰；一张决定性的图胜过五张凑数图。
- **ImageGen 的询问时机**：DESIGN.md 阶段，页面映射表出现 L1 影像时，先问用户"这一页要不要生成一张图"；同意后统一一种视觉风格（写进 DESIGN.md），产物存 `assets/`，逐张 Read 核对，标注为生成图。
- **插画默认不用**：除非用户明确要（儿童教学可例外），且必须统一风格并声明；不用图库水印图、不用杂志扫描页。
