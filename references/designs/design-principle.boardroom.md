# design-principle.boardroom.md · 董事会编辑（Boardroom Editorial · 白底版）

**瑞士网格 × 编辑叙事，全无衬线执行**：McKinsey 的结构纪律、Swiss International 的网格与动线、Müller-Brockmann 的尺度对比。暖纸与衬线声部已移除——那是上一版方言的皮肤，不是本模块的必然。

与内置 consulting 分支**互斥**（它禁衬线、走卡片），命中本模块时不再叠加 consulting。

## 1. 风格 DNA

- **先主张，后证据**：页顶一句完整结论句，导语紧随，展品证明，主题色决策带说出决定。
- **网格先于装饰**：所有元素吸附 12 列网格与 8px 基线；发丝线落在网格线上。结构即装饰，圆角卡片、阴影、渐变不是。
- **阅读动线固定**：kicker → 标题 → 导语 → 证据 → 决策带 / 页脚，全篇同一顺序、同一位置。变的是展品语法，不变的是轴线。
- **单一 grotesque 家族 + 一个显示家族**：正文与标题统一 `'Helvetica Neue'`（真瑞士，非 Arial）；层级只靠字号与字重，不靠换家族、不引衬线。**D 档 900 用 `'Avenir Next Heavy'`**（系统里唯一拿得到的瑞士气质黑体；窄体 Condensed Heavy 留作长标题省宽度）——引擎只认 `bold` / `normal`，`fontWeight: 900` 与 `'Helvetica Neue Condensed Black'` 都会被静默回退（见 typography.md §2.1）。
- **数据落在纸面上**：图表直接画在白底或主题色底上，无白色绘图板、无卡片、无仪表盘铬件。
- **边缘克制**：一个展品一个强调色；摄影只在开场与收束（也可零照片）。

### Theme DNA（四槽，全篇不变）

- **底场组**：白 `#FFFFFF` 为主阅读底；主题色满版（如亮蓝 `#0057FF`，或按内容换红/黄）用于封面、转折页、决策带，深场也可用纯黑 `#111111`；**不使用暖纸/米白/深蓝黑**。
- **单一骨架 + 一个显示字面**：骨架 `'Helvetica Neue'`（标题 700 / 正文 400 / 注释 600）；显示字面 `'Avenir Next Heavy'` 只用于 D ≥96；中文 `'Hiragino Sans GB'` 栈首。不用 Arial。
- **唯一结构母题**：**主题色决策带**——每页以一条通栏或 8 列宽的实色带收束主张，位置随页型变化但永不离网格。
- **节奏**：白底精读 ↔ 实色转折 ↔ 透明证据，三种温度交替；零摄影时用图表/账本/结构图承担影像位。

**Extension Rule**：没有样本可照的页面，只允许改跨度（8/12 列）、尺度、图片状态（可为零）、密度与底场温度；不新增声部、不换母题、不加第二强调色。

## 2. 网格与母版（1280×720）

- 外边距 70；内容宽 1140；**12 列**，列宽 73、槽宽 24（12×73 + 11×24 = 1140）。
- 垂直节奏以 **8px** 为基线单位；所有 margin / gap / 行高取 8 的倍数（行高可容差 ±2px）。
- 阅读动线（内容页全篇固定）：
  1. Kicker 行（y ≈ 44）：14px 无衬线全大写、0.2em 字距、muted，写章节名。
  2. Action Title：44–48px、700、ink，≤2 行，左对齐至第 1 列。
  3. 1px 发丝线：标题下 8–12px，横跨 12 列。
  4. 导语 Lead：26px、400，占 7–8 列（655–752px），位于证据之上。
  5. 证据区：图表 / 账本 / 三栏发现，吸附列宽；底部可接主题色决策带。
  6. 页脚（y 660–720）：左 Source + 说明 13px，右页码 `NN / TOTAL`。
- 决策带：通栏或 8 列宽，白字主张 22px、700，次级文字 13px（White + `opacity: 0.78`）。

## 3. 色彩与字体

### 语义色板（颜色即语义，不装饰）

| 角色 | 值 | 用途 |
|---|---|---|
| White | `#FFFFFF` | 主阅读底，≥55% |
| Theme ground | 主题色满版（如 `#0057FF`）或纯黑 `#111111` | 封面、转折页、决策带 |
| Accent | 与 Theme ground 同源 | 唯一亮信号：推荐、进度、关键数字、当前段；单页 ≤8% |
| Ink | `#111111` | 标题、正文、直标 |
| Muted | Ink + `opacity: 0.62` | 次级标签、来源、注释（**不另立灰 hex**） |
| Rule | Ink + `opacity: 0.12` | 发丝线、表格横线 |
| On dark | White / White + `opacity: 0.78` | 深底主张 / 深底正文 |

**只有三个色相：白、黑、主题色。** 中间调全部由不透明度派生，不写 `#6B6B6B`、`#E5E5E5`、`#D4D4D4` 这类独立灰值——写一个灰 hex 就是引入第四色，纸面立刻变卡片。深场也不要用 `#0B1F33` 这种"深蓝黑"，要么主题色本身，要么纯黑。

主题色选择（按内容定，全册一个）：瑞士红 `#E2231A`（宣言、风险、强主张）、亮蓝 `#0057FF`（科技、教育、理性）、亮黄 `#FFD400`（活力、儿童，仅块面）。不引第二个强调色；暖纸、米白、莫兰迪色不是 Swiss 主题色。

### 字号阶梯（1280×720，见 typography.md）

| 角色 | px | 字重（A 重压型） | 实现 |
|---|---|---|---|
| 封面主张 / 金句 | 96–160 | 900 | `'Avenir Next Heavy'` + `'normal'` |
| 页标题 | 64–72 | 700 | `'Helvetica Neue'` + `'bold'`；中文 `'Hiragino Sans GB'` + `'bold'` |
| 导语 | 26–28 | 400 | `'Helvetica Neue'` + `'normal'` |
| 正文 | 18–19 | 400 | `'Helvetica Neue'` + `'normal'` |
| 图表直标 / kicker | 13–15 | 600–700 | `'Helvetica Neue'` + `'bold'` |
| 来源 / 页码 | 12–13 | 400 | `'Helvetica Neue'` + `'normal'` |

**页标题 64–72，不是 44–48**：本册封面尺 96–160，标题若取 48 就形成 3× 以上级比，视觉上会退化成图注。44–48 只在没有巨字的页（如账本页）成立。页标题用 Helvetica Neue Bold 而非 900，是瑞士的本来做法——压迫感来自字号与紧密行距，不是字重。

**正文 18–19 是对内置参考区间（22–28）的显式覆盖**，必须在 DESIGN.md 声明；对比度 ≥4.5:1 仍为硬线。单页字号 ≤5 种，前三级级比 ≥1.5。

## 4. 信息密度

- 论证页正文 300–450 字（B 18 的舒适区）；正文预算超了先删字，不缩字号。
- 每页一个视觉锚点，锚点周围留 ≥40px 呼吸空间；留白是结构，不是待填的坑。
- 内容区填充 ≥85% 指**结构占位**（证据、账本、图表铺满网格），不指"塞满文字"。
- 散文页双栏，栏宽 45–68 字符，不两端对齐，至多一个 pull quote。

## 5. 配图

摄影只在开场与收束各一张（也可零照片）：全幅底图 + 主题色蒙版，海报尺度、一个主张；收束页配三条带日期的承诺。证据页不用图库照片填空——那里的主视觉是图表与排版。需要具象场景时，先问用户是否用 ImageGen，统一风格并标注生成图。

## 6. 页面角色与节奏

| 页面角色 | 展品 | 成立条件 |
|---|---|---|
| 封面 / 收束 | 满版主题色 + 主张（D 级）+ 关键数字列或三条承诺 | 一个主张；数字列是结构不是装饰 |
| 一页论证 | 三编号发现 + 指标列 + 决策带 | 发现=论点，不是目录 |
| 目录 | 五行 + 主题色一览轨 | 轨上是数字，不是第二张表 |
| 变化 | 白底折线，末端直标 | 无图例时 ≤2 系列；洞察行沿网格分栏 |
| 桥接 | 瀑布 | 仅当落差本身是论点 |
| 定位 | 气泡矩阵 + 虚线中位线 | 每个气泡在标记处直标 |
| 诊断 | 问题树，关键分枝 accent | 根结论先于叶子可读 |
| 情景 | 开放表 + 点图 | 推荐只标一次 |
| 选择 | 对比表 + 推荐列 | 准则行对齐，只有一列赢得强调 |
| 计划 | 路线图 + 门径 | 条是工作流不是任务，门径带日期 |
| 散文 | 双栏阅读 | 一个 pull quote |
| 请求 | 三动作 + 负责人 + 价值 | 总计上双横线，决策带重复请求 |
| 记分 | 六指标排版账本 | 值/基线/进度/目标/负责人，无仪表盘 |

节奏：变的是展品语法与决策带位置，不变的是 kicker、标题线、页脚、边距。同一展品语法不连续超过两页。典型页序：情境 → 冲突 → 诊断 → 选择 → 建议 → 路线 → 记分 → 决策。

## 7. 图表与表格

执行 `../data-graphics.md`：透明绘图区、末端直标、语义色、单位/期间/基线/来源贴近展品标题。原生 Chart 只用于柱/折线，background 设为白底或主题色底；瀑布/气泡/点图/账本走 SVG 形状 + 独立文字层。表格开放横线、数字右对齐、单位在表头，推荐列浅底是唯一填充。

## 8. 反模式（出现即返工）

暖纸/米白底、装饰性背景框/半透明色块底板、KPI 磁贴与圆角卡片；阴影/渐变/发光/3D；仪表盘圆环、进度胶囊、线+彩块、图标墙；白色绘图板与色块图例；照片填充证据页；无衬线长段落里混入衬线；正文 Bold；一页多个强调色；为凑量化结论编数字（演示数据标 illustrative）。

**为通过留白检测而填充内容或装饰**——同样是反模式：先重排网格与动线，再谈是否补证据。

## 9. 最终硬闸门

1. 正文页标题不是完整结论句 → 返工。
2. 缺 Source/页码，或 kicker / 标题线 / 页脚位置漂移 → 返工。
3. 出现 §8 反模式任一，包括"为过检而填充" → 返工。
4. 正文 <18px 或未按声明阶梯执行，或引回衬线/暖纸 → 返工。
5. 元素未吸附网格（列宽、8px 基线）且无理由 → 返工。
6. 图表文字烤进 SVG/图片，或导出后回潮白底绘图板/图例 → 返工。
7. 同一展品语法连续 >2 页 → 调整节奏。
