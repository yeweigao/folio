# 风格方言：Otl Aicher · Munich 72（公共信息系统）

> 风格身份证括号里应写这个名字。它是真实流派——1972 慕尼黑奥运会视觉识别系统，Otl Aicher 主持，Univers 无衬线 + 色彩编码 + 系统化象形符号，为"远距离、快速识别、非母语读者"设计。课堂投影与公共导视是同一类问题：观众在 3 米外、只看 3 秒、必须立刻读懂。

## 1. 风格身份证

```
风格：瑞士网格 × 公共信息（Otl Aicher · Munich 72）
不是：SaaS 官网感、卡片仪表盘、卡通课件、渐变霓虹、培训 PPT 模板
三件不变：12 列硬网格 · 单编码色 + 黑白 · 无衬线单一声部
冲突裁决：网格裁决布局 > 编码色裁决强调 > 内容裁决长度
```

## 2. 四槽

1. **底场组**：白 `#FFFFFF` 纸面 + 墨 `#111111` + **一个编码色**。编码色只做三件事——块面、刻度、结构性标识；**绝不做小字**（黄/橙系在白底上不可读）。深场 = 墨满版；亮场 = 编码色满版。全册只允许这两种反转。
2. **双声部（实为单声部 + 尺度）**：全册一套 grotesque，靠字号与字重分级。Aicher 用 Univers 单一家族，不玩衬线对位。可用的 900 字面见 typography.md §2.1（Avenir Next Condensed Heavy）。
3. **唯一结构母题**：**编码色块条**——页眉 6px 的段位刻度条（或缺省时的 section 色条），以及 worksheet 的 SECTION 色带。同一母题贯穿全册，不换第二种标记方式。
4. **节奏**：白底精读 ↔ 墨满版转折 ↔ 编码色满版爆发。三种场，不引入第四种温度。

**Extension Rule**：没有样本可照的页面，只允许改跨度（3/4/6/12 列）、尺度（D 档取 72/96/120/150）、场的温度（白/墨/编码色）、密度。不得新增字体、不得新增色相、不得引入圆角/阴影。

## 3. 网格与排印

- 画布 1280×720；外边距 70；12 列 × 73 + 24 槽（第 n 列起点 = 70 + 97n）。
- 母版四段：页眉刻度条 y26–32 → kicker y50–70 → 标题 78–141（T56）→ 内容 157–653（496）→ 页脚 688–708。
- 字号（投影型）：D 72–150 / T 56 / L 32 / B 26 / Bs 22 / C 18 / A 16。
- **容器高度按 `fontSize × 1.6` 预留**——引擎的 lineHeight 在包含检测里几乎不生效，按 1.15 算必报 child-containment。

## 4. 编码色怎么选

编码色的唯一标准：**在白底上做块面时够亮，在投影仪上不脏，与黑字对比 ≥ 7:1**。

| 气质 | 编码色 | 说明 |
|---|---|---|
| 课堂、儿童、公共活动（默认推荐） | 柠檬黄 `#FFD400` | 黑字压黄 13.2:1；投影最亮；"学校"联想（校车、荧光笔、铅笔） |
| 机构、理性、数据 | 亮蓝 `#0057FF` | 白底小字可读（5.5:1），但**易读成 SaaS 蓝**，慎用于低龄 |
| 强主张、风险、文化 | 瑞士红 `#E2231A` | 块面 + 白字 |
| 生长、自然、科学 | 墨绿 `#00693E` | 块面 + 白字 |

**并列类别超过 3 类时才启用第二编码色**（如三课段各一色）；每色只承载一类语义，且必须在 DESIGN.md 写明"哪个色 = 哪一类"。**不要用紫 + 黄**——那是万圣节配色；也不要用粉 + 蓝——那是消费品牌。

## 5. 信息图形

- 对比用**长度**（条、格、基线），不用饼、不用环、不用 3D。
- 数值直标在图元末端，不出图例、不出白色绘图板、不出网格线。
- 系统化符号（icon）只允许在"需要快速识别动作"时出现；**纯文本页不配图标**——Aicher 的符号系统是为跨语言导视，不是为了给每条要点配小图。

## 6. 禁区

渐变、阴影、圆角、发光、3D、卡片、KPI 磁贴、图标墙、彩色胶囊标签、彩虹色、卡通贴纸、彩带礼花、装饰性插画、把色块当背景框。

## 7. 什么时候不要用它

- 需要"权威厚重感"的董事会稿 → 用 boardroom；
- 品牌已有视觉规范 → 以用户资产为准；
- 纯文字长文档 → 不是 deck，别套。

## 8. 并列页扩展：Bento（Swiss 化）

见 `modular-grid.md`。要点重复一次：**块面 = 纯色块或墨线框，无圆角无阴影**；层级只有三种（实色块 > 3px 墨线 > 1px 墨线）；跨度取 12 列整数倍；块间槽 20（不是 40）。词卡、功能矩阵、模块地图都用它。
