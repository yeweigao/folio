# 通用适配器（任何 agent / 任何引擎）

> status: 通用清单 · 最后核对：2026-10-25
> 适用于 Claude、Codex、DeepSeek、Gemini、WorkBuddy，以及任何能读 Markdown 并产出文件的工具。没有引擎专属命令，只有验收事实。

## 1. 先定"谁在渲染"

交付前必须知道三件事：

1. **最终渲染器是什么**（浏览器 / 幻灯片引擎 / 排版软件 / 图像管线）。
2. **字体从哪来**（系统字体 / 嵌入 / 网络字体 / 回退栈）。
3. **用户拿到的是什么**（可编辑源文件 / PDF / 图片 / 代码）。

不知道这三件事，就不要声称"排版已完成"。

## 2. 文本：四个必测

| 测试 | 方法 | 失败表现 |
|---|---|---|
| 换行 | 用最终字族与字号渲染，数行数 | 标题掉字、孤字成行、卡片高度不够 |
| 溢出 | 取最长的一条真实文案，不看占位文 | 文本被裁切或自动缩小 |
| 字重 | 对比 bold 与 normal 的实际渲染 | 数字字重被忽略、中文 bold 失效 |
| 可编辑 | 打开导出文件，选中文字 | 文字被转曲 / 烤进图片 |

**容器高度**：按 `fontSize × 1.6` 预留；行高在部分引擎里不参与包含检测。英文按字符数估算行数时乘 1.1 安全系数，中文按字号直接算。

## 3. 字体：三条硬规则

1. 含中文的文本，中文字体放栈首。
2. 只使用**实际存在**的字重；要 Black 就换带 Black 字面的字族，不靠数字。
3. 换字体 = 重排版面。字宽差 10–25%，所有换行点、卡片高度、按钮宽度都要重核。

无法嵌入字体时：转曲仅用于展示性大字，正文保持可编辑并随附字体清单；两者不可兼得时，优先保证正文可编辑。

## 4. 布局：先量后画

- 用真实内容测量，不用 Lorem ipsum 决定高度。
- 固定画布（deck / poster / handbook）：所有元素吸附列线与基线；导出后逐页看缩略图。
- 响应式（web / canvas）：至少在 390 / 768 / 1440 三个宽度验证；断点坍缩后网格仍须可指认。
- 自动布局只能实现已决定的构图，不能替你做构图。生成后检查间距是否被均分、层级是否被抹平。

## 5. 图像与图表

- 图片：真实素材 > 公共收藏的真实照片 > 代码绘制 > 纯文字。**没有就不放**，不用生成图冒充事实。
- 图表：能用代码绘制就不用截图；原生图表必须能关图例、去背景、直标终值。做不到就换实现。
- 矢量文字层：SVG 内的文字若要可编辑 / 可搜索，必须另建文本层，不烤进路径。
- 导出图片：至少 2x；印刷按 `handbook.md` 的 300dpi；网页按实际显示尺寸的 2 倍。

## 6. 导出：五种格式的验收

| 格式 | 必查 |
|---|---|
| PPTX | 字体替换、换行、图表、图片位置、母版、可编辑性 |
| PDF | 字体嵌入、出血与裁切标记、RGB/CMYK、页面尺寸、链接 |
| PNG / JPG | 分辨率、裁切、色彩配置、透明背景是否符合预期 |
| SVG | 文字是否仍是文字、字体引用、viewBox、外部资源 |
| HTML / 代码 | 真实浏览器渲染、断点、焦点、对比度、语义标签、控制台报错 |

**"应该能过"不算验收。** 打开、翻页、缩放到 100%、在目标设备上看过，才算。

## 7. 引擎做不到时

按顺序处理：

1. **换实现**：原生图表做不到直标 → 用代码绘制；引擎字体不全 → 换字族。
2. **换构图**：复杂效果做不出来 → 改用色块、几何、纯文字，仍符合契约。
3. **明确降级**：在交付说明写清哪一项没达到、为什么、代价是什么；不得静默降低可读性下限。
4. **不修改契约去迁就引擎**。引擎是印刷厂，不是立法者。

## 8. 交付回执

五行的“交付说明”不是回执。统一表单与模板在 [`acceptance.md`](acceptance.md) §3：每一条必须指回文件、页面、宽度、设备或数值；允许写 `unverified`，不允许把没验写成通过。
