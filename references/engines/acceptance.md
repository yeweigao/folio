# 验收单与交付回执（跨引擎）

> 不是引擎适配器。所有引擎共用一张单；引擎特有的事实仍住各自的适配器。
> 状态：stable（表单）· 最后核对：2026-10-25

## 1. 一条原则

验收不是“看起来对”，是“能被另一个陌生人复查”。每一条检查必须留下可指认的证据：文件名、页数、宽度、设备、选中文字、对比度数值。

“应该能过”“预览没问题”“导出成功”都不是证据。

## 2. 验收单（12 项）

| # | 检查 | 方法 | 通过条件 | 失败动作 |
|---|---|---|---|---|
| 1 | 文件能开 | 用目标软件打开导出件，翻到最后一页 / 屏 | 无报错、无缺字、无空白页 | 重导出；换实现 |
| 2 | 文字可编辑 | 选中标题与正文，改一个字再撤销 | 是文本对象 | 转曲 / 烤图 → 重建文本层 |
| 3 | 字体真实 | 看实际字族与字重，不看设置面板 | 与声明一致；中文栈首 | 换字族；重排换行 |
| 4 | 换行与溢出 | 用最长的一条真实文案，数行数并看容器 | 不掉字、不裁切、不自动缩小 | 改字号 / 列宽 / 文案 |
| 5 | 可读下限 | 量正文、标签、图注的实际字号 | 达到表面下限 | 提字号；删内容 |
| 6 | 对比度 | 用实际前景与背景算 WCAG | 正文 ≥4.5:1；大字 ≥3:1 | 换前景；加深 scrim |
| 7 | 网格与基线 | 量边距、列宽、槽、元素边缘 | 公式成立；元素吸附列线与基线 | 重算；不目测 |
| 8 | 图像分辨率 | 按成品尺寸算像素 | 印刷 300dpi；大画幅 ≥150dpi；web 2x | 换图；缩用途 |
| 9 | 来源与许可 | 抽查 3 个数字 / 图片；量 illustrative 标记的实际字号 | 来源可指回（作者 / 机构、标题、日期、定位）；图片有许可；标记 ≥ 同表面图注下限（屏幕 12px；印刷 8.5pt；A2 海报 14pt），同层同单位 | 补来源 / 许可；放大标记；删断言 |
| 10 | 一个单位一个主意 | 遮住标题，能否说出这一页 / 屏的主张 | 能 | 拆单位 |
| 11 | 动作与方言 | 遮住颜色与字体，能否认出决定性动作与方言 | 能 | 重做结构 |
| 12 | 偏离与未验证 | 查回执 | 每条例外有理由与代价；未验证写明 | 补记；不得口头放过 |

第 1–6、9 项是打开、可编辑、字体、溢出、可读、对比、来源与许可，不能豁免；第 9 项的标记字号属于可读性，同样不能豁免。第 7–8 项必须以实测值为准，可因声明过的破格而偏离，但不能“目测通过”；第 10–11 项是设计判断，失败就返工，不用“风格”解释。第 12 项是诚实的出口：做不到的可以写，不能藏。

**测量三条**（数字来自渲染结果，不来自声明）：

1. **对比度先合成。** `rgba` 前景按 α 合成到实际背景后再算 WCAG；背景是图像时取字后最差像素。用声明色直接算会高估。
2. **字号与行宽量字面。** 用文字范围或等价物，不量块级盒；块级 `span` 会把整行撑满。字号保留一位小数，向下取整。
3. **网格只量构图元素。** 标题块、信号块、信息列、页脚对列线；组内流与块内内缩不单独对线，但要在系统声明里写明。

## 3. 交付回执（模板）

```
folio receipt
项目：
契约版本 / 日期：
引擎 / 渲染器 / 版本：
表面 / 画布 / 网格：
方言 / 决定性动作 / 信号语义：
材料来源 / illustrative：
实际打开的证据：
  - 文件：
  - 页数 / 宽度 / 设备：
验收结果：pass | pass-with-deviations | unverified
逐项：#1 pass · #2 pass · …（只展开例外与未验证）
表面追加项：web 键盘 / focus / 三档；poster 出血 / 打样；handbook 预检；canvas 25%；deck 逐页（按 §8）
红队残余风险：未触发 / 见 <文件>（触发红队时写）
偏离记录：
  - 哪条：
  - 为什么：
  - 代价：
  - 批准：
未验证项：
  - 项 / 为什么没验 / 下一步
```

回执长度不设上限，但每一条都必须指回一个文件、一个页面、一个数值或一次操作。没有指回对象的“已检查”不算。

## 4. 三种结果

- **pass**：12 项与 §8 本表面追加项全过，且有实际打开的证据。
- **pass-with-deviations**：12 项的硬地板与 §8 的硬项全过；风格偏离事先声明、写清代价。可交付。
- **unverified**：任何硬地板项或 §8 硬项未验，或没有实际打开的证据。只能称“待验”，不能称“完成”。

硬地板项（不编事实、文字可编辑、真材料、可读性、来源与许可）永远不能进入 pass-with-deviations。引擎做不到，就换实现、换构图或明确降级；降级也不能突破可读性与诚实。

红队结论不是验收结论。`no-unregistered-high` 只说明门禁没有已知的便宜赢法；pass 仍由本单与独立复审给出。

```

引擎 / 渲染器 / 版本：无（纸面推演）

方言 / 决定性动作 / 信号语义：folio / “12”成为网格 / 第 10 列红线
材料来源 / illustrative：无照片；讲者、日期、地点均为占位
实际打开的证据：无（未导出）
验收结果：unverified
逐项：#1–#8 未验证（未导出）；#9 未验证（占位标记未落到成品）；#10–#11 pass（纸面可判）；#12 pass
表面追加项：未验（纸面推演）
红队残余风险：未评估（纸面推演）
偏离记录：无
未验证项：
  - 导出与字体回退：未在 slidep / 浏览器 / 印刷打样中打开
  - 真实材料：没有讲者照片与现场图，示例不补
```

这张回执的价值不是“通过”，是它没有假装通过。

## 6. 两个失败样本

### 6.1 缩略图通过，文字没通过

一份 deck 导出后，缩略图看起来对齐，agent 宣布完成。打开 PPTX 后发现：中文粗体回退成常规，标题多换了一行，一个正文块被容器裁掉。三个问题在缩略图里都看不见。

回执会强制第 2 项（选中文字）、第 3 项（看实际字族）、第 4 项（用最长文案数行）。失败的不是引擎，是把缩略图当成了证据。

修正：缩略图只用于看节奏；验收要打开、选中、量字号、数行数。没有回执，不算交付。

### 6.2 标记存在，读者看不见

A2 海报的 illustrative 声明设为 6pt。渲染后计算字号 8px，行高 10.4px，低于屏幕 12px 与 A2 图注 14pt 的下限。0.8 的表单只问“显眼”，会判通过；读者在正常看距下读不到这句话。

修正：#9 从“有标记”改为“标记 ≥ 同表面图注下限”，并量实际字号；6pt 不合格，14pt 才合格。存在不等于可读。

## 7. 一张单，三种引擎

| 引擎 | 主要风险 | 回执里必须多写的 |
|---|---|---|
| slidep | 字重被忽略、中文 bold 失效、容器裁切 | 实际字族与字重、容器高度、PPTX 逐页打开 |
| ardot | 自动布局改写网格、字体回退、组件默认值 | 三个断点宽度、文本层是否可编辑、哪些是工具默认 |
| generic | 渲染器不明、字体来源不明、导出格式不定 | 谁在渲染、字体从哪来、用户拿到什么 |

引擎适配器负责“这个引擎会怎么坏”；本单负责“坏了有没有被看见”。

## 8. 表面追加项

12 项是共用地板；每个表面还有自己的硬项。追加项不替代 12 项，只补该表面才会发生的失败。对应表面交付时，追加项未验即 `unverified`。

| 表面 | 在 12 项之外必须验 | 证据 | 未验的结果 |
|---|---|---|---|
| web | Tab 走完主路径；`:focus-visible` ≥2px；语义标题与 `lang`；skip link；`prefers-reduced-motion`；390 / 768 / 1440 无横向滚动 | Tab 顺序记录、focus 样式、三档 `scrollWidth` | unverified |
| poster | 3mm 出血 / 5mm 安全区；CMYK、总墨量 ≤300%；300dpi（大画幅 ≥150dpi）；打样 | 页面框、出血标记、像素数、打样照片 | 无打样 → unverified |
| handbook | 骑马钉页数为 4 的倍数；3mm 出血 / 5mm 安全区；300dpi / CMYK / PDF/X-4；总墨量 ≤300%；书脊 ≥5mm 才排字 | 页数、跨页图、预检报告、书脊计算 | 无预检 → unverified |
| canvas | 画框有名称与顺序；25% 缩览帧标题可读；连接线正交；导出 ≥2x | 25% 截图、连接线截图、导出尺寸 | 未做 25% → unverified |
| deck | 最后一排可读；逐页打开 PPTX；中文字重真实；16:9 安全区无裁切 | PPTX 页数、末排字号、实际字重、安全区截图 | 未逐页 → unverified |

屏幕截图只能证明屏幕。任何“印刷用”结论，没有 PDF/X-4、出血与打样，就停在 `unverified`。
