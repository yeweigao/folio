# Canon · 来源、母体数值与词条

本文件回答三类问题：这套审美从哪来；母体的数字是多少；v0.1 里互相打架的地方在现行契约里怎么裁决。

规则可以改，来源不能编。任何一个数字、口径或方言，都要能在这里指回原处。

## 1. 谱系

### 1.1 设计史

- **瑞士国际主义**：Josef Müller-Brockmann《Grid Systems in Graphic Design》《Gestaltungsprobleme des Grafikers》；Emil Ruder《Typographie》；《Neue Grafik / New Graphic Design》1958–1965（Lohse、Müller-Brockmann、Neuburg、Vivarelli）；Massimo Vignelli 的 Unimark / 纽约地铁图。
- **公共信息**：Otl Aicher 与慕尼黑 1972 视觉系统；Erco 导视；ISO 7001 公共信息符号。
- **构成主义**：Rodchenko、Lissitzky 的 Proun；《Kino-Fot》版式。
- **包豪斯 / 风格派**：Bayer 的通用字母表；Mondrian、Doesburg 的网格与基本形。
- **编辑设计**：Brodovitch 的《Harper's Bazaar》；《Neue Grafik》的三语并排；当代报纸与年报的动作标题制度。
- **纪实摄影**：Farm Security Administration；`Life` 的图片叙事；光圈与马格南的图注纪律。
- **瑞士朋克 / 后现代**：Wolfgang Weingart 的排印实验；April Greiman 的叠印与层；80 年代 Emigre。
- **克制粗野**：结构主义建筑与早期现代主义的材料诚实；当代展览图形中的裸露网格。

### 1.2 屋主的系统

- `全样式-Folio2.1样式总册.html`：20 个布局、35 个组件、14 种变奏。**十四破格的直接来源。** 原书原则："十四条规则是默认。每一种变奏有意打破其中一条，并让读者认出这是破格。"
- `ppt-master-themes/framework/PHILOSOPHY.md`：公式"瑞士国际主义网格秩序 × 先锋编辑叙事 × 有控制的解构切分 × 克制的新粗野结构感"；四个 DNA 槽；四种大师视角。
- `ppt-master-themes/themes/`：`boardroom`（深海军蓝 + 编辑论证）、`fashion`（Bodoni + 钴蓝 + 时装摄影）、`natgeo`（暖纸 + 柠檬黄 + 纪实照片）、`brand-geometry`（身份几何作度量）。
- `handbook-designer-skill/references/swiss.md`：先决定关系，再选配方；表现力从比例和材料中来。
- `handbook-designer-skill/references/style.md`：Folio CSS 2.2 的 token 与 A4 手册参数。

### 1.3 外部 skill 的方法论

- **Hallmark v2**：硬地板不可谈判；反趋同的发牌；材料盘点；一个签名动作；换上下文复审；"地板之上，页面是你的"。
- **taste-skill v2**：先盘点对象自身的事实，再写论证，再定方向；"在这一页，[对象的东西] 变成 [装置]"；一个活的交互；文案先行；看截图再修。
- **Karpathy skills**：入口短、声明式、零预加载。Folio 的 `SKILL.md` 必须能独立开工。

## 3. 四个 DNA 槽

任何方言、任何表面，先填这四槽。填不满，说明还没想清楚。

1. **底场组** — 纸、墨、一个信号；深场与亮场如何反转；纸占多少。纸色是材料，不是第四个色相。
2. **双声部** — 主张声部与证据声部各用什么、在哪出现、何时不出现。角色不互换。
3. **唯一结构母题** — 全篇一个可指认的标记系统：刻度尺、决策带、出血巨字、四角括号、裁切框、连接线。一个，不是一套。
4. **节奏** — 精读场 ↔ 转折场 ↔ 爆发场如何交替；同一种语法连续出现几次必须换。

## 6. v0.1 矛盾的裁决

v0.1 的绝对禁令与屋主自己的作品有冲突。现行契约不装作没看见，逐条收窄：

| v0.1 说法 | 现行裁决 | 理由 |
|---|---|---|
| 零 em dash | 英文文案禁装饰性 em dash；中文破折号按中文标点规范 | 把中文标点当成英文 AI 味，会误伤正常写作 |
| 禁渐变 | 禁装饰性渐变；照片压暗层（scrim）可为可读性使用，单层、中性、可解释 | 深色照片上的白字需要底，这是功能不是装饰 |
| 禁文字进图片 | 禁可读正文进图片；装饰性"字即图像"必须配真实可选文本与替代文本 | 时装与海报的字形图像是合法材料，不可读与不可编辑才是问题 |
| 禁 Inter | 禁 Inter 作默认正文/展示；作为声明的标签/数字字族可用 | 屋主的手册系统确实用 Inter 做标签；问题在"没选过"，不在字体本身 |
| 只有三色相 | 纸、墨、一个信号；纸的暖冷是材料，不算第四色相；功能类别色只在 `public-info` 出现且有映射 | 印刷暖纸与导视功能色是真实需求 |
| 只许无衬线 | `folio` 无衬线；`editorial`、`fashion`、`documentary` 可引一个衬线展示族 | 衬线不是背叛瑞士，未经声明地混用才是 |
| 辅助黄/橙/沙色 | 从 `folio` 删除；信号色四选一，全篇一个 | v0.1 自己的色板违反了三条色相纪律 |
| 多色导视 | 只在 `public-info` 允许功能色组，必须写明"哪个色 = 哪一类"，且不承担装饰 | 语义色不是第二个信号色 |

**裁决原则**：先保可读性与诚实，再保方言的表达力，最后才保条文的字面整齐。任何收窄都要在这里留一行。

## 7. 词条

- **信号色** — 一个构图里唯一承担"看这里"的色相。常规页 ≤10%，主张页 ≤20%。
- **中间调** — 由墨的不透明度派生，不写独立灰 hex。
- **双声部** — 主张声部（display）与证据声部（body/reading/label/number）；角色不互换。
- **结构母题** — 全篇唯一可指认的标记系统。
- **决定性动作** — 一个单位里唯一能被观者用一句话描述的构图决定；承担排序、证据或节奏，不是装饰。说不出，说明形式还没发生。
- **形态** — 一个单位在干什么：宣言、展品、论证、推进、对照、演练、并列、转场。
- **方言** — 瑞士母语 + 一种历史运动，带书面融合契约。
- **签名动作** — 一个方言的可指认构图动作；不是配色或字体。换掉颜色与字体后动作仍在，方言才成立。
- **破格** — 有意打破一条默认，并让读者认出规则的存在。
- **illustrative** — 演示数据标记；必须给算式或基线，排版上与真数据同样显眼。
- **最小单位** — 封面、首屏、首帧或最难的一页；先做它，再复制语法。

## 8. 变更

新增来源、修改母体数值、裁决新矛盾，都要在 `EVOLUTION.md` 记一行：日期 · 类型 · 对象 · 动作 · 理由。没有来源的数字不进本文件。
