# Steering — named moves for refinement turns

Borrowed from impeccable's command vocabulary, kept to Folio's own grammar:
after delivery, a refinement names one move. The move is recorded in
DESIGN.md (tokens first, then the units) before it is applied, exactly like
a value added at Make. Floors never move under any steering word.

| Move | Changes in DESIGN.md | Never changes |
|---|---|---|
| **Quieter** | Accent uses drop (fewer units carry it, accent area toward the theme floor); scale contrast narrows one step; one variation is retired to continuity | Facts, the lead of each unit, type floors |
| **Bolder** | Scale contrast widens one step; the leading move grows (graphic scale for type, closer crop for image); one named variation is added at the strongest turn | Reading text treatment; more than one break per unit |
| **Ledger** | Loose numbers and KPI-style figures are re-set as ledger rows: value, baseline, period, change, aligned on the decimal (craft, Data) | The numbers themselves |
| **Densify** | Spacing steps compress one declared step; reference treatment spreads to suitable units; empty fields are given a job or removed | Measure (line length) floors and size floors |
| **Open up** | Spacing steps widen one declared step; one Pause variation is placed before the climax; secondary material recedes to muted | Content: nothing is deleted to make room |
| **Field turn** | The strongest statement unit moves to an accent or dark field with its complete foreground palette (theme, Variations: Accent field) | More than one field turn per sequence |
| **Retype** | The hierarchy mode changes (weight leads ↔ scale leads, craft, Type) and the ramp is re-declared; faces stay unless the brief changes | The faces' scripts coverage: a new face still needs its CJK pair resolved |

A turn that names no move is read for the move it describes; an unnamed
change is still written into DESIGN.md first.
