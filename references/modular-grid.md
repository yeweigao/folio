# 模块网格（Bento 的瑞士化）

Bento 是便当盒：分格、圆角、每格一个话题。**把盒子去掉，剩下的是模块网格**——这本来就是瑞士的东西：不同跨度的方块压在 12 列上，靠面积与线宽排主次，不靠卡片。所以它不是外来风格，是同一套哲学的并列页语法。

## 1. 什么时候用（每册自己判断，不预设）

判据一句话：**内容之间是"并列"还是"推进"？并列才切块。**

| 适合 | 不适合 |
|---|---|
| 目录 / 课程总览 / 模块地图 | 论证页（要单轴推进，切块就断） |
| 功能矩阵、能力对照 | 叙事页（时间 / 因果链） |
| 多模块并列介绍、产品线总览 | 单主题页（一页一个主张时不切） |
| 指标快照（4–6 个平级数字） | 需要读者按顺序读的推导 |

一册里最多出现 1–2 次。它不是默认页型，是"这一页恰好是并列结构"时才启用。

## 2. 形态（去壳）

- **块面 = 纯色块**（主题色满版 / 纯黑 / 白），不是卡片：**无圆角、无阴影、无灰底**。
- **跨度取 12 列的整数倍**（3 / 4 / 6 / 12 列）；行高取 160 或 340；块间槽 20（不是 40——大缝隙会造出"卡片感"）。
- **层级只有三种**：实色块 > 3px 墨线 > 1px 墨线。一眼排出主次，不用第四种手段。
- **每块只放三样**：kicker（编号 + 名称）、一句标题、可选一个数字或一句注释。块内左对齐、共基线。
- 一块一个话题，不跨话题；块数 4–7 个，超过就说明这页该拆。

## 3. 反模式

圆角卡片、悬浮阴影、灰底分区、四色以上；**九宫格等分**（没有主次就不是 bento，是表格）；每块塞满文字（那是卡片墙）；用大留缝 + 描边营造"独立卡片"的错觉。

## 4. 与三色纪律的关系

模块网格最容易破三色——块一多就想加浅底。**分区只允许：实色块、墨线、白**。需要第四种层级时，改线宽或改跨度，不加色。
