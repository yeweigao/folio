# 形态路由 —— 先判这一页在干什么

**第一性原理**：依据内容的用途选展现形式，然后才在风格框架里"带着镣铐跳舞"。
顺序是：**内容契约（整册）→ 风格 → 形态（逐页）→ 版式 → 语法润色**。把顺序倒过来，就会得到"好看但不干活"的页。

自检一句话：**把这一页的装饰全删掉，只剩文字，读者还能完成那个动作吗？** 能，形态成立；不能，说明在用装饰替代结构。

## 1. 八种形态

| 形态 | 这一页在干什么 | 出现即选它 | 必须给的 | 禁则 |
|---|---|---|---|---|
| **宣言** Manifesto | 让一句话被记住 | 全页只有一个主张，且它能被复述 | 巨字、满版场、极少元素 | 加第二组证据；加解释段落；加装饰 |
| **展品** Exhibit | 让一个对象被看清 | 有明确主角（物、人、界面、产品） | 主角 ≥40% 内容区；直标 | 主角缩成角标；多主角平分版面 |
| **论证** Argument | 让一个判断被接受 | 主张 + 证据 + 含义，三段齐 | 结论式标题；证据可数 | 只摆数字不给判断；证据与主张不同轴 |
| **推进** Sequence | 让人跟着走一遍 | 项之间有先后依赖（时间 / 步骤 / 因果） | 单轴编号；每步一个动作；末步落结论 | 蛇形分栏；打乱顺序；把有先后的内容写成并列 |
| **对照** Comparison | 让差异被看见 | 两个以上对象需要被比 | 同一基准线、同一尺度、直标 | 双轴；不同量纲并排；只靠颜色区分 |
| **演练** Drill | 让人动手做一遍 | 有题、有作答位、有核对方式 | 作答空间；**独立答案页** | 答案与题同页；题干被装饰挤压 |
| **并列** Parallel | 让一组同级项被扫读 | 项与项之间没有先后依赖 | 统一基线；跨列面积排主次 | 九宫格等分；蛇形分栏；每项塞满 |
| **转场** Turn | 让人知道翻章了 | 进入新的章节或段落 | 一句话说清下一段是什么 | 铺正文；四卡预览；重复目录 |

**收束**（结尾页）不是第九种，是**宣言的终局用法**：只回收、不新增。

## 2. 形态 → 版式家族

形态只约束"允许哪一族的版式"，具体用哪一种由风格给语法。

| 形态 | 允许的版式家族 | 风格在其中的作用 |
|---|---|---|
| 宣言 | 满版单主张、巨字 + 一处证据 | 场色、字面、尺度极差 |
| 展品 | 单主角占位（半屏 / 满高 / 首格） | 裁切比例、直标、与文字的耦合方式 |
| 论证 | 结论标题 + 单轴证据 + 决策带 | 标题制度、图表纪律、密度 |
| 推进 | 单轴编号、时间轴、步骤条 | 编号制度、连接件（线/箭头）、每步的视觉重量 |
| 对照 | 双栏 / 双行 / 同基准的裸条 | 线宽分级、是否用色块 |
| 演练 | 卷头 + 分节 + 作答行；答案独立成页 | 卷头语法、分节标记、行距密度 |
| 并列 | 模块网格（跨列不等）、单轴列表 | 去壳方式（实色 / 粗线 / 细线）、槽距 |
| 转场 | 满版场 + 一句话 + 元信息 | 场色、巨字、元信息栏 |

## 3. 冲突裁决：内容有否决权

**形态与风格打架时，先改语法，再改密度，最后才换风格。** 绝不为守住风格而曲解内容用途。

| 冲突 | 处置 |
|---|---|
| 风格禁卡片，但形态需要分块 | 保形态、改语法：**去壳分块**（实色块 / 粗线 / 细线三档），不是放弃分块 |
| 风格禁彩色小字，但形态需要强调 | 保形态、改手段：块面反白、加粗、加大字号，不是加第二个色相 |
| 风格的密度撑不起形态（如演练页要密） | 保形态、改密度：密度是形态的函数，不是风格的常量 |
| 内容根本装不进风格（同一批内容换读者/距离） | 才换风格。给家长会讲与给三年级课堂讲，是两种风格选择 |

镣铐的边界：**开工前可以换一副，开跳之后不许换**。中途换 = 拼贴。

## 4. 判错的三种典型代价

- **演练形态被套了论证页语法** → 题目页带答案带。学生看见答案，卷子作废。
- **并列形态被套了对称版式** → 六宫格 / 九宫格。没有主次，扫读变成逐格读。
- **论证形态被写成宣言** → 每页一句金句，全册没有一处证据落地。读着爽，什么都没证明。

## 5. 一页只能有一个主形态

允许"主形态 + 一个从属动作"（如：论证页右下角带一个 4 行小结）。**出现两个主形态就该拆页**，不是压缩。

## 6. 从内容源判形态

叙事层给的信号大概率对应某个形态，但映射不是一一对应，须逐页确认：

| 内容源的信号 | 大概率形态 |
|---|---|
| 封面 / 收束 | 宣言 |
| 章节扉页 | 转场 |
| 内容页 + 有题有作答 | 演练 |
| 内容页 + 有主角图或物 | 展品 |
| 内容页 + 有数字对比 | 论证 或 对照 |
| 内容页 + 有先后 / 步骤 / 时间 | 推进 |
| 清单页 + 平级项 | 并列 |

**页面映射表必须有一列"形态"**，写在版式列之前。没有形态列 = 没做形态路由。

## 7. 复核清单（接在交付前）

- [ ] 每页的形态都填了，且与内容用途一致（不是与版式一致）
- [ ] 演练页没有答案；答案在独立页
- [ ] 宣言页没有第二条证据；论证页有结论式标题
- [ ] 并列页的项之间没有先后依赖；推进页的项之间有；两者没有互串
- [ ] 推进页是单轴向，没有蛇形分栏
- [ ] 一页没有两个主形态
- [ ] 形态与风格冲突处，记录了选了哪一边、为什么
