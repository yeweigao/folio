# DESIGN.md 写作指南 —— 本册设计系统 + 页面契约

DESIGN.md 不是参数复读，是**本册的设计系统声明 + 逐页契约**。内置流程在 Step4 生成它；本包负责把它写成艺术总监的宪法。写法原则：全部落成具体值（hex、px、字重、列宽），判断层写"默认 / 若…则…"，偏离要计费。

## 0. 风格身份证（DESIGN.md 的第一屏）

agent 每页动笔前都会回读 DESIGN.md，第一屏决定它的"默认审美"落在哪。写四行，不超过 60 字：

```
风格：瑞士网格 × <哲学分支>（<真实流派名 · 代表作>）
不是：纯 Swiss（全无衬线/少层级）、咨询卡片风、SaaS 官网感
三件不变：<网格> · <双声部> · <唯一母题>
冲突裁决：网格裁决布局 > 声部裁决字体 > 内容裁决长度
```

三条理由，缺一条就别写：

1. **名字负责召回**：一个准确的传统名能让模型调出正确的参照系（网格、动线、排印纪律），比"高级感、大师级"有效得多。
2. **"不是"负责防漂移**：模型会滑向训练里最高频的默认（白卡片、KPI 磁贴、居中海报、渐变阴影）。点名"不是什么"比笼统说"避免 AI 感"有效。
3. **数字负责执行**：名字只给方向，网格列宽、字号阶梯、W(S)、对比度才是可验证的规格。**只有名字没有数字 = 内置 `swiss-minimal` 的水平**（见源仓库 PHILOSOPHY §2 的反例）。

名字要短、要具体、要是真实存在的传统（"瑞士网格 × 编辑叙事"可以，"高级商务风"不行）；名字与实际参数必须一致——挂 Swiss 的名却用衬线正文、卡片布局，比不写名字更糟，因为模型会忠实执行那个错误的名字。

**这四行是每册一份，不是模板常量。** 前半句（哲学）恒定，括号里的方言随内容变；"不是"与"三件不变"也随方言重写。**括号里必须是真实流派名**（可检索、有代表作，见 SKILL.md §4.1），自造场景词等于没写。选方言看四件事：

| 内容 / 场合 | 括号里写（真实流派） | 身份证前半句 |
|---|---|---|
| 课堂投影、培训、公共信息、导视 | `Otl Aicher · Munich 72` | 瑞士网格 × 公共信息 |
| 董事会战略评审、投资案、咨询交付 | `Boardroom Editorial`（Brockmann 海报系统） | 瑞士网格 × 编辑叙事 |
| 并列条目、词卡、功能矩阵 | `Bento（Swiss 化）` | 瑞士网格 × 模块并列 |
| 纪实叙事、研学手册、品牌故事（摄影主导） | `Editorial`（Brockmann 影像版） | 瑞士网格 × 纪实叙事 |
| 时尚 / 作品集 / lookbook（影像与裁切） | `Editorial · Fashion` | 瑞士网格 × 时尚编辑 |
| 品牌几何、产品发布（几何母题主导） | `Bauhaus · De Stijl` | 瑞士网格 × 品牌几何 |
| 技术架构、API 文档、内部规范（无叙事需求） | `Vignelli · Unimark` | 瑞士网格 × 技术文档（全无衬线、3–4 级字号） |
| 政务 / 党建、学术答辩 | 不套本哲学 | 走内置对应分支，本包不介入 |

没有合适方言时按 `design-philosophy.md` §8 派生，只重填四槽，不改哲学。**同一份内容换个读者或换个观看距离（课堂投影 ↔ 会议室屏幕），方言也可能换**——身份证随册重写，不要从上一册复制。

### 0.1 方言可被内容否决

**身份证描述的是语法，不是用法。** 方言在形态清点（`form-routing.md`）之后才落笔，它的任务是把每页的形态画得一致、画得准确，而不是规定这页该干什么。

裁决只有一条：**形态 vs 方言，形态赢。** 方言装不下某个形态时，按顺序试三档，别一步跳到"改内容"：

1. **改语法**（首选）：同一形态换实现手段。禁卡片但需要分块 → 去壳分块（实色块 / 粗线 / 细线三档）；禁彩色小字但需要强调 → 块面反白、加粗、加大字号。
2. **改密度**：密度是形态的函数，不是方言的常量。演练页本来就该密，讲授页本来就该疏——同一册里两种密度并存是正常的，不算破格。
3. **换方言**（最后）：内容根本装不进去时换，例如同一批内容从"董事会评审"改到"三年级课堂"，密度、字号、场色全部要换。**换方言要整册换，不能在册内混用**——镣铐可以在开工前换一副，开跳之后不许换。

写进 DESIGN.md 的形态冲突必须留痕：`冲突：X 形态要求分块，方言禁卡片 → 处置：去壳分块（实色 > 3px > 1px），未加圆角`。没有留痕的"破格"一律视为失控。

## 1. 六行本册设计系统（先定这个，再谈页面）

```
排印系统：重压 / 反压 / 单一字重   ← 三选一
标题制度：论证页=结论句；扉页=命名；引语=宣言
对比主轴：尺度 / 字重 / 色彩 / 留白   ← 只选一个
结构母题：（Theme DNA 的第四槽，一句话）
色彩角色：底 / 主文字 / 次文字 / 强调（一页一个）/ 语义正负
本册禁区：（写具体样式，不写"避免 AI 感"）
```

这六行决定后面每一页怎么判。没有它们，"好看"只能靠感觉。

## 2. 必填字段

| 字段 | 要求 |
|---|---|
| 画布与网格 | 1280×720；外边距 70；12 列 × 73 + 24 槽；8px 基线；页脚/标题线的固定 y |
| 底场与强调色 | 白 `#FFFFFF` + 黑 `#111111` + 一个主题色，**只有这三个色相**；中间调由墨的不透明度派生，不写灰 hex |
| Theme DNA | 四槽各一句：底场组 / 双声部 / 唯一结构母题 / 节奏温度 |
| Extension Rule | 没有样本可照的页面，只允许改哪些变量（跨度、尺度、图片状态、密度、底场） |
| 色彩池 | 主色板 ≤4 hex + 中性色；语义功能色单独声明；每页面积分配 |
| 字体与 W(S) | 字体栈含回退；**重字面写明用哪个 Black 字族**（`fontWeight` 数字无效）；**中文字体在栈首**，否则 bold 丢失；W(S) 选型；导语-正文差 ≥5–6px |
| 字号阶梯 | 按 typography.md 取桌面型或投影型的一套；单页字号 ≤5 种 |
| 装饰声明 | 渐变/阴影/卡片/图标用或不用；与内置默认值的差异逐条写出 |
| 配图分级 | L1 主视觉 / L2 支撑 / L3 徽标；同一 deck 视觉类型不混用 |
| 图表纪律 | 绘图区透明、直标、语义色、单位/期间/来源贴近标题 |
| 页面映射表 | 每页：序号 / 文件 / **形态** / 页型 / 角色 / 版式占列 / 展品 / 正文预算 / 色彩分配 / 关键约束。**形态列必须排在版式列之前**——先写"这页在干什么"（七种形态，见 form-routing.md），再写"怎么排"。没有形态列的映射表 = 没做形态路由 |

**网格要可被看见**：12 列从 x=70 起，列宽 73、槽 24（第 n 列起点 = 70 + 97n）。4/8 分栏用 364 + 24 + 752；3/9 用 267 + 24 + 849；2×6 用 558 + 24 + 558。多栏页在**槽中线**加 1px 结构线（4/8 在 x=376，3/9 在 x=279，2×6 在 x=570），高度与内容区一致。巨字与内容必须各自占明确列，不能"大概靠左"。

**排列纪律**：编号、题干、选项各占固定列，阅读顺序沿**单轴**（1→6 自上而下）；禁止 1/4、2/5、3/6 的蛇形分栏，那会让眼睛来回跳。表格用列线与对齐建立秩序，不靠缩进或加粗。

**并列结构换页型**：若这一页的内容彼此并列（目录、模块总览、指标快照、能力矩阵），可改用模块网格，见 `modular-grid.md`——判据是"并列还是推进"，一册最多 1–2 次。

## 3. 覆盖声明（合法且必须显式）

内置通用默认值可以被项目宪法覆盖，但必须写出来。常用三条：

```
- 本项目不使用渐变、阴影、发光、3D、装饰卡片/KPI 磁贴；结构由发丝线、留白与字重层级承担。
- 图表直接落在页面底色上，无白色绘图板、≤3 系列末端直标、无色块图例。
- 正文采用 18–22px（覆盖内置参考区间 22–28），对比度 ≥4.5:1 仍为硬线。
```

## 4. 底场、强调色与影像

- **三色纪律（硬约束）**：全册只有 **白 + 黑 + 一个主题色**。中间调一律由黑的不透明度派生（`#111111` + opacity 0.62 / 0.4 / 0.12），或由线宽区分；**不写独立灰 hex，不用灰面做分区**。灰面就是第四色——它一出现，瑞士的"纸面"立刻变成"卡片"。
- **默认底：白 `#FFFFFF`**。深场 = 主题色满版，只用于封面、转折页、答案页。暖纸/米白不做默认，也不作为任何方言的常量。
- **主题色（主题色底与强调色同源，全册一个）**，按内容选：

| 内容气质 | 主题色 | 典型用途 |
|---|---|---|
| 宣言、风险、强主张、文化 | 瑞士红 `#E2231A` | 海报式主张、决策、警示、关键数字 |
| 科技、教育、理性、数据 | 亮蓝 `#0057FF` | 结构、图表、推荐路径、当前段 |
| 活力、儿童、消费 | 亮黄 `#FFD400` | **仅块面**，不作文字；文字用黑 |

主题色同时承担"主题色底"（封面/转折/决策带）与强调色，不另引第二亮色；深场要么主题色本身，要么纯黑 `#111111`。**不要引入 `#0B1F33` 这类"深蓝黑"——那是第四色。** 深青、墨绿、莫兰迪色系同样不是 Swiss 主题色。
- **几何层**：解构几何只允许 1–2 个转折页；矩形、条带、裁切蒙版、叠印；透明度 8–30%；对齐网格；不压字、不承载信息；禁渐变/阴影/3D。**几何必须有构图职责**（切分、遮挡、导流、承托证据）；没有职责就不画，不要用半透明色块当背景框或底板。
- **影像**：页面需要具象情境时，在页面映射表标 L1，并在 DESIGN.md 阶段**询问用户是否用 ImageGen**；同意后统一一种视觉风格，产物存 `assets/`、逐张核对、标注为生成图。插画默认不用；图库水印图、杂志扫描页不用。

## 5. 不变量与品质分开写

**不变量（违反即返工）**：可读、无损、真实、语义、可编辑、推进。逐页可查，与风格无关。

**品质（按本册声明的系统判定）**：一致、标题制度、尺度与字重（一个 W(S)、一页一个极值轴）、动线（20% 缩略图第一眼）、节奏（≥2 次尺度突变，无连续 3 页同构）。

**不在不变量里的**：填满画布、四角均衡、留白率、视觉检测器的"失衡"提示。见 vlm-review.md。

## 6. 审美复核清单（交付前）

- [ ] 六行设计系统齐备，且逐页真的按它执行；
- [ ] 每页一个视觉锚点；20% 缩略图第一眼落在计划元素上；
- [ ] 没有连续 3 页同构；全册 ≥2 次由论证驱动的尺度突变；
- [ ] 图表：绘图区透明、无卡片、≤3 系列无图例、单位/来源贴近标题；
- [ ] 全册一个 W(S)；导语比正文大 ≥5–6px；正文行宽 45–68 字符；
- [ ] **标题压得住页面**：T ≥56（投影 ≥60）；D ≥96 时级比 D/T ≤4×；标题真的落在 900/Black 字族上，不是"48px + bold"；
- [ ] 语义色未漂移；**全册只有白/黑/主题色三个色相**，没有灰面、没有第四个 hex；强调色常规页 ≤10%、hero ≤20%；
- [ ] 文字全可编辑（未烤进 SVG/图片）；illustrative 已标注；
- [ ] 留白能说明它围绕哪个焦点；没有为过检添加的内容或装饰；
- [ ] VLM 偏离已登记（页号、原话、判定、理由、代价）。

## 7. 偏离记录格式

```
偏离：P04 瀑布页保留浮动柱下方空白（VLM 报"失衡"）。
理由：瀑布语义要求柱体悬空，空白由基线承托，属结构空白。
代价：视觉检查不通过；人工目视确认基线与直标完整。
```
