# 风格模板 · 派生新风格与写项目宪法

两份东西共用一个模板：一份**风格文件**（住 `styles/`，跨项目复用），一份**项目宪法 DESIGN.md**（住项目目录，本项目最高权威）。

## 1. 派生方法论（七步）

1. **找最近的现有风格当底** —— 默认从 `folio.md` 派生，不从头写。
2. **只重填 Theme DNA 四槽** —— 底场组 / 双声部 / 唯一结构母题 / 节奏。四槽之外能不改就不改。
3. **真实流派名三测**（见 §3），括号位必须是真名。
4. **`use_when` 写读者 + 观看距离 + 证据形态**，不写题材标签（"董事会"是读者，"金融"是题材）。
5. **逐条写铁律互动** —— 七条里每一条，本风格是收紧还是照常。写不出互动说明它只是皮肤。
6. **Adoption 纪律** —— 选中即整套采纳，**禁止与 folio 混搭**。需要混的部分说明它其实属于项目宪法，不属于风格。
7. **实测才入库** —— 在真实项目最难的一页跑通，状态标 `experimental`；有一次完整运行记录才升 `stable`。

状态写在文件头部：`status: experimental | stable`。

## 2. 风格文件九节模板

```markdown
# <风格 id> · <中文名>

> status: experimental
> 派生自 folio：继承 <X>，覆盖 <Y>。覆盖只能收紧，不能取消铁律。

## 1. 风格身份证
风格：<哲学层 × 流派层（真实流派名 · 代表作）>
不是：<三个它不是什么>
三件不变：<三件>
冲突裁决：<A > B > C>

## 2. Theme DNA（四槽）
1. 底场组：…
2. 双声部：…
3. 唯一结构母题：…
4. 节奏：…

## 3. 色彩（语义色板表 + 面积分配 + 中间调派生规则）
## 4. 排印（双声部取值、字族栈、W(S) 预设、介质最小值）
## 5. 网格（列数 / 槽宽 / 基线单位 / 外边距）
## 6. 影像（媒介、分级、裁切、构图）
## 7. 图表与表格
## 8. 禁忌 + 铁律互动表（七条逐条）
## 9. Extension Rule（无需请示可改的变量清单 + 禁改清单）
```

字段纪律：
- 每一节必须有**数字**。写不出数字的节，说明这个风格还没想清楚，不要入库。
- 禁忌不能只写"不要丑"，要能指认（哪个元素、出现在哪、长什么样）。
- Extension Rule 清单外即偏离，须记录（改了什么 / 为什么 / 代价）。

## 3. 真实流派名三测

风格身份证括号位是**召回锚点**，不是文案。写自造场景词（`课堂投影`、`高级感`），模型调不出参照系，等于没写。

1. **可检索** —— 设计史上有独立条目或公认命名，不是本包发明的词。
2. **有代表作** —— 能指到一套具体系统或作品（慕尼黑 1972 视觉系统、Brockmann 的 Beethoven 海报、Vignelli 的纽约地铁图）。
3. **给的是系统不是皮肤** —— 必须能落到网格、字号、色彩编码、信息图形四件事上。

合格名举例：`Otl Aicher · Munich 72`（公共信息 / 远距离识别）· `Boardroom Editorial`（Brockmann 海报系统）· `Vignelli · Unimark`（纯信息层级）· `Bauhaus · De Stijl`（几何母题 + 原色）· `Bento（Swiss 化）`（模块网格）。
不合格：`（课堂投影）`（海图尺）（杂志感）（高级商务）。

允许的组合：`瑞士网格 × 公共信息（Otl Aicher · Munich 72）` —— 前半是哲学层，括号是流派层，两层都要是真名。

## 4. 项目宪法 DESIGN.md 模板

命中风格后，为每个项目写一份。它是**本项目的最高权威**，排在风格文件之前（优先级链：用户 > 形态 > DESIGN.md > 风格）。

```markdown
# DESIGN.md · <项目名>
风格身份证：瑞士网格 × <流派层（真名）>；不是 <三个不是>；冲突裁决：<链>
风格依据：references/styles/<id>.md（唯一风格来源）
表面：<deck / poster / web / canvas>；尺寸与网格：<数字>
信号色：<值>；理由：<内容 / 受众>
覆盖声明：<本项目对铁律与风格的显式覆盖，逐条写>
色彩池：paper / ink / signal 三个色相 + 中间调派生方式（不写灰 hex）
字体与 W(S)：<骨架族> / <显示族> / <中文栈首>；字号阶梯 <D/T/L/B/C/A>
母题：<唯一结构母题>；影像：<媒介> L1 ≤3 页
页面映射表：
| # | 文件 | 形态 | 版式（占列） | 视觉锚点 | 正文预算 | 关键约束 |
覆盖与偏离记录：（改了什么 / 为什么 / 代价）
```

**页面映射表必须先有"形态"列，再有版式列。** 没有形态列 = 没做形态路由（见 `../form-routing.md`）。

命中外部生成引擎预设、不允许另建 DESIGN.md 时，改落 `ART-DIRECTOR.md`（风格增量单），六行：外观取自 / 结构取自 / 网格 / 声部 / 影像 / 禁区。绕开命名冲突，不硬刚门禁。
