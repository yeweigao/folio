# 方言模板

> status: experimental | stable
> 派生自 `folio`：继承 \_\_\_；覆盖 \_\_\_；不取消任何铁律。

一份方言文件必须能独立回答：它借什么、拒什么、留下什么瑞士、什么时候用、数字是多少。
写不出数字的节，说明这个方言还没想清楚，不要入库。

## 0. 融合契约

```
借：<一个可指认的系统：网格 / 字制 / 色制 / 图形语法>
拒：<该运动里与 Folio 冲突的部分>
留下：<网格、左齐、留白、可读性中至少三条>
读者：<谁>
距离：<0.5m / 3m / 10m / 30m>
证据形态：<文字 / 数据 / 照片 / 实物 / 界面>
何时不用：<三种情况>
```

**真实流派名三测**：可检索；有代表作；给的是系统不是皮肤。自造场景词（“高级商务”“课堂投影”）不算锚点。

## 1. 身份证

```
风格：瑞士网格 × <流派层（真名 · 代表作）>
不是：<三个它不是什么>
三件不变：<三件>
冲突裁决：<A > B > C>
```

## 2. DNA 四槽

1. **底场组**：纸、墨、信号；深场/亮场如何反转；纸占比。
2. **双声部**：主张声部与证据声部各用什么；角色边界。
3. **唯一结构母题**：一个可指认的标记系统；出现频率。
4. **节奏**：精读 ↔ 转折 ↔ 爆发如何交替；同一语法连续几次换。

## 3. 色彩

- 语义色板表：角色 / 值 / 用途 / 面积上限。
- 中间调派生：`ink + opacity` 的具体档位。
- 信号色：全篇一个；低对比底上的替换值。
- 若用功能类别色：写清“哪个色 = 哪一类”，并说明它不承担装饰。

## 4. 排印

- 字族与角色：展示 / 正文 / 标签数字；中文栈首；回退栈。
- 字号阶梯：给出具体值；介质最小值。
- 字重轴：一个 `字号 → 字重` 映射；不允许第二种映射。
- 行宽、行高、对齐、标点、数字格式。
- 禁用：默认 Inter、彩色小字、换字体做层级（除非本方言明确把换字体作为材料，且写明边界）。

## 5. 网格

- 列数 / 槽宽 / 外边距 / 基线单位；给出可计算的公式。
- 元素吸附规则：什么必须落在列线与基线上。
- 分块语法：实色块 > 3px 线 > 1px 线（或本方言自己的三档）。
- 允许的跨度组合；禁止的等分。

## 6. 图像

- 媒介：照片 / 双色 / 网点 / 几何图形 / 界面截图；全篇一种或两种，写明。
- 裁切：对齐哪条列线；主体偏置；出血规则。
- 图注与来源：位置、字号、写法。
- 占位规则：没有真实材料时放什么，不放什么。

## 7. 数据与图表

- 允许的图型；禁止的图型（饼/环/仪表盘/双轴/3D 默认禁）。
- 基线、单位、时期、来源的位置。
- 直标规则；图例规则；表格线宽。
- 演示数据标记方式。

## 8. 母题、签名动作、失败模式与七律

**母题**：<全篇唯一的标记系统；一句话>

**签名动作**：<一个能被一句话描述、只属于本方言的构图动作；不是形容词>

**失败模式**：<本方言被简化成皮肤时的样子；可指认>

**一句练习**：<用最小材料练这个动作的一句话题目>

**禁忌**：能指认的元素、位置、样子，不写“不要丑”。

**七律互动表**：

| 铁律 | 本方言是收紧、照常，还是有限豁免 |

| 1 内容先于形式 | |
| 2 网格 | |
| 3 一套排印系统 | |
| 4 三种声音 | |
| 5 装饰挣位 | |
| 6 诚实 | |
| 7 可读性 | |

## 9. Extension Rule

无需请示即可改的变量：跨度、尺度极差、场的温度（纸/墨/信号满版）、密度、图片数量、母题的疏密。

必须请示或记录的：新增字族、新增色相、换母题、引入新图型、改变双声部角色。

## 10. 验收样本

在真实项目最难的一个单位上跑通，记录：

- 项目 / 表面 / 尺寸；
- 该单位为什么难；
- 方言的哪三个决定让它成立；
- 哪里被迫偏离，代价是什么；
- 日期与运行者。

有一次完整运行记录，`status` 才能从 `experimental` 升 `stable`。

## 附：项目宪法 DESIGN.md 模板

项目宪法住项目目录，是本项目最高权威。优先级：用户 > 内容与事实 > DESIGN.md > 方言 > 默认。

```markdown
# DESIGN.md · <项目名>

风格身份证：瑞士网格 × <流派层（真名）>；不是 <三个不是>；冲突裁决：<链>
方言依据：references/styles/<id>.md（唯一方言来源）
表面：<deck / poster / web / canvas / handbook>；尺寸与网格：<数字>
读者与距离：<谁 / 多远 / 多久>
信号色：<值>；理由：<内容 / 受众>
覆盖声明：<对铁律与方言的显式覆盖，逐条写>

色彩池：paper / ink / signal + 中间调派生方式（不写灰 hex）
字体与字重轴：<展示族> / <正文族> / <标签数字族>；中文栈首；阶梯 <D/T/L/B/C/A>
母题：<唯一结构母题>
图像：<媒介>；上限 <n> 个单位；图注与来源规则
数据：<来源 / 基线 / illustrative 标记>

单位映射表：
| # | 单位 | 形态 | 版式（占列） | 视觉锚点 | 字数预算 | 关键约束 |

偏离记录：
- <单位>：改了什么 / 为什么 / 代价
```

**单位映射表必须先有“形态”列，再有版式列。** 没有形态列 = 没做形态路由。

引擎不允许另建 DESIGN.md 时，改写 `ART-DIRECTOR.md`（风格增量单），六行：外观取自 / 结构取自 / 网格 / 声部 / 影像 / 禁区。绕开命名冲突，不硬刚门禁。
