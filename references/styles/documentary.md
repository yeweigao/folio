# documentary · 纪实

> status: stable
> 派生自 `folio`：继承 12 列、三声、左齐、可读性；覆盖为照片优先、图注制度、来源与地图。

## 0. 融合契约

```
借：FSA / Life / 马格南的纪实传统——现场照片、图注、人物与地点、证据链
拒：摆拍假现场、无出处的图、滤镜怀旧、把苦难做成气氛
留下：网格、左齐、留白、可读性、一个信号
读者：研究、公益、田野报告、深度报道、档案展览的读者
距离：0.5–3m（屏幕 / 手册 / 展板）
证据形态：照片 + 图注 + 地图 + 数据 + 引文
何时不用：纯形象页、时装、儿童教学、强主张海报
```

## 1. 身份证

```
风格：瑞士网格 × 纪实摄影（FSA / Life / 马格南 · 图片叙事）
不是：旅行杂志、国家地理仿作、滤镜怀旧、公益苦难海报
三件不变：照片优先 · 五要素图注 · 来源可指回
冲突裁决：证据完整 > 照片张力 > 信息密度
```

## 2. DNA 四槽

1. **底场组**：纸 `#FFFFFF`（印刷 `#F7F3E8` 暖纸）；墨 `#151515`；信号柠檬黄 `#FFE500`。深场 = 墨满版；黄场 = 信号满版，黑字。
2. **双声部**：主张声部 = 衬线标题（人物、地点、判断）；证据声部 = 无衬线正文 + 图注 + 来源 + 数据。
3. **唯一结构母题**：**图注块 + 来源行**——每张照片下方一个固定结构的图注块（谁 / 什么 / 哪里 / 何时 / 来源）；全篇一个格式。
4. **节奏**：主导照片页 ↔ 文本/数据页 ↔ 多图证据页 ↔ 深场引文页。主导照片不超过单位总数的 1/3。

## 3. 色彩

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| Paper | `#FFFFFF` / `#F7F3E8` | 阅读底 | ≥50% |
| Ink | `#151515` | 字、线、场 | 结构 |
| Signal | `#FFE500` | 关键引文、当前地点、一个数字 | ≤10% |
| Muted | Ink + 0.62 | 图注、来源 | 小 |
| Rule | Ink + 0.14 | 图注分隔、表格线 | 线 |

暖纸是材料，不是第四色相；屏幕上默认纯白。照片可以是彩色或黑白，但全篇一种。黄只做块面与标记，不做小字。

**照片压暗层（scrim）**：只在深色照片上放白字时使用；单层、中性黑、透明度 ≤0.55；必须能解释"为了可读"；不允许渐变到透明。

## 4. 排印

- **展示**：`Georgia` / `Source Serif 4` / `Noto Serif SC`；标题 32–64；引文 24–32。
- **正文**：`Arial Narrow` / `Helvetica Now` / `Noto Sans SC`；16–20；行高 1.65。
- **图注 / 来源**：同正文族 12–13；muted；不缩到 8px。
- **阶梯**：12 / 13 / 16 / 20 / 24 / 32 / 46 / 64。
- **图注五要素**：谁 / 什么 / 哪里 / 何时 / 来源。缺一项就标"未知"，不猜。
- **禁**：全大写长句；图注用斜体代替结构；把来源藏进页脚小字。

## 5. 网格

- 12 列；内容宽 = `12c + 11g`；基线 8px（屏幕）/ 28px（A4）。
- 主导照片占 8–12 列，高度 ≥ 内容区 40%；图注占照片起始列起的 3–4 列。
- 多图页：一张主导 + 2–3 张辅助；辅助图不等分，按重要性给 4 / 3 / 3 列。
- 地图占 6–12 列；比例尺与指北针必须出现。
- **禁止**：等分九宫格照片墙；照片做背景壁纸；图注与照片不同基线。

## 6. 图像

- 全篇一种媒介：彩色纪实 / 黑白纪实 / 双色。选一。
- 不摆拍、不合成、不 AI 生成；不用图库图冒充现场。
- 裁切保留现场关系（人物与环境），不做无理由的特写。
- 图注与来源是图像的一部分，不是附属品；没有来源的图不用。

## 7. 数据

- 照片讲人，图表讲量；两者不互相替代。
- 图表透明绘图区，直标，无图例；基线、单位、时期、来源齐全。
- 地图：比例尺、指北针、来源；地点标记全篇一套。
- 引文必须有说话者、身份、时间、来源；不改写引文。
- 演示数据标 `illustrative`。

## 8. 母题、签名动作、失败模式与七律

**母题**：图注块 + 来源行。全篇一个格式；没有图注的照片视为装饰。

**签名动作**：一张真实照片占主导；图注写全“谁 / 何处 / 何时 / 何事 / 来源”；地图与时间线只做证据索引；暖纸或纯白。

**失败模式**：摆拍或 AI 假照片冒充现场；图注只写“图片来源”；照片当壁纸。

**一句练习**：选一张真实照片，写 5 行图注（人物 / 地点 / 时间 / 事件 / 许可），照片 8 列、图注 4 列；不修图。

**禁忌**：滤镜怀旧；摆拍；无出处；把人物当气氛；等分照片墙；图注只写"图：网络"；用黄色做苦难高亮；把来源缩到 8px。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 照片与证据决定版面，不是相反 |
| 2 网格 | 图片与图注都吸附列线 |
| 3 排印 | 衬线标题 + 无衬线正文 + 图注 |
| 4 三声 | 纸 / 墨 / 柠檬黄；暖纸是材料 |
| 5 装饰 | 只允许图注块、来源行、地图符号 |
| 6 诚实 | 五要素图注；来源可指回；不摆拍 |
| 7 可读 | 正文 ≥16；图注 ≥12；scrim 后白字 ≥4.5:1 |

## 9. Extension Rule

无需请示：主导照片比例、辅助图数量、图注列宽、纸张冷暖（印刷）、地图位置。

必须记录：使用彩色照片、增加第二种图注格式、引入双色处理、把照片做成背景。

## 10. 验收样本

- 项目：田野调查报告（A4，40 页）。
- 表面：handbook；印刷暖纸 `#F7F3E8`；信号黄；彩色纪实照片。
- 难点：12 个村庄、36 张照片、4 张地图、8 组数据，不能变成旅行画册。
- 成立原因：每张照片五要素图注；主导照片每章一张；地图统一比例尺；数据只做同基线横条；黄色只标当前村庄。
- 结果：36/36 图有来源；无滤镜；无等分照片墙；任意数据可指回表格。
