# editorial · 编辑论证

> status: stable
> 派生自 `folio`：继承 12 列网格、三声、左齐、单一母题；覆盖为"动作标题 + 证据 + 决策带"的论证制度，并引入一个衬线展示声部。

## 0. 融合契约

```
借：Brockmann 的海报系统 × 年报 / 董事会编辑制度——动作标题、证据、决策带、页码
拒：杂志拼贴、首字下沉装饰、彩色小字、引号墙
留下：网格、左齐、留白、可读性、一个信号
读者：董事会、评审会、研究者、深度报道读者
距离：1–3m（桌面 / 会议室屏幕）
证据形态：文字 + 数据 + 少量纪实照片
何时不用：纯形象页、时装、儿童教学、强主张海报
```

## 1. 身份证

```
风格：瑞士网格 × 编辑论证（Brockmann · Neue Grafik × 年报制度）
不是：咨询公司模板、麦肯锡页、杂志翻页、彩色信息图
三件不变：动作标题制度 · 12 列 · 衬线展示 × 无衬线正文
冲突裁决：论证完整 > 标题长度 > 图像面积
```

## 2. DNA 四槽

1. **底场组**：纸 `#FFFFFF`（印刷可用 `#F7F5F0`，声明的纸）；墨 `#0B1B2B`（蓝黑）；信号 `#C83024`；深场 `#071C2C`（墨的满版，不是新色相）。
2. **双声部**：主张声部 = 衬线展示（动作标题、章节扉页、一个关键数字）；证据声部 = 无衬线正文 / 标签 / 表格 / 图注。
3. **唯一结构母题**：**决策带**——每个论证单位底部一条全宽墨线或实色带，写"所以，要做什么"。
4. **节奏**：论证页（密）↔ 单一证据页（疏）↔ 章节扉页（深场）↔ 决策页（信号带）。连续论证不超过三页。

## 3. 色彩

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| Paper | `#FFFFFF` / 印刷 `#F7F5F0` | 阅读底 | ≥50% |
| Ink | `#0B1B2B` | 标题、正文、线 | 结构 |
| Deep | `#071C2C` | 章节扉页、封面深场 | ≤25% |
| Signal | `#C83024` | 决策带、风险、关键数字 | ≤12% |
| Muted | Ink + 0.60 | 来源、图注、次级标签 | 小 |
| Rule | Ink + 0.14 | 表格线、分隔线 | 线 |

不使用青色。深场不是"再加一个蓝"，是墨的满版。信号红只承担判断与行动，不承担装饰。

## 4. 排印

- **展示**：`Source Serif 4` / `Georgia` / `Noto Serif SC`；只用在动作标题、章节扉页、一个关键数字。Bold 700。
- **正文**：`Helvetica Now` / `Archivo`（Arial 仅作回退）/ `Noto Sans SC`；Regular 400，行高 1.6–1.75。
- **标签 / 数字**：同正文族的 Medium 500 或表格数字；不用等宽，除非内容是代码。
- **阶梯**：13 / 16 / 20 / 24 / 32 / 46 / 64 / 88。动作标题 32–46（跨 8–12 列）；导语 24；正文 16–20；图注 13；关键数字 64–88。
- **动作标题**：一个完整判断句，不是名词短语。全篇标题连起来应能读成摘要。
- **行宽**：正文 6–8 列；45–70 字符；CJK 25–36 字。
- **禁**：标题居中；标题里一个斜体词；全大写长标签；用颜色区分标题层级。

## 5. 网格

- 12 列；内容宽 = `12c + 11g`；屏幕基线 8px；A4 基线 28px。
- 动作标题占 8–12 列；导语与正文占 6–8 列；证据图占 6–12 列；决策带全宽。
- 决策带高度 = 2 个基线单位；带内文字 16–20，左对齐；右侧可放一个负责人 / 日期 / 页码。
- 每页留一个"呼吸列"：至少 2 列不被正文占用，除非页面是满版证据。
- **禁止**：三栏等分正文；标题与正文同宽同重；页脚堆三行小字。

## 6. 图像

- 纪实黑白或单色 duotone；全篇一种。
- 图像不超过单位总数的 1/3；单页一张，占 6–12 列；不做背景壁纸。
- 图注放图像下方，13px，muted；来源与图注分开写。
- 人物照片必须能指回来源；不用 AI 假人物。

## 7. 数据

- 每页最多一个主图；图前有动作标题，图后有"所以"。
- 绘图区透明，末端直标，无图例，无白板。
- 表格：开放横线，数字右对齐，单位在表头，合计行用 1px 墨线。
- 关键数字用展示声部 64–88，配一行来源与基线；不把数字放进彩色圆。
- 演示数据标 `illustrative`，并给算式。

## 8. 母题、签名动作、失败模式与七律

**母题**：决策带。每个论证单位都有；扉页与纯图页可以没有，但全篇覆盖率 ≥70%。

**签名动作**：动作标题写完整判断句；底部一条全宽决策带写“所以，要做什么”；两者之间只放一个主图或一张表。

**失败模式**：做成咨询报告——名词短语标题、三栏正文、决策带退化成装饰线、来源缩成 8px。

**一句练习**：把一个名词短语标题改成“因为…所以…”的判断句，把结论压进 2 基线高的决策带；删掉其余强调。

**禁忌**：咨询模板的"三列图标 + 标题"；彩色小字标签；标题下加一条装饰短线；每页右下角放同一个装饰箭头；把来源写成 8px 灰色；用青色做"科技感"。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 论证结构赢；宁可加一页，不压成三栏 |
| 2 网格 | 12 列；决策带必须全宽对齐 |
| 3 排印 | 两个阅读字族（衬线展示 + 无衬线正文）+ 一个标签角色 |
| 4 三声 | 纸 / 墨 / 红；深场是墨的满版 |
| 5 装饰 | 只允许决策带与发丝线；无其他装饰 |
| 6 诚实 | 每个数字有来源与基线；标题不夸大 |
| 7 可读 | 正文 ≥16；投影 ≥26；对比 ≥4.5:1 |

## 9. Extension Rule

无需请示：标题占列、证据图高度、决策带位置（底部 / 右侧）、密度、纸张冷暖（印刷）。

必须记录：新增字族、引入第二种图表、把决策带换成别的母题、使用彩色照片。

## 10. 验收样本

- 项目：董事会战略评审 deck（18 页）。
- 表面：deck 1280×720；深场章节扉页；信号红决策带。
- 难点：一页要同时放三年财务对比、三个判断、一个决策，且不能变成表格墙。
- 成立原因：动作标题先给判断；主图只留一条基线；决策带承担"所以"；来源与口径在图下 13px。
- 结果：18/18 页有动作标题；15/18 页有决策带；无饼图、无双轴、无独立灰 hex。
