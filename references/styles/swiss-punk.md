# swiss-punk · 瑞士朋克

> status: experimental
> 派生自 `folio`：继承 12 列、三声、左齐、可读性；覆盖为一次旋转、一次叠印、一次裁切。

## 0. 融合契约

```
借：Weingart / Greiman 的排印实验——旋转、叠印、层、裁切、报纸纸
拒：假做旧、故障艺术、勒索信拼字、安全别针朋克戏服、不可读正文
留下：网格、左齐、留白、可读性、一个信号
读者：文化节、音乐、独立出版、实验展览的观看者
距离：0.5–3m（海报 / 屏幕 / 小册子）
证据形态：一句话 + 一张图 + 日期地点
何时不用：董事会、教学、长篇论证、公共导视
```

## 1. 身份证

```
风格：瑞士网格 × 朋克排印（Weingart · Greiman / Emigre）
不是：Grunge 滤镜、赛博朋克、拼贴垃圾、复古朋克海报
三件不变：一个手势 · 正文可读 · 网格仍在
冲突裁决：可读性 > 手势 > 气质
```

## 2. DNA 四槽

1. **底场组**：纸 `#FFFFFF` 或报纸纸 `#F2F0EB`；墨 `#111111`；信号红 `#E2231A`。蓝 `#0057FF` 只在声明的叠印破格里出现，不作为第二信号。
2. **双声部**：主张声部 = grotesque Black 或 condensed 巨字（一个词、一个日期）；证据声部 = grotesque Regular（正文、图注、来源）。正文永不旋转。
3. **唯一结构母题**：**一个手势**——旋转 / 叠印 / 裁切，三选一，一个单位只用一次。全篇可以换手势，但不能在同一单位叠加两个。
4. **节奏**：手势页 ↔ 安静文本页 ↔ 图像页 ↔ 报纸场转折。手势页不超过单位总数的 1/3。

## 3. 色彩

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| Paper | `#FFFFFF` / `#F2F0EB` | 阅读底 | ≥50% |
| Ink | `#111111` | 字、线、场 | 结构 |
| Signal | `#E2231A` | 一个词、一条线、一个日期 | ≤15% |
| Overprint blue | `#0057FF` | 只在与红叠印处出现 | 破格 |
| Muted | Ink + 0.60 | 来源、图注 | 小 |

**叠印破格**：红与蓝以正片叠底相交，交界近黑；蓝只存在于交叠区域，不单独铺场。一个作品最多一次。没有叠印需求时，只有红一个信号。

## 4. 排印

- **展示**：`Helvetica Black` / `Archivo Black` / `Druk`；或 condensed `Oswald` / `Archivo Narrow`。字号 64 / 96 / 128 / 160。
- **正文**：`Helvetica Now` / `Archivo`（Arial 仅作回退）/ `Noto Sans SC`；16–20；行高 1.55。
- **阶梯**：12 / 14 / 16 / 20 / 28 / 40 / 64 / 96 / 160。
- **旋转**：只用于展示声部；最多 90° 或 -8°；一个单位一次；旋转后必须仍可读。
- **禁**：正文旋转；勒索信式逐字换字体；假复印噪点；全大写正文；用一个以上手势压同一信息。

## 5. 网格

- 12 列；内容宽 = `12c + 11g`；基线 8px。
- 网格仍然成立：旋转元素的原点落在列线交点；裁切边对齐列线或画幅边。
- 一个单位允许一个元素越出网格，但正文与其他信息仍在网格上。
- 叠印区域不超过画幅 1/4；不压正文。
- **禁止**：整页旋转；把网格完全取消；用错位代替构图。

## 6. 图像

- 高对比黑白照片、真实复印/网点扫描；全篇一种。
- 一张图；不做多层图像拼贴；不做故障切片。
- 图像可以被裁切或旋转，但保留一个可读主体。
- 不用 AI 假照片；不用假做旧纹理。

## 7. 数据

- 数据保持安静：不要旋转、不要叠印、不要做旧。
- 日期、地点、票价用证据声部；一个关键数字可以用展示声部。
- 图表只在必要时出现；透明绘图区、直标、来源齐全。
- 演示数据标 `illustrative`。

## 8. 母题、签名动作、失败模式与七律

**母题**：一个手势（旋转 / 叠印 / 裁切），一个单位一次。

**签名动作**：一次旋转 / 叠印 / 裁切，只发生在标题或一个图像上；正文回到严格网格；叠印用正片叠底。

**失败模式**：假做旧、故障装饰、全页旋转、不可读正文；破格没有声明。

**一句练习**：选一个标题旋转 7° 或裁掉 1/4，与一张图叠印；正文保持 12 列左齐；只做一次。

**禁忌**：假做旧；故障错位；勒索信拼字；安全别针与骷髅；正文旋转；整页只有一个手势没有信息；用红色涂满全页；把"朋克"当"不排版"。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 手势必须服务一个词或一个日期，不服务气氛 |
| 2 网格 | 网格仍在；一个元素可以越界 |
| 3 排印 | 展示可旋转；正文永不旋转 |
| 4 三声 | 纸 / 墨 / 红；蓝只在叠印破格里 |
| 5 装饰 | 一个手势；其余回到默认 |
| 6 诚实 | 日期、地点、票价、来源必须真实 |
| 7 可读 | 正文 ≥16；旋转展示仍可读；对比 ≥4.5:1 |

## 9. Extension Rule

无需请示：手势三选一、旋转角度（90° / -8°）、裁切比例、报纸纸冷暖、红块面积。

必须记录：一个单位用两个手势、引入蓝色叠印、使用第二张图、把正文旋转。

## 10. 验收样本

- 项目：独立音乐节海报（A2，3m 看距）。
- 表面：poster；报纸纸 `#F2F0EB`；红 `#E2231A`；黑白照片。
- 难点：乐队名、日期、地点、票价、二维码，不能变成信息堆。
- 成立原因：乐队名旋转 90° 贴边；日期用红；照片只占 6 列；票价与二维码安静地落在右下网格；正文未旋转。
- 结果：3 秒读出乐队与日期；一个手势；正文 16pt 可读。
