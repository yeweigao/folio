# public-info · 公共信息

> status: stable
> 派生自 `folio`：继承 12 列、三声、左齐、可读性；覆盖为远距识别、功能色、象形符号与双语音标。

## 0. 融合契约

```
借：Otl Aicher · Munich 72 的公共信息系统——功能色、象形符号、远距字、路线与进度
拒：装饰插画、无映射的多色、拟物图标、儿童贴纸
留下：网格、左齐、留白、可读性、一个信号
读者：学生、乘客、访客、跨语言人群
距离：3–10m（投影 / 海报 / 导视），局部 0.5m（手册）
证据形态：规则、路线、时刻、步骤、对照
何时不用：董事会论证、时装、纪实长文
```

## 1. 身份证

```
风格：瑞士网格 × 公共信息（Otl Aicher · Munich 72）
不是：幼儿园课件、机场模板、彩色信息图、图标墙
三件不变：单一 grotesque · 功能色有映射 · 象形符号全篇一套
冲突裁决：识别距离 > 信息密度 > 气质
```

## 2. DNA 四槽

1. **底场组**：纸 `#FFFFFF`；墨 `#111111`；信号柠檬黄 `#FFD400`（默认）或亮蓝 `#0057FF`。深场 = 墨满版，字反白。
2. **双声部**：主张声部 = 单一 grotesque 的 Bold/Black（指令、数字、阶段词）；证据声部 = 同族 Regular（说明、时刻、图注）。
3. **唯一结构母题**：**进度尺**——12 格刻度，标出当前阶段；或**路线线**——2px 的路径与节点。全篇择一。
4. **节奏**：指令页（大字 + 少字）↔ 练习页（题 + 作答位）↔ 对照页（✓/✗）↔ 总结页（回收）。同一语法连续不超过两页。

## 3. 色彩

**默认模式**（教学、活动、一般公共信息）：纸 / 墨 / 信号黄。黑字压黄 13.2:1；黄只做块面，不做小字。

**导视模式**（真实寻路、安全、分类）：纸 / 墨 + 功能色组，最多三色，必须写映射：

| 功能 | 值 | 映射 |
|---|---|---|
| 停止 / 禁止 / 风险 | `#E2231A` | 只用于禁止与危险，不做强调 |
| 通行 / 安全 / 正确 | `#00693E` | 只用于许可与安全 |
| 信息 / 方向 / 当前 | `#0057FF` | 只用于路径与信息点 |

功能色不是第二个信号：它们只在导视模式出现，且每个色只有一个语义。没有映射就不许用。

中间调：Ink + 0.62 / 0.12；反白字 White / White + 0.78。

## 4. 排印

- **字族**：一套 grotesque。`Univers` / `Helvetica Now` / `Archivo`（Arial 仅作回退）；中文 `PingFang SC` / `Noto Sans SC`。不引第二套。
- **阶梯**：16 / 20 / 24 / 32 / 46 / 64 / 112。投影正文 ≥26；标题 46–64；巨字 112。
- **字重**：Regular 400 正文 / Bold 700 指令 / Black 900 数字与巨字。
- **远距规则**：3m 看距标题 ≥46；10m 看距主字 ≥112；一行不超过 12 个汉字或 24 个拉丁字符。
- **双语**：主语言在上，副语言在下；副语言小 2 档、muted；不并排挤在一行。
- **禁**：全大写长句；细体大字；用彩色小字做指令；一套页面三种字族。

## 5. 网格

- 12 列；内容宽 = `12c + 11g`；基线 8px；象形符号画在 24 / 32px 模块上。
- 进度尺：12 格，每格 = 1 列宽；当前格用信号色实心，其余 1px 墨线。
- 路线线：2px；节点 8px 实心；转角 90° 或 45°；不画曲线。
- 指令区最多占 8 列，右侧留 4 列给图示或作答位。
- **禁止**：九宫格；图标与文字不同基线；箭头粘在文字上。

## 6. 图像与符号

- 象形符号：几何化，2px 统一描边，圆角 0；只画动作与对象，不画气氛。
- 全篇一套符号；同一动作只有一个符号。
- 照片只在"真实场景需要被识别"时使用；不加滤镜；图注写地点与来源。
- 不用 emoji、不用彩色 3D 图标、不用混合风格的图标包。

## 7. 数据

- 时刻表 / 步骤 / 规则用表格或单轴列表；数字右对齐或统一左对齐。
- 进度用刻度条 + 数字，不用圆环；比例用长度，不用饼。
- 颜色只承担分类或状态，不承担装饰；每个色有映射表。
- 演示数据标 `illustrative`。

## 8. 母题、签名动作、失败模式与七律

**母题**：进度尺或路线线，二选一，全篇一个。

**签名动作**：用 12 格进度尺或 2px 路线线贯穿全篇；当前状态用信号色实心格 / 节点；其余信息只用一个 grotesque 的两档字重。

**失败模式**：做成幼儿园课件或机场图标墙——彩色图标、无映射的功能色、双语挤一行、每页三种箭头。

**一句练习**：把一页步骤压成 12 格进度尺 + 一句指令 + 一个作答位；不加图标。

**禁忌**：幼儿园贴纸；彩色图标墙；一套页面三种箭头；红绿同时用于非安全语义；把功能色当装饰；用渐变做"现代感"；双语句子挤成一行。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 识别距离决定字号，字号决定密度 |
| 2 网格 | 12 列 + 8px 模块；符号必须落在模块上 |
| 3 排印 | 只许一套 grotesque；双语是两档，不是两族 |
| 4 三声 | 默认三声；导视模式的功能色必须有映射 |
| 5 装饰 | 只允许进度尺 / 路线线 / 象形符号 |
| 6 诚实 | 时刻、规则、来源必须真实；示例标 illustrative |
| 7 可读 | 3m / 10m 字号硬线；对比 ≥4.5:1；黄底黑字 ≥7:1 |

## 9. Extension Rule

无需请示：进度格数（6 / 12）、路线转角、符号模块（24 / 32）、字号档、双语层级。

必须记录：新增功能色、换母题、引入第二套符号、使用照片。

## 10. 验收样本

- 项目：三年级英语课件（26 页）。
- 表面：deck 1280×720；黑 / 白 / 柠檬黄；12 格进度尺。
- 难点：每页要放阶段词、示例题、对照、焦点词，且学生坐 5–8m 外。
- 成立原因：阶段词固定在页眉同一列；示例题只用一条 3px 墨线；✓/✗ 只用墨色，不引入红绿；正文 ≥26px。
- 结果：26/26 页进度尺覆盖；无图标墙；无第二信号色。
