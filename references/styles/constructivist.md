# constructivist · 构成主义

> status: experimental
> 派生自 `folio`：继承 12 列、三声、左齐、可读性；覆盖为一条斜线、condensed 巨字、红黑对撞。

## 0. 融合契约

```
借：Rodchenko / Lissitzky 的构成主义——斜线、巨字、红黑、编号、海报尺度
拒：苏联纹章、锤子镰刀、假西里尔字母、宣传画人物、做旧纸张
留下：网格、左齐、留白、可读性、一个信号
读者：宣言、动员、发布、文化活动的观看者
距离：3–10m（海报 / 投影 / 户外屏）
证据形态：一句主张 + 一个事实 / 一个数字
何时不用：论证密集、数据表、长文、需要温柔气质的场合
```

## 1. 身份证

```
风格：瑞士网格 × 构成主义（Rodchenko · Lissitzky / Kino-Fot）
不是：苏联宣传画、复古海报皮肤、蒸汽波、红色主题模板
三件不变：一条斜线 · 红黑两声 · 巨字必须可读
冲突裁决：主张清晰 > 斜线张力 > 装饰
```

## 2. DNA 四槽

1. **底场组**：纸 `#F2F0EB`（或纯白）；墨 `#111111`；信号 `#D5231E`。深场 = 墨满版；红场 = 信号满版。全篇只用这三种场。
2. **双声部**：主张声部 = condensed 无衬线全大写（巨字、编号、动词）；证据声部 = grotesque 正文（说明、日期、地点、来源）。
3. **唯一结构母题**：**一条斜线**——18° 或 45°，从画幅一边穿到另一边；全篇只允许一个角度。斜线可以是一条实色带、一条 3px 线，或一块被斜切的场。
4. **节奏**：红场宣言 ↔ 纸面证据 ↔ 黑场转折。同一场连续不超过两个单位。

## 3. 色彩

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| Paper | `#F2F0EB` | 阅读底 | 40–60% |
| Ink | `#111111` | 字、场、线 | 结构 |
| Signal | `#D5231E` | 斜线、巨字、一个事实 | 10–25% |
| Muted | Ink + 0.60 | 来源、日期 | 小 |
| Rule | Ink + 0.16 | 网格线、分隔 | 线 |

红只做三件事：斜线、一个巨字、一个关键事实。不做小字，不做图标，不做渐变。中间调由墨派生，不新增灰。

## 4. 排印

- **展示**：condensed 无衬线，全大写。`Druk Condensed` / `Oswald` / `Archivo Narrow`；中文用 `Noto Sans SC` 的 Bold + 负字距，或声明的 condensed 中文字体。字号 96 / 128 / 160 / 200。
- **正文**：grotesque。`Helvetica Now` / `Archivo`（Arial 仅作回退）/ `Noto Sans SC`；16–24；行高 1.5。
- **阶梯**：14 / 18 / 24 / 32 / 48 / 64 / 96 / 160。巨字只在一处。
- **字重轴**：正文 Regular / 证据 Bold / 巨字 Black。全篇一套。
- **斜线上的字**：可以沿斜线排，但倾斜不超过 18°；正文永不倾斜。
- **禁**：正文全大写；假西里尔；用红字做长句；巨字压住可读信息。

## 5. 网格

- 12 列；内容宽 = `12c + 11g`；基线 8px。
- 斜线从网格交点出发，落在另一条列线上；角度全篇一个（18° 或 45°）。
- 巨字可以出血，但必须保留至少一个完整词可读；裁切不进安全区。
- 红块可跨 4 / 6 / 8 / 12 列；不与斜线争夺同一视线。
- **禁止**：两条以上斜线；斜线与图片对角线重复；把正文放进斜切区域。

## 6. 图像

- 高对比黑白照片、 halftone 或纯几何；全篇一种。
- 单页最多一张图；图不做背景，不做圆形裁切。
- 人物照片不做仰角英雄化；不用宣传画式构图。
- 没有真实图像就用纯字与几何，不用 AI 假照片。

## 7. 数据

- 一个单位只允许一个数字；数字用 condensed 巨字，配一行来源与单位。
- 比较用两条同基线的横条；不用饼 / 环 / 双轴。
- 编号用 01 / 02 / 03，与斜线方向一致；编号不是装饰，是阅读顺序。

## 8. 母题、签名动作、失败模式与七律

**母题**：一条斜线。它可以很粗（场），也可以很细（线），但角度、方向、含义全篇一致。

**签名动作**：一条 30°–45° 斜线贯穿版面，condensed 巨字沿斜线排或与斜线对撞；红黑两色，斜线必须承担动线。

**失败模式**：苏联纹章、假西里尔字母、红黑贴纸；斜线只是装饰，不指向动作或时间。

**一句练习**：只用一条斜线、一个 condensed 词、一个数字做 A3 海报；斜线必须回答“何时 / 去哪 / 做什么”。

**禁忌**：锤子镰刀与红星；假西里尔；做旧纸纹；两张以上斜线；红色小字；把正文倾斜；用"革命"字体拼贴；巨字遮住日期或来源。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 主张必须能被复述；斜线不能替代论点 |
| 2 网格 | 斜线必须从网格交点出发 |
| 3 排印 | 两个声部；正文永不倾斜 |
| 4 三声 | 纸 / 墨 / 红；红只做三件事 |
| 5 装饰 | 只允许一条斜线；编号属于结构 |
| 6 诚实 | 数字与引文必须真实；不用宣传式夸大 |
| 7 可读 | 巨字保留完整词；正文 ≥16；红底白字 ≥4.5:1 |

## 9. Extension Rule

无需请示：斜线角度（18° / 45°，全篇一个）、红块跨度、巨字档、纸张冷暖（印刷）。

必须记录：新增第二种角度、引入第二张图、使用彩色照片、把斜线换成弧线。

## 10. 验收样本

- 项目：文化节主视觉海报（A2，3m 看距）。
- 表面：poster；纸 `#F2F0EB`；红 `#D5231E`；45° 斜线。
- 难点：一句话主张、日期、地点、票务四组信息，不能变成四块补丁。
- 成立原因：45° 红带从左上到右下，日期沿带排；巨字只占一个词；票务信息落在右下网格；来源与年份 14px。
- 结果：3 秒测试能读出主张与日期；无第二斜线；正文未倾斜。
