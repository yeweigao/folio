# brutalist · 克制粗野

> status: experimental
> 派生自 `folio`：继承 12 列、三声、左齐、可读性；覆盖为裸露网格、系统字、材料重量与表格优先。

## 0. 融合契约

```
借：结构主义 / 当代展览图形——裸露结构、系统字、1px 线、无修饰的材料
拒：做旧纹理、故障艺术、假终端窗口、全等宽正文、以丑为酷
留下：网格、左齐、留白、可读性、一个信号
读者：工程、基础设施、透明度报告、文化项目的专业读者
距离：0.5–3m（屏幕 / 手册 / 展板）
证据形态：代码、规格、表格、原始数据、截图
何时不用：董事会叙事、时装、儿童、需要柔软气质的场合
```

## 1. 身份证

```
风格：瑞士网格 × 克制粗野（结构主义 / 当代展览图形）
不是：Grunge、赛博朋克、终端皮肤、无政府主义拼贴
三件不变：裸露网格 · 系统字 · 1px 线
冲突裁决：结构透明 > 材料重量 > 气质
```

## 2. DNA 四槽

1. **底场组**：纸 `#FFFFFF` 或原纸 `#F2F0EB`；墨 `#111111`；信号 `#FF3B00`（默认）或 `#0057FF`。深场 = 墨满版；信号只做块面或一条线。
2. **双声部**：主张声部 = grotesque Black（标题、编号、巨字）；证据声部 = grotesque Regular + mono（代码、规格、数字）。Mono 是材料，不是标签装饰。
3. **唯一结构母题**：**裸露网格 + 超大索引号**——在至少一个单位里把列线/基线画出来；全篇索引号用同一套（01 / 02 / 03）。
4. **节奏**：裸网格页 ↔ 密集表格页 ↔ 深场转折 ↔ 单句页。同一语法连续不超过两页。

## 3. 色彩

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| Paper | `#FFFFFF` / `#F2F0EB` | 阅读底 | ≥50% |
| Ink | `#111111` | 字、线、场 | 结构 |
| Signal | `#FF3B00` 或 `#0057FF` | 当前项、风险、一个关键数 | ≤10% |
| Muted | Ink + 0.58 | 规格、来源、次级 | 小 |
| Rule | Ink + 1.0 / 0.24 | 1px 结构线 / 次级线 | 线 |

中间调由墨派生。信号色不进入正文，不进入小字，不进入图表系列色。

## 4. 排印

- **字族**：grotesque + mono。`Helvetica Now` / `Archivo`（Arial 仅作回退）/ `Noto Sans SC`；mono 用 `IBM Plex Mono` / `JetBrains Mono`。中文正文用 `Noto Sans SC`，代码块用 mono。
- **阶梯**：12 / 13 / 16 / 20 / 24 / 32 / 48 / 72 / 112。正文 16–20；规格 13–14；索引号 48–112。
- **字重**：Regular 400 正文 / Medium 500 标签 / Black 900 标题与索引。
- **Mono 边界**：只用于代码、路径、版本号、坐标、精确数值；不用于整段正文，不用于装饰性小标签。
- **禁**：全等宽正文；全大写长句；字距拉开的小标签；用 mono 假装"技术感"。

## 5. 网格

- 12 列；内容宽 = `12c + 11g`；基线 8px。
- 裸网格单位：列线用 1px `ink + 0.24`，基线不画；至少一个单位展示结构。
- 表格：1px 横线，无竖线，无斑马纹；数字右对齐；表头 Medium。
- 索引号占 1–2 列，贴着内容起点；它是结构，不是水印。
- **禁止**：卡片壳；圆角；阴影；把网格线画成装饰纹理。

## 6. 图像

- 截图、图表、原始照片；不加水印、不加滤镜、不做艺术化裁切。
- 截图必须可读：放大到关键区域，配一行说明；不把整屏缩成缩略图。
- 照片只在提供证据时出现；不用图库图冒充现场。
- 图像边缘对齐列线；不加边框，不加投影。

## 7. 数据

- 表格是第一等公民：规格表、对照表、变更记录。
- 图表只在趋势必须被看见时使用；透明绘图区，直标，无图例。
- 代码块用 mono 12–14，行高 1.5；只展示必要片段，加行号。
- 来源、版本、日期写在表格下方 12–13px；演示数据标 `illustrative`。

## 8. 母题、签名动作、失败模式与七律

**母题**：裸露网格 + 超大索引号。至少一个单位展示网格；索引号全篇一致。

**签名动作**：把网格、列线、容器边界画出来；系统字不修饰；材料与数据直接呈现，结构本身就是内容。

**失败模式**：做旧纹理、故障装饰、粗野字体堆叠；裸露的是装饰，不是结构。

**一句练习**：把一页网格线画出来，删掉所有装饰，只留结构、系统字和一组真实数据；还成立才是粗野。

**禁忌**：做旧/噪点纹理；故障错位；假终端绿字；全等宽正文；1px 线变成装饰网纹；把"粗野"当"不排版"的借口；用信号色涂满整页。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 结构透明优先；表格能说清就不用图 |
| 2 网格 | 网格可以露出来；露出也是结构 |
| 3 排印 | grotesque + mono；mono 只做材料 |
| 4 三声 | 纸 / 墨 / 一个信号；线是墨的透明度 |
| 5 装饰 | 索引号与网格线是结构，不是装饰 |
| 6 诚实 | 截图、版本、来源必须真实；不伪造终端 |
| 7 可读 | 正文 ≥16；代码 ≥12；对比 ≥4.5:1 |

## 9. Extension Rule

无需请示：索引号大小、网格露出比例、表格密度、信号色二选一、纸张冷暖（印刷）。

必须记录：引入第二种 mono、把网格线做成纹理、使用全屏照片、增加第二种图表。

## 10. 验收样本

- 项目：基础设施透明度报告（A4 手册，24 页）。
- 表面：handbook；白纸；信号橙 `#FF3B00`。
- 难点：12 张规格表、3 张架构图、1 段代码，不能变成 Excel 打印件。
- 成立原因：索引号 01–12 贯穿；表格只留横线；架构图用 1px/2px 两级线；代码只留 14 行；信号橙只标变更项。
- 结果：任意一页能在 5 秒内定位章节与变更；无斑马纹；无卡片。
