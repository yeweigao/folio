# folio · 母体风格

> 默认底座。任何表面、无特殊声明时用它。其他风格从它派生，显式写"继承什么、覆盖什么"。
> 哲学：瑞士国际主义（Swiss International Style）——网格即结构、flush-left、极少装饰、尺度对比。

## 1. 风格身份证

```
风格：瑞士网格 × 编辑叙事（Swiss International · Müller-Brockmann 谱系）
不是：SaaS 官网感、卡片仪表盘、渐变霓虹、暖纸复古、模板 PPT
三件不变：12 列硬网格 · 三色相 · 无衬线单一骨架
冲突裁决：网格裁决布局 > 信号色裁决强调 > 内容裁决长度
```

## 2. Theme DNA（四槽，全篇不变）

1. **底场组**：纸 `#FFFFFF`（主阅读底，≥55%）· 墨 `#111111` · **一个信号色**。深场 = 墨满版；亮场 = 信号色满版。全册只允许这两种反转，不引入第三种温度。
2. **双声部**：主张声部（display，仅巨字档）；证据声部（body / reading / label / number）。角色不互换，见 §4。
3. **唯一结构母题**：全册择一 —— 刻度标尺 / 决策带 / 裸露粗框 / 三级叠透 / 四角测绘括号 / 切角。同一母题贯穿全册，不换第二种标记方式。
4. **节奏**：纸面精读 ↔ 墨满版转折 ↔ 信号色满版爆发。三种场交替，同一展品语法不连续超过两页。

## 3. 色彩（颜色即语义，不装饰）

| 角色 | 值 | 用途 |
|---|---|---|
| Paper | `#FFFFFF` | 主阅读底 ≥55% |
| Ink | `#111111` | 标题、正文、直标 |
| Signal | 见下表，全册一个 | 唯一亮信号：主张、风险、关键数字、当前段；常规页 ≤10%，hero ≤20% |
| Muted | Ink + `opacity 0.62` | 次级标签、来源、注释 |
| Rule | Ink + `opacity 0.12` | 发丝线、表格横线 |
| On dark | White / White + `opacity 0.78` | 深底主张 / 深底正文 |

**中间调一律由墨的不透明度派生。** 写 `#6B6B6B` / `#E5E5E5` / `#D4D4D4` 这类独立灰 hex 就是引入第四色，纸面立刻变卡片。深场也不要 `#0B2E4A` 这种"深蓝黑"——要么信号色满版，要么纯黑。

信号色按内容气质选（全册一个）：

| 气质 | 信号色 | 说明 |
|---|---|---|
| 主张、风险、宣言（默认） | 瑞士红 `#E2231A` | 块面 + 白字 |
| 理性、数据、机构 | 亮蓝 `#0057FF` | 慎用于低龄，易读成 SaaS 蓝 |
| 活力、儿童、公共活动 | 柠檬黄 `#FFD400` | 黑字压黄 13.2:1，**仅块面，绝不做小字** |
| 生长、自然、科学 | 墨绿 `#00693E` | 块面 + 白字 |

辅助块面色（只做面，不做字）：黄 `#FCCC0A` · 橙 `#FF6319`。中性辅助：muted `#68645D` · sand `#CFCBC3`。
**并列类别 >3 类才启用第二个信号色**，且必须在 DESIGN.md 写明"哪个色 = 哪一类"。不用紫 + 黄（万圣节），不用粉 + 蓝（消费品牌）。

## 4. 排印：双声部 + 一个字重轴 W(S)

- **主张声部**：巨字、封面、章节扉页、核心大数字。用带 Black/Heavy 字面的字族。
- **证据声部**：标题、导语、正文、图表、表格、页脚。正文骨架一套 grotesque，层级只靠字号与字重。
- **一册只允许一个 `字号 → 字重` 映射**（三套预设见 `../surfaces/deck.md` 的引擎事实段）。
- 硬线：导语比正文大 ≥5–6px；正文行宽 45–68 字符；左齐不两端对齐；可读文字 ≥12px（投影介质 ≥16px）。
- 显示家族只在巨字档出现，一页最多一处。
- 中文字体放栈首（`Hiragino Sans GB` / `PingFang SC`），否则 bold 丢失。
- **禁 Inter 作默认**：它是通用 UI 默认，写出来就是"没选过"。

## 5. 网格

- 模块化，flush-left，外边距与槽宽由表面声明（deck：1280×720 / 边距 70 / 12 列 × 73 + 槽 24 / 8px 基线）。
- 所有元素吸附列线与基线；发丝线落在网格线上。**结构即装饰**——圆角卡片、阴影、渐变不是。
- 并列页用模块网格：跨度取整数倍，块间槽 20（不是 40），层级只有三档（实色块 > 3px 墨线 > 1px 墨线）。

## 6. 影像

全册一种媒介（高对比黑白摄影 / 单色 duotone / 硬边几何，三选一）；L1 影像 ≤3 页；裁切对齐列宽；主体偏置 ≥1/3 画幅。四种媒介混用 = 四本杂志。
生成图 prompt 固定四段：媒介 → 主体与构图 → 情绪 → 技术（比例 / no text / no watermark）。逐张目视核对。

## 7. 图表

图表是论点不是容器。透明绘图区、末端直标、不出图例、不出白色绘图板；对比用长度不用饼/环/3D；单位 / 期间 / 基线 / 来源贴近展品标题写一次。表格开放横线、无竖线、数字右对齐、单位在表头。

## 8. 禁忌

暖纸 / 米白底（warned，投影会洗掉）· 装饰性背景框与半透明色块底板 · KPI 磁贴与圆角卡片 · 阴影 / 渐变 / 发光 / 3D · 仪表盘圆环与进度胶囊 · 图标墙 · 白色绘图板与色块图例 · 照片填充证据页 · 一页多个信号色 · 为凑结论编数字 · **为通过留白检测而填充内容**。

## 9. 铁律互动（本风格如何收紧）

| 铁律 | 本风格的收紧 |
|---|---|
| 1 网格 | 12 列 + 8px 基线为默认；无网格声明的页视为未开工 |
| 2 排印 | 只允许双声部，不引衬线对位（衬线版须另立风格文件） |
| 3 三色相 | 纸 / 墨 / 信号色，灰值一律由墨派生 |
| 4 装饰 | 装饰位只允许唯一结构母题 |
| 5 诚实 | 演示数据标 illustrative；文字层独立，不烤进 SVG |
| 6 形态 | 形态与母题打架时，改母题的密度，不改形态 |
| 7 可读 | 对比 ≥4.5:1 为底线，信号色块面 + 黑字须 ≥7:1 |

## 10. Extension Rule

没有样本可照的页面，只允许改：跨度、尺度、场的温度（纸 / 墨 / 信号色）、密度、图片状态（可为零）。
**不许**：新增字体或声部、新增色相、换母题、引入圆角 / 阴影 / 渐变。
