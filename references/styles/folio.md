# folio · 瑞士母体

> status: stable
> 派生自：无。所有方言从本文件派生；本文件不取消任何铁律。

## 0. 融合契约

```
借：Müller-Brockmann / Ruder 的瑞士国际主义——模块网格、非对称、grotesque、留白
拒：装饰性构图、怀旧皮肤、表演性的"高级感"
留下：网格、左齐、留白、可读性、一个信号
读者：通用；无特殊气质要求的项目
距离：0.5m（手册）– 10m（投影 / 海报）
证据形态：文字、数据、单一实物或照片
何时不用：需要论证制度、纪实叙事、时装图像或强主张时，换方言
```

## 1. 身份证

```
风格：瑞士网格 × 编辑叙事（Müller-Brockmann · Neue Grafik 谱系）
不是：SaaS 官网感、卡片仪表盘、渐变霓虹、暖纸复古
三件不变：12 列硬网格 · 三声（纸/墨/一个信号）· 无衬线单一声部
冲突裁决：网格 > 信号 > 内容长度
```

## 2. DNA 四槽

1. **底场组**：纸 `#FFFFFF`（主阅读底 ≥55%）；墨 `#111111`；一个信号。深场 = 墨满版；亮场 = 信号满版。全篇只允许这两种反转。
2. **双声部**：主张声部（display，只在巨字档）+ 证据声部（body / reading / label / number）。角色不互换。
3. **唯一结构母题**：全篇择一——刻度标尺 / 决策带 / 裸露粗框 / 三级叠透 / 四角测绘括号 / 切角。同一母题贯穿，不换第二种标记。
4. **节奏**：纸面精读 ↔ 墨满版转折 ↔ 信号满版爆发。三种场交替；同一语法连续不超过两个单位。

## 3. 色彩

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| Paper | `#FFFFFF` | 主阅读底 | ≥55% |
| Ink | `#111111` | 标题、正文、直标 | 结构为主 |
| Signal | 四选一，全篇一个 | 主张、风险、关键数字、当前项 | 常规 ≤10%，主张 ≤20% |
| Muted | Ink + opacity 0.62 | 次级标签、来源、注释 | 小面积 |
| Rule | Ink + opacity 0.12 | 发丝线、表格横线 | 线 |
| On dark | White / White + 0.78 | 深底主张 / 深底正文 | 深场 |

**信号四选一**（按内容气质，不按心情）：

| 气质 | 值 | 备注 |
|---|---|---|
| 主张、风险、宣言（默认） | `#C83024` | 块面 + 白字；低质投影可提到 `#D5231E`，需实测 |
| 理性、数据、机构 | `#0057FF` | 慎用于低龄，易读成 SaaS 蓝 |
| 活力、儿童、公共活动 | `#FFD400` | 黑字压黄 13.2:1；只做块面，不做小字 |
| 生长、自然、科学 | `#00693E` | 块面 + 白字 |

**中间调一律由墨的不透明度派生**：muted 0.62 / rule 0.12 / 深底正文 white 0.78。不写独立灰 hex，不写"深蓝黑"。
纸的暖冷是材料：屏幕默认纯白；印刷可用 `#F7F5F0`，必须在 DESIGN.md 声明"这是纸，不是第四色相"。

## 4. 排印

- **字族**：一套 grotesque 走全篇。`Neue Haas Grotesk` / `Helvetica Now` / `Archivo`（Arial 仅作回退）；中文栈首 `PingFang SC` / `Noto Sans SC` / `Hiragino Sans GB`。展示档可用同族的 Black/Heavy，或声明的 `Archivo Black`。
- **双声部**：主张声部只在 64 / 112 档出现，一个单位最多一处；证据声部承担标题、导语、正文、标签、数字。
- **阶梯**：12 / 14 / 16 / 20 / 24 / 32 / 46 / 64 / 112。屏幕正文 ≥16；投影正文 ≥26；印刷正文 ≥10.5pt。
- **一个字重轴**：Regular 400 正文 / Medium 500 标签 / Bold 700 强调 / Black 900 巨字。全篇一套映射。
- **硬线**：导语比正文大 ≥5px；行宽 45–68 字符（CJK 25–34 字）；左齐不两端对齐；长句不全大写。
- **禁**：Inter 作默认；用换字体或彩色小字做层级；一页六种字号。

## 5. 网格

- 12 列；内容宽 = `12c + 11g`。屏幕基线 8px；A4 基线 28px。
- 具体表面取自己的数字（deck / poster / web / handbook 各文件为准），但必须能写出上式。
- 元素吸附列线与基线；发丝线落在网格线上。
- 允许跨度：12 / 8 / 6 / 4 / 3；分块只用三档——实色块 > 3px 墨线 > 1px 墨线。
- **禁止**：九宫格等分；三张同构卡片；为填满而拆页。

## 6. 图像

- 全篇一种媒介：高对比黑白摄影 / 单色 duotone / 硬边几何。选一，不混。
- 影像单位不超过总数的 1/3；裁切对齐列宽；主体偏置 ≥1/3 画幅。
- 图注与来源用 muted 0.62，12–13px，紧贴图像左下或右下。
- 没有真实图像就不放；不用 AI 假照片、不用图库图冒充现场。

## 7. 数据

- 图表是论点，不是容器：绘图区透明、末端直标、不出图例、不出白色底板。
- 对比用长度，不用饼 / 环 / 3D；双轴禁用；同一图只有一个量纲。
- 单位、时期、基线、来源写在标题下或图下，一次写全。
- 表格开放横线、无竖线、数字右对齐、单位在表头。
- 演示数据标 `illustrative`，给算式。

## 8. 母题、签名动作、失败模式与七律

**母题**：六选一，全篇一个——刻度标尺 / 决策带 / 裸露粗框 / 三级叠透 / 四角测绘括号 / 切角。

**签名动作**：用一次极端尺度差（112 巨字 / 16–26 正文，按介质）在同一条列线上建立层级，其余元素退到 1px 线或空白；全篇只留一次信号满版作转折。

**失败模式**：把瑞士做成灰白极简皮肤——每页同一个音量，没有尺度极差、没有信号满版，只剩 Helvetica 和空白。

**一句练习**：一页只有标题和三个事实：标题 112、事实 16（屏幕）/ 26（投影）、只加一条 1px 线；不加色块，看层级是否仍成立。

**禁忌**（能指认）：暖纸当默认屏幕底；装饰性背景框与半透明色块底板；KPI 磁贴与圆角卡片；阴影 / 渐变 / 发光 / 3D；仪表盘圆环与进度胶囊；图标墙；白色绘图板与色块图例；照片填充证据页；一页多个信号色；为凑结论编数字；为通过留白检测而填充。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 形态与母题打架时，改母题的密度，不改形态 |
| 2 网格 | 12 列 + 基线为默认；无声明视为未开工 |
| 3 排印 | 只允许双声部；衬线对位须另立方言 |
| 4 三声 | 纸 / 墨 / 一个信号；灰值一律由墨派生 |
| 5 装饰 | 装饰位只允许唯一母题 |
| 6 诚实 | 演示数据标 illustrative；文字层独立 |
| 7 可读 | 对比 ≥4.5:1；信号块 + 黑字须 ≥7:1 |

## 9. Extension Rule

无需请示：跨度、尺度极差、场的温度（纸 / 墨 / 信号满版）、密度、图片数量与裁切、母题疏密。

必须记录：新增字族、新增色相、换母题、引入新图型、改变双声部角色。

## 10. 验收样本

- 项目：小学三年级英语课件（26 页课堂投影）。
- 表面：deck 1280×720；信号柠檬黄；三色纪律黑 / 白 / 黄。
- 难点：教学叠加层要在同一页放阶段词、对照、示例题、焦点词，且不能变成卡片墙。
- 成立原因：12 格进度尺作唯一母题；阶段词固定在页眉同一列；信号色锚点每页 ≥1.5%；示例题只用一条 3px 墨线分隔。
- 结果：26/26 页母题覆盖，无独立灰 hex，投影正文 ≥26px。
