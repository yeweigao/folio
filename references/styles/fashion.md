# fashion · 时装编辑

> status: stable
> 派生自 `folio`：继承 12 列、三声、左齐、可读性；覆盖为 Bodoni 巨字、图像裁切、钴蓝阶梯与黑白摄影。

## 0. 融合契约

```
借：Bodoni / Didot 谱系 × 时装编辑——巨字与图像对撞、极端裁切、黑白摄影、窄体标签
拒：奢侈品金、玻璃拟态、玫瑰金渐变、居中logo墙、彩色产品图
留下：网格、左齐、留白、可读性、一个信号
读者：时装、美容、展览、品牌形象的观看者
距离：0.5–3m（屏幕 / 画册 / 展板）
证据形态：摄影 + 一句主张 + 一个系列名
何时不用：数据论证、教学、纪实长文、公共导视
```

## 1. 身份证

```
风格：瑞士网格 × 时装编辑（Bodoni / Didot · 时装画册）
不是：奢侈品官网模板、美妆电商、金色高级感、杂志翻页动画
三件不变：Bodoni 巨字 · 黑白摄影 · 钴蓝一个信号
冲突裁决：图像张力 > 字与图的关系 > 信息量
```

## 2. DNA 四槽

1. **底场组**：纸 `#FFFFFF`（印刷 `#F6F4EF`）；墨 `#0A0A0A`；信号钴蓝 `#1710CC`。深场 = 墨满版；蓝场 = 钴蓝满版。全篇只允许这两种反转。
2. **双声部**：主张声部 = Bodoni/Didot 巨字（一个词、系列名、数字）；证据声部 = grotesque 正文 + condensed 标签。标签声部只做地点、日期、作者、编号。
3. **唯一结构母题**：**字与图的裁切碰撞**——一个巨字被图像边缘切掉一部分，或图像被字切掉一部分。一个单位一次。
4. **节奏**：图像场 ↔ 巨字场 ↔ 文本页 ↔ 钴蓝转折。图像不超过单位总数的 1/2；同一构图连续不超过两个单位。

## 3. 色彩

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| Paper | `#FFFFFF` / 印刷 `#F6F4EF` | 阅读底 | ≥45% |
| Ink | `#0A0A0A` | 字、场 | 结构 |
| Signal | `#1710CC` | 巨字、一条线、一个编号 | ≤15% |
| Blue 92 | `#1710CC` + 0.92 | 蓝场上的正文 | 场 |
| Blue 72 | `#1710CC` + 0.72 | 次级信息 | 小 |
| Blue 45 / 22 | `#1710CC` + 0.45 / 0.22 | 发丝线、分区 | 线 |

钴蓝阶梯只做透明度派生，不新增第二种蓝。黑与白承担摄影与正文；钴蓝只做标点。金色、银色、玻璃、发光一律不出现。

## 4. 排印

- **展示**：`Bodoni Moda` / `Didot`；中文用 `Noto Serif SC` 的 Black，或声明的现代宋体。字号 112 / 160 / 196。
- **正文**：`Archivo` / `Helvetica Now` / `Noto Sans SC`；14–16；行高 1.6。
- **标签**：`Six Caps` / `Arial Narrow`；12；全大写，字距 +2%；只做地点、日期、作者、编号。
- **阶梯**：12 / 14 / 16 / 20 / 24 / 32 / 46 / 64 / 112 / 160 / 196。
- **巨字**：一个单位最多一个词；必须与图像发生关系（切、压、穿、让）；不放在图像旁边当标题。
- **禁**：一个标题里混斜体词；彩色小字；正文用 Bodoni；标签用等宽；超过三个字族角色。

## 5. 网格

- 1280 画布：12 列 ×74 + 11 槽 ×16 + 左右边距 108 = 1280；内容宽 1064。
- A4 画册：12 列 × 9mm，槽 6mm；边距上 18 / 下 21 / 内 21 / 外 15mm；基线 28px。
- 图像占 6 / 8 / 12 列；巨字可跨 6–12 列并出血；图注落在图像起始列。
- 钴蓝发丝线 1px，落在列线上；不做装饰框。
- **禁止**：居中奢侈品排版；三等分产品图；把巨字缩成安全标题。

## 6. 图像

- 全篇黑白或单色 duotone；一种媒介。
- 人像裁切可以极端（切掉半张脸、切到肩线），但必须保留一个可读的主体动作。
- 图像不做圆角、不加阴影、不加边框；不加金色滤镜。
- 图注：人物 / 服装 / 摄影师 / 来源，12px；没有来源的图不用。
- 不用 AI 假人像冒充真实模特或真实系列。

## 7. 数据

- 时装内容通常不需要图表；如出现，只用一个数字（年份、系列号、价格）作为展示声部。
- 价格与日期用标签声部，不放大；不做"促销红"。
- 任何数字必须有来源或标 `illustrative`。

## 8. 母题、签名动作、失败模式与七律

**母题**：字与图的裁切碰撞。一个单位最多一次；不做重复贴纸。

**签名动作**：一个 Bodoni 谱系巨字与一张裁切人像对撞；字压图或图压字，只保留一个焦点；钴蓝作唯一信号。

**失败模式**：奢侈品金、玻璃拟态、美妆电商；巨字只是大，没有与图像发生关系。

**一句练习**：用一张人像、一个 3 字母词、一个钴蓝块面做 A4 封面；词必须与裁切发生关系，不压脸。

**禁忌**：金色/玫瑰金；玻璃拟态；发光；居中大logo；彩色产品图；一个标题多个斜体词；把 Bodoni 用在正文；用钴蓝涂满整页。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 图像与一个字先成立，再加信息 |
| 2 网格 | 巨字可以出血，但起点落在列线 |
| 3 排印 | 三个角色：Bodoni 展示 / grotesque 正文 / condensed 标签 |
| 4 三声 | 纸 / 墨 / 钴蓝；钴蓝阶梯只做透明度 |
| 5 装饰 | 只允许一次字图碰撞与一条钴蓝发丝线 |
| 6 诚实 | 摄影师、人物、系列、来源必须真实 |
| 7 可读 | 正文 ≥14；图注 ≥12；黑白图上白字需实测对比 |

## 9. Extension Rule

无需请示：巨字字号、图像裁切、蓝场比例、标签字距、纸张冷暖（印刷）。

必须记录：引入彩色照片、第二个展示词、第二种衬线、把钴蓝换成别的信号。

## 10. 验收样本

- 项目：时装系列画册（A4，32 页）。
- 表面：handbook；印刷纸 `#F6F4EF`；钴蓝 `#1710CC`；黑白摄影。
- 难点：一个系列名要同时出现在封面、跨页、封底，且不能重复成三张同构海报。
- 成立原因：封面巨字被模特肩线切掉；跨页字在图像后面；封底只留一个钴蓝编号；标签声部承担所有地点与日期。
- 结果：三个单位三种字图关系；无金色；无彩色照片；正文 10.5pt 可读。
