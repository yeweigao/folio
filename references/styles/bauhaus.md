# bauhaus · 包豪斯

> status: experimental
> 派生自 `folio`：继承 12 列、三声、左齐、可读性；覆盖为一个基本形系统、几何无衬线、单主色块面。

## 0. 融合契约

```
借：Bauhaus / De Stijl 的几何系统——基本形、模块、比例、原色块面
拒：三原色纸屑、装饰圆点、复古包豪斯海报皮肤、Woody Allen 式怀旧
留下：网格、左齐、留白、可读性、一个信号
读者：教育、产品结构、系统说明、几何与建筑内容
距离：0.5–3m（手册 / 屏幕 / 展板）
证据形态：结构图、比例、步骤、对照
何时不用：纪实叙事、时装、强情绪宣言、数据密集论证
```

## 1. 身份证

```
风格：瑞士网格 × 包豪斯 / 风格派（Bayer · Mondrian / De Stijl）
不是：三原色派对、复古海报、几何贴纸、极简主义空白
三件不变：一个基本形系统 · 一个主色 · 几何承担构图
冲突裁决：结构清晰 > 几何张力 > 色彩
```

## 2. DNA 四槽

1. **底场组**：纸 `#FFFFFF`；墨 `#111111`；一个主色（红 `#D5231E` / 蓝 `#0057FF` / 黄 `#FFD400` 三选一）。深场 = 墨满版；主色场 = 主色满版。不同时出现两个主色。
2. **双声部**：主张声部 = 几何无衬线的 Bold（标题、数字、标签）；证据声部 = 同族 Regular（正文、说明、图注）。
3. **唯一结构母题**：**一个基本形**——圆 / 方 / 三角，三选一；它必须承担一个内容角色（圆 = 循环，方 = 块/模块，三角 = 方向/层级），不是装饰。
4. **节奏**：几何宣言页 ↔ 结构图页 ↔ 文本页 ↔ 主色场转折。同一语法连续不超过两页。

## 3. 色彩

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| Paper | `#FFFFFF` | 阅读底 | ≥50% |
| Ink | `#111111` | 字、线、场 | 结构 |
| Primary | 红 / 蓝 / 黄 三选一 | 基本形、一个数字、一块场 | ≤20% |
| Muted | Ink + 0.60 | 来源、图注 | 小 |
| Rule | Ink + 0.14 | 网格线、分隔 | 线 |

**只选一个主色。** 另外两个原色不出现在同一作品里；需要第三层时用墨的线宽或主色块面，不用第二个原色。黄底黑字 ≥7:1；红/蓝底白字 ≥4.5:1。

## 4. 排印

- **字族**：几何无衬线。`Futura` / `Jost` / `Avenir`；中文 `Noto Sans SC` / `PingFang SC`。全篇一套。
- **阶梯**：12 / 16 / 20 / 24 / 32 / 48 / 72 / 120。标题 32–48；巨字 72–120；正文 16–20。
- **字重**：Regular 400 正文 / Medium 500 标签 / Bold 700 标题与数字。
- **几何字**：圆形的 o、e、a 是特征；不人为拉长或压扁。
- **禁**：全大写长句；用两个原色做层级；斜体；手写体；装饰性连字。

## 5. 网格

- 12 列；内容宽 = `12c + 11g`；基线 8px；基本形画在 8px 模块上。
- 圆 / 方 / 三角的尺寸取 8 的倍数：24 / 48 / 96 / 192。
- 形与文字的关系：形可以是文字的容器、度量或方向；不能只是角落装饰。
- 允许跨度：12 / 8 / 6 / 4 / 3；块面只用实色，不用渐变。
- **禁止**：随机散布的圆点；把基本形缩小成图标；用形做项目符号。

## 6. 图像

- 优先结构图、剖面、比例图；照片只在必要时使用，黑白或单色。
- 图像裁切成几何形（方 / 圆 / 三角）时，必须与母题一致；不能一张方一张圆。
- 不用彩色照片；不用装饰性几何插画。

## 7. 数据

- 比例用长度或面积；面积图必须同宽；不用饼 / 环 / 3D。
- 结构关系用树 / 层 / 矩阵；连接线统一 1px 或 2px。
- 数字用几何无衬线 Bold；单位小一档；来源 12–14。
- 演示数据标 `illustrative`。

## 8. 母题、签名动作、失败模式与七律

**母题**：一个基本形（圆 / 方 / 三角），全篇一个，且有内容角色。

**签名动作**：一个基本形（圆 / 方 / 三角）在全篇重复，改变尺度与裁切；原色块面只承担分区；用几何无衬线。

**失败模式**：三原色纸屑、装饰圆点、包豪斯海报模仿；基本形没有系统，只是贴纸。

**一句练习**：选一个基本形，用 3 种尺度、2 种裁切、1 个原色块面组织一页；不增加第二种形。

**禁忌**：三原色同时出现；装饰圆点；把形做成图标墙；复古包豪斯字体拼贴；几何形无角色；用红黄蓝做"儿童感"。

| 铁律 | 本方言 |
|---|---|
| 1 内容先于形式 | 基本形必须回答一个内容问题 |
| 2 网格 | 形落在 8px 模块上；文字吸附列线 |
| 3 排印 | 只许一套几何无衬线；一个主色 |
| 4 三声 | 纸 / 墨 / 一个主色；另两个原色不出现 |
| 5 装饰 | 形是结构，不是项目符号 |
| 6 诚实 | 结构图必须有真实比例与来源 |
| 7 可读 | 正文 ≥16；黄底黑字 ≥7:1；不把正文放进形里 |

## 9. Extension Rule

无需请示：主色（红/蓝/黄）、基本形（圆/方/三角）、形的尺寸、跨度、场反转。

必须记录：同时使用两个原色、引入第二种形、使用照片、把形变成装饰。

## 10. 验收样本

- 项目：产品结构说明折页（A4 三折）。
- 表面：handbook；白纸；蓝 `#0057FF`；方作为母题。
- 难点：三层结构、六个部件、两组比例，不能变成六张卡片。
- 成立原因：方 = 模块，承担所有分区；蓝只标当前层；比例图同宽；正文 10.5pt。
- 结果：三折展开后结构可一眼读出；无第二个原色；无圆角卡片。
