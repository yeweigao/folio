# 红队 · 门禁的敌人

> 不是复审。复审问作品好不好；红队问门禁有没有**便宜的赢法**。
> 状态：stable · 最后核对：2026-10-25

## 1. 一条原则

每写下一条门禁，就同时写下了一种最便宜的满足方式。

“有来源”可以变成“据行业报告”。“能打开”可以变成一张截图。“illustrative 显眼”可以变成一个 6pt 的脚注。“网格成立”可以先排好版，再叠十二条线。这些都不是违规；它们逐字满足条文，却让读者得到更差的东西。

红队找的不是 bug，是**合规地失败**。它不打分、不投票、不判作品美不美；它只把门禁推到墙角，看哪一条会先让路。

## 2. 什么算攻击

一个改动要同时满足三条，才算攻击：

1. **过门**：按现行条文，它能被判 pass。
2. **更便宜**：它比真做少一步、少一个证据、少一次打开。
3. **伤读者**：它让可读性、诚实、证据或判断变差。

只满足前两条、读者没有变差，那是优化，不是攻击。红队不反对省事，只反对**用省事冒充做到**。

## 3. 预算与触发

**触发**（满足一条就做）：

- 发布契约版本；
- 高风险交付：公开、印刷、对外、不可撤回；
- 同一类失败第二次出现；
- 回执写了 pass，但读者体验与 pass 不符。

**不触发**：日常小改、内部草稿、已经过一次红队且契约未变。红队不是每件作品的仪式；每件都跑，它会变成新的填充物。

**预算**：30 分钟，十二类过一遍。至少三类落在**真实成品**上，其余可纸面推演，但必须标明。连续两类只产出已登记的残余风险，就停；剩下的不是这一版能补的。

## 4. 十二类攻击

| # | 攻击 | 最便宜的通过改动 | 偷走什么 | 该谁拦 | 最小修复 |
|---|---|---|---|---|---|
| A01 | 缩印免责 | 把 illustrative、来源、免责压到 6pt，仍然“存在” | 标记的可读性 | 验收 #9 | 标记 ≥ 同表面图注下限；同层、同单位、实测 |
| A02 | 改写材料 | 18 字标题缩成 6 字，以适配版式上限 | 文案保真 | `SKILL.md §2.1`、G2 | 逐字 diff；长标题走 `poster.md §4` 协议 |
| A03 | 截图代开 | 交 PNG 代替原生文件，声称“文件能开” | 可编辑、字体真实、逐页 | 验收 #1–#3、G4 | 原生打开 + 选中改字撤销 + 逐页；否则 `unverified` |
| A04 | 声明色对比 | 用 CSS 声明色算对比，或取最亮背景像素 | 实际可读性 | 验收 #6 | 先把 `rgba` 合成到实际背景，再取字后最差像素 |
| A05 | 盒宽充字面 | 用块级盒宽证明行宽；字号 11.6px 报成 12 | 字面真实尺寸 | 验收 #4–#5 | 量文字范围，不量块盒；字号保留一位小数并向下取整 |
| A06 | 事后画网格 | 先排版，再叠十二条线；或检测每一个子元素 | 网格作为结构 | 验收 #7 | 先声明公式再施工；只测构图元素；内缩写进声明 |
| A07 | 注水填白 | 加三张卡片、图标墙或色块填结构空白 | 留白的结构意义 | `§2.3`、`§2.12`、`review.md §4.3` | 只改网格变量；空单位删掉或放大既有锚点 |
| A08 | 挂名来源 | “据行业报告”；图片来源写“网络” | 可追溯与许可 | 验收 #9 | 作者 / 机构、标题、日期、定位；图片加许可；否则删 |
| A09 | 视觉键盘 | 网页只走鼠标路径，focus 不可见，Tab 顺序乱 | 非鼠标用户 | 验收 §8 web 追加项 | Tab 走主路径、focus ≥2px、语义标题、skip link、reduced-motion、三档无横滚 |
| A10 | 屏幕冒充印刷 | 用 PNG 声称 300dpi，无出血、CMYK、打样 | 成品可靠性 | 验收 #8、G4 | 按成品 mm 算像素；PDF/X-4 + 3mm 出血 + 打样；否则 `unverified` |
| A11 | 同源复审 | 新开一个聊天，但带着建稿者解释；或自评当复审 | 独立性 | `rubric.md §3`、`review.md §6.1` | 复审只拿 SKILL、DESIGN、成品；记录模型与温度；自评不产生 pass |
| A12 | 追认破格 | 做完再补“已声明”；一页叠五次破格 | 规则的可识别性 | `§2.13`、`variations.md` | 施工前声明；一单位一次；超过一次重做结构 |

十二类不是穷举。它们覆盖三种攻击面：**测量**（A01、A04、A05、A06）、**证据**（A02、A03、A08、A10、A11）、**结构**（A07、A09、A12）。遇到新攻击，先判断它属于哪一种，再找最近的一条修复动作。

## 5. 修复动作库

修复不是再加一条禁令。禁令越多，便宜的赢法越多。优先用下面六种动作，把“最便宜的改法”变贵。

| 动作 | 把什么改成什么 | 例 | 验收句 |
|---|---|---|---|
| **数值化** | 形容词 → 数 + 单位 + 下限 | “显眼” → “≥同表面图注下限” | 我能报出实测值，且不低于下限 |
| **同源化** | 两套来源 → 一套来源 | 网格线由列宽变量生成；对比度由合成像素算 | 证据与成品出自同一个变量或同一张渲染 |
| **缩小对象** | 每个子元素 → 构图层级 | 只测标题块、信号块、信息列、页脚 | 检测对象与设计对象是同一个 |
| **降级** | 假装做到 → 明确未验 | 屏幕稿只证明屏幕；印刷无打样写 `unverified` | 结论没有超出证据 |
| **删除** | 补证据 → 去掉断言 | 无来源数字、无许可图片、无职责装饰 | 删掉后论证没有变弱 |
| **窄补** | 新增一套流程 → 补一条可判定条款 | 只给 #9 加标记下限，不新增第 13 项 | 补丁能被一句话复述，能重跑同一攻击 |

**修复后必须重跑攻击。** 如果最便宜的改法还是原来那条，说明补丁只增加了字数，没有增加成本。

## 6. 残余风险登记

不是所有洞都能补。复审可能同源，打样可能缺席，模型可能共享盲点。红队的最后一件交付不是零风险，是一张签了名的表：哪些洞还在，谁承担，什么时候再验。

```
攻击 / 等级 / 为什么仍在 / 谁承担 / 下一步 / 复查版本
```

| 等级 | 含义 | 处置 |
|---|---|---|
| **高** | 触及硬地板，或读者会因此读错、读不到、被欺骗 | 必须封堵，或由屋主书面接受；不能静默放过 |
| **中** | 降低品质，但不改变事实与可读性 | 登记，下一次同类交付前复查 |
| **低** | 工艺瑕疵，不影响判断 | 登记即可 |

0.9 的已知残余风险：

| 攻击 | 等级 | 为什么仍在 | 谁承担 | 下一步 | 复查版本 |
|---|---|---|---|---|---|
| A11 同源复审 | 高 | 独立上下文仍是同一模型；跨模型盲测未做 | 屋主 | 1.0 后做跨模型盲测 | 1.1 |
| A10 印刷成品 | 高 | B03 v2 无 PDF/X-4、CMYK、出血与打样 | 屋主 / 印刷方 | 在真实印刷项目走完预检 | 1.1 |
| A06 自动网格检测 | 中 | 组内流、块内内缩、出血元素需人工判断 | 复审者 | 每次交付人工确认构图元素 | 持续 |
| A04 自动对比度 | 中 | 背景图的最差像素仍需工具或人工取样 | 建稿者 | 固定“合成后再算”的测量顺序 | 持续 |
| 审美判断本身 | 高 | 门禁能防合规地失败，不能代替四视角 | 屋主 | 保留 `review.md` 的独立复审 | 持续 |

## 7. 实测记录：B03 v2

对象：`/tmp/folio-b03-v2.html`，A2 420×594，屏幕 100% 渲染，DPR 2。以下“实测”均在已加载页面上执行；写回文件的成品仍是 14pt 页脚。

| 攻击 | 操作 | 结果 | 判定 |
|---|---|---|---|
| A01 | 把页脚 illustrative 声明改为 6pt | 计算字号 8px，行高 10.4px；0.8 表单只问“显眼”，会放过 | **命中**；0.9 给 #9 加标记下限 |
| A02 | 对照冻结 brief 数标题 | 18/18 字，3 行；未改写 | 封堵 |
| A04 | 用声明色算页脚对比 | naive 脚本报 17.33:1；按 `rgba(17,17,17,.62)` 合成后为 5.13:1 | **命中测量漏洞**；加“先合成再算” |
| A05 | 量标题三行的块盒与字面 | 三个块级 `span` 的右边缘都报 1481.6px；文字范围实测 1267.2 / 1108.8 / 475.2px | **命中测量漏洞**；块宽不能证明行宽 |
| A06 | 对每个含文字元素量列线 | “2026 秋季”差 8.3px、日期差 37.8px、时间差 6.8px；但 `.date-block` 在 28mm、`.details` 在 276mm，均对列线 | **误判**；检查对象应是构图元素，不是组内流 |
| A03 / A09 / A10 | 原生打开、键盘、印刷预检 | 未做；v2 只有屏幕渲染，印刷项已标 `unverified` | 封堵于诚实边界 |
| A11 | 查复审来源 | 只有自评 86，无独立复审 | 封堵于规则：自评不产生 pass |
| A12 | 查破格声明 | 无破格 | 不适用 |

这一轮证明了两件事：门禁可以被 6pt、一个 `rgba`、一个块级盒宽和一次“先排版后画线”绕过；测量本身也是攻击面。它没有证明十二类覆盖了所有表面与模型；A09 的 web 追加项仍是纸面条款，A10 的印刷链路仍未走完。

## 8. 红队单与提示词

```
red-team: <项目> / <契约版本>
artifact: <路径> / <表面> / <怎么打开>
attacks run: 12 / 12（实测 <n>；纸面 <n>）
blocked: <A02, ...>
patched: <A01, A04, ...>
residual:
  - <攻击> / <高|中|低> / <为什么仍在> / <谁承担> / <下一步> / <复查版本>
verdict: no-unregistered-high | unverified
```

`no-unregistered-high` 不是 pass。它只说明门禁没有**已知的**便宜赢法；交付结论仍由 `engines/acceptance.md` 与独立复审给出。

可直接用的红队提示词：

```
你是 Folio 的红队。只读契约、成品与回执，不读建稿者的解释。
按 A01–A12 逐类回答：
1. 通过这张单，最便宜的改动是什么？
2. 它是否让读者更差？如果不会，跳过，这不是攻击。
3. 现行条文能不能拦住？引用条款与位置。
4. 如果拦不住，最小修复是什么？修复后最便宜的改法变贵了吗？
最后只交三样：已封堵、已修补、残余风险（等级 / 承担者 / 下次复查）。
不要给作品打分，不要用“整体不错”收尾。
```

红队不是让作品通过，是让通过变贵。门禁的敌人不是违规，是合规地失败。
