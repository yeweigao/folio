# 十四破格 · Variationen

> 十四条规则是默认。每一种变奏有意打破其中一条，并让读者认出这是破格。
> ——《全样式 · Folio 2.1》

破格是**被规则托住的偏离**，不是自由的同义词。

## 使用协议

1. **一个单位最多一次。** 一页、一屏、一帧、一幅、一个跨页，只允许一个破格。
2. **施工前写三行**：打破哪条默认 / 为什么必须破 / 代价是什么。写进 DESIGN.md 或交付说明。
3. **不为弱构图遮丑。** 构图先成立，破格才有意义。用破格救场，等于承认构图不成立。
4. **其余部分回默认。** 破格之外，网格、排印、色彩、可读性全部照常。整页都在破，等于没有规则。
5. **破格会过期。** 同一个破格在同一作者的作品里反复出现，它就不再是破格：要么升级为方言，要么退役。
6. **可读性与诚实不破。** 任何破格都不允许牺牲正文可读性、来源、可编辑文字或真实材料。

## 01 · 红底 Grund Rot

**打破**：纸占一半以上。
**何时**：一个主张、一个封面、一次 campaign；文字少，看距远。
**怎么做**：信号色满版出血，字反白；只留一个主张 + 一个事实 + 来源；其余信息移到相邻单位。
**代价**：信号色在这里用掉，其他单位不能再靠它强调；长文不可读；印刷墨量大。
**仍然成立**：网格、一个主意、对比度实测、来源。
**表面**：deck 扉页 / poster / web hero / handbook 扉页。

## 02 · 出血的巨字 Anschnitt

**打破**：内容留在边距与安全区内。
**何时**：封面、章节扉页、海报；一个词足够强。
**怎么做**：展示字放大到超出裁切边或视口边；保留至少一个完整词可读；字仍落在基线上。
**代价**：印刷可能裁掉字形；屏幕可能被浏览器裁切；不可用于需要完整阅读的标题。
**仍然成立**：一个词、一个主意、其余信息在安全区。
**表面**：poster / deck 扉页 / web hero / canvas 主帧。

## 03 · 石色纸 Grund Stein

**打破**：纯白纸是默认。
**何时**：印刷长文、档案、纪实、需要降低屏幕眩光的画册。
**怎么做**：用石色 / 暖白纸作为声明的场；屏幕上仅在有理由时使用；对比度重新实测。
**代价**：颜色偏移；屏幕与印刷不一致；容易被读成复古皮肤。
**仍然成立**：三声、对比、一个信号、纸是材料不是第四色相。
**表面**：handbook / poster / deck（谨慎）。

## 04 · 双色 Duplex

**打破**：照片必须全彩。
**何时**：一张强图、一个封面、一次 campaign；图像本身有明暗结构。
**怎么做**：照片转灰度，再以正片叠底印在一个平色上；两块版：黑 + 一个信号色；亮部成为纸色。
**代价**：丢失颜色信息；肤色偏移；需要打样；不适合产品色准。
**仍然成立**：一张图、一个信号、图注与来源。
**表面**：poster / handbook 封面 / deck 图像页。

## 05 · 黑底 Grund Schwarz

**打破**：纸是默认底。
**何时**：章节扉页、文化 / 夜间 / 技术主题、一个主张。
**怎么做**：墨满版，正文反白，次级信息用白 + 0.78；照片选亮部；信号色只做一个小标点。
**代价**：印刷墨量重、易透背；屏幕眩光；暗照片不可见。
**仍然成立**：层级、对比、一个信号、来源可读。
**表面**：deck 扉页 / web hero / poster / canvas 主帧。

## 06 · 反白字 Negativ

**打破**：字是墨，纸是底。
**何时**：海报、封面、章节页；一个词或一句短话。
**怎么做**：黑色印版铺满条带，字形是未印的纸；条带本身就是裁切框；字母可以在条带边缘被截断。
**代价**：只在大字号成立；正文不可用；细笔画会断。
**仍然成立**：一个词、可读性、不用描边/阴影/渐变补字。
**表面**：poster / deck 扉页 / web hero。

## 07 · 字里有照片 Bildschrift

**打破**：字与图像各自独立。
**何时**：一个词 + 一张强图；封面、海报、章节页。
**怎么做**：照片裁进字形；字形只做装饰层，必须同时提供真实可选文本、替代文本与可读的同一信息。
**代价**：字形内对比不可控；小字不可读；图片必须经得起裁切。
**仍然成立**：真实文本、替代文本、一个词、图注来源。
**表面**：poster / web hero（配真实 h1）/ handbook 封面。

## 08 · 四字四图 Bildschrift

**打破**：一个单位一张图。
**何时**：四个字各自承载一个概念；系列封面、概念页。
**怎么做**：四个字形各填一张不同的照片；同一字族、同一字号、同一基线；四张图同一处理。
**代价**：容易变成四格贴纸；需要四张同样强的图；信息容易碎。
**仍然成立**：一个主意（这四个字是一组）、网格、图注。
**表面**：poster / deck 章节页 / canvas 主帧。

## 09 · 叠印 Überdruck

**打破**：色块互不混合。
**何时**：双色海报、文化项目、需要"两块版"的印刷感。
**怎么做**：两块色版以正片叠底相交；交界变成近黑；只用于浅色纸；不用在深底。
**代价**：颜色不可预测；需要打样；文字压叠印会降低对比。
**仍然成立**：两版两色、一个信号、正文不压叠印。
**表面**：poster / handbook 封面 / deck 图像页。

## 10 · 瑞士朋克 Swiss Punk

**打破**：网格正交、单一朝向。
**何时**：文化、音乐、独立出版；一个单位需要一个手势。
**怎么做**：旋转 / 错位 / 层叠三选一；只作用于展示声部；正文保持正交；网格仍是底层。
**代价**：扫描路径被打断；容易变成 gimmick；不适合长文。
**仍然成立**：网格、正文可读、一个手势、一个信号。
**表面**：poster / deck 章节页 / web hero / canvas 主帧。

## 11 · 粗网点 Raster

**打破**：照片是连续调。
**何时**：报纸、回顾、档案、单张图；需要有"印刷"的物理感。
**怎么做**：用真实网点（45–85 lpi）或等价的点阵处理；一张图；网点角度全篇一致；不用滤镜假装。
**代价**：细节丢失；印刷可能撞网；屏幕缩放会摩尔纹。
**仍然成立**：图像是证据、图注、来源、一种媒介。
**表面**：poster / handbook 封面 / deck 图像页。

## 12 · 程序 Programm

**打破**：手工一次性构图。
**何时**：数据海报、系列生成、系统身份；同一规则要产出一组。
**怎么做**：用规则 / 代码从数据或参数生成版式；记录种子与参数；输出可复现；人工只做筛选与修正。
**代价**：可能生成无聊或破版；需要约束与人工判断；不是"随机即兴"。
**仍然成立**：网格规则、可读性、一个主意、来源。
**表面**：poster 系列 / web 生成页 / canvas 生成帧。

## 13 · 导向 Signaletik

**打破**：只用排印，不用象形符号。
**何时**：导视、公共信息、复杂空间、跨语言。
**怎么做**：一套几何象形符号 + 2px 路线 + 功能色映射；同一动作只有一个符号；符号画在 24/32 模块上。
**代价**：符号可能歧义；需要测试；容易滑向图标墙。
**仍然成立**：映射表、一套符号、可读性、一个信号。
**表面**：poster / web / handbook / deck 教学页。

## 14 · 楼梯排字 Treppensatz

**打破**：左齐、同一基线。
**何时**：一句话、封面、海报；短，且节奏本身是内容。
**怎么做**：每行按一个列宽或一个基线单位递进 / 退让；步长全篇一致；正文不参与。
**代价**：阅读节奏变慢；不适合长文；容易变成装饰。
**仍然成立**：对齐系统（步长是规则的）、可读性、一个信号。
**表面**：poster / deck 扉页 / web hero。

## 记录格式

```
破格：07 字里有照片
单位：P04 章节扉页
打破：字与图分离
理由：这一章的主题是"被看见"，字形需要承担图像
代价：小字不可读——真实标题另置 32px，图片仅作装饰层
仍然成立：h1 可选文本、alt、图注来源、网格
```

没有这五行，破格视为失误。
