# 评分表（rubric）

> 先过五道门，再打分。门失败 → 不通过，不看总分。
> 每一处扣分必须能指到**单位 + 位置 + 规则**；指不到就不扣。

## 1. 五道门（Gate）

| 门 | 内容 | 判定 |
|---|---|---|
| **G1 Floor** | `SKILL.md §2` 十六条 | 任一出现 → fail（例外须有记录；第 1、9、10、16 条无例外） |
| **G2 诚实** | 事实、数字、来源、素材、对方提供的文案 | 编造或篡改任何一项 → fail |
| **G3 可读** | 对比 ≥4.5:1；字号 ≥介质下限；行宽达标 | 任一项实测不达标 → fail |
| **G4 实际打开** | 导出件在目标环境打开、翻页、缩放；屏幕截图只证明屏幕 | 未做 → fail；印刷品无 PDF/X-4 / 打样 → unverified |
| **G5 留痕** | 读解三行、系统声明、偏离记录 | 缺一项 → fail |

工程门禁（溢出、画布、组件上限）由机器判定；不做审美判断，但必须 `ok`。

## 2. 五个维度（各 20 分）

### D1 · 读解与形态（20）

| 分 | 判据 |
|---|---|
| 18–20 | 三行读解准确；每个单位一个形态且与用途一致；材料盘点诚实；方言选择有理由 |
| 14–17 | 形态基本正确；有一处形态与内容错配；材料有缺口但已说明 |
| 10–13 | 形态靠版式猜；方言选择无理由；材料盘点遗漏但未编造 |
| 5–9 | 多个单位形态混乱；把 deck 当 poster 做；靠模板套内容 |
| 0–4 | 没做读解；内容与形式互相矛盾 |

### D2 · 结构与网格（20）

| 分 | 判据 |
|---|---|
| 18–20 | 网格可复算；元素吸附列线与基线；留白是结构；节奏有强弱；缩略图第一眼落在计划元素 |
| 14–17 | 网格成立；一两处元素漂移；节奏较平 |
| 10–13 | 网格存在但未贯穿；空白有塌陷；靠间距均分 |
| 5–9 | 无声明网格；对齐靠目测；每页结构不同 |
| 0–4 | 元素散落；无阅读动线 |

### D3 · 排印（20）

| 分 | 判据 |
|---|---|
| 18–20 | 一套阶梯；层级只靠字号/字重/位置；行宽与行距舒适；中西文混排干净；标点正确 |
| 14–17 | 阶梯成立；一处行宽或标点问题；字重轴基本统一 |
| 10–13 | 两套字号系统；靠彩色小字或换字体造层级；行宽失衡 |
| 5–9 | 标题与正文无级差；大面积全大写；中文 bold 失效未察觉 |
| 0–4 | 不可读；文字被裁切或溢出 |

### D4 · 三声、母题与图像（20）

| 分 | 判据 |
|---|---|
| 18–20 | 纸/墨/一个信号；中间调派生；母题贯穿；图像是证据或空气；图表直标无白板 |
| 14–17 | 三声成立；母题出现 2/3 单位；一处图像或图表冗余 |
| 10–13 | 多一个强调色；母题只像装饰；图表有图例和白底 |
| 5–9 | 糖果色；图像只是填充；图表类型与问题不符 |
| 0–4 | 无色彩纪律；假图/假数据图 |

### D5 · 诚实与收尾（20）

| 分 | 判据 |
|---|---|
| 18–20 | 数字有来源或 illustrative；图注完整；文字可编辑；导出逐页核对；偏离记录具体 |
| 14–17 | 来源基本齐全；一处图注弱；导出检查做了但不彻底 |
| 10–13 | illustrative 未标；图注缺来源；文字转曲但未说明 |
| 5–9 | 数字无单位/无基线；图注缺失；"应该能过" |
| 0–4 | 编造事实；假人物/假 logo |

## 3. 判定

- **通过**：五门全过，总分 ≥75，且无维度 <10；必须有至少一个独立上下文的复审记录，自评不产生通过。
- **优秀**：五门全过，总分 ≥88，屋主测试通过，无豁免；同样必须独立复审。
- **不通过**：任一门失败，或总分 <75，或任一维度 <10；或只有自评。

## 4. 屋主测试（单独判定，不计分）

把成品去色、替换成中性字体后给屋主看：

- 仍能认出网格、母题、节奏、三声比例 → 通过。
- 只剩"干净"或"高级"这种通用印象 → 不通过；说明方言只是皮肤。

## 5. 扣分纪律

1. **一处一记**，不重复扣同一问题（如"未标来源"不同时在 G2 与 D5 扣）。
2. **证据优先**：写清单位、位置、实测值（例：`P04 正文 14px < 投影下限 26px`）。
3. **不扣偏好**：不能因为"我不喜欢这个信号色"扣分；只能引用规则或实测。
4. **不奖励复杂度**：多做不等于做好；删减后更清楚，应加分而不是扣分。
5. **自评不产生结论**：自评只用于定位问题；pass 必须由独立上下文确认。自评与复审差 >10 分时，按 `calibration.md §3` 重审。
