# 评测（evals）—— 证明契约真的能约束输出

## 1. 测什么

不是测"好不好看"这种无法复现的整体印象，而是测三件事：

1. **服从度**：一个读到 `SKILL.md` 的新 agent，能不能稳定产出地板上以的作品。
2. **辨识度**：遮住颜色和字体，成品是否仍像同一套系统（屋主测试）。
3. **抗压性**：遇到缺材料、客户乱点菜、默认组件诱惑时，是否守得住诚实与可读性。

评测结果只对**当次模型 + 当次版本**有效。记录模型名、日期、温度、渲染器；没有这些元数据的结果不可比较。

## 2. 四个层级

| 层 | 名称 | 做什么 | 通过线 |
|---|---|---|---|
| **L0** | 合规检查 | 跑 `conformance.md`：链接、frontmatter、数字、禁用词、文件类型 | 全部通过 |
| **L1** | 命题作文 | 用 `briefs.md` 的 01–08，各交一件成品 | 地板 0 违规；总分 ≥75；无单项 <10 |
| **L2** | 对抗输入 | 用 briefs 09–11：缺材料、风格乱炖、客户要求破禁、修复既有稿 | 同上，且每次豁免都有记录 |
| **L3** | 介质迁移 | 用 brief 12：同一内容从 deck 迁到 web | 两件都过 L1；网格与字号按目标表面重算 |

**L0 不过，不跑 L1。** 契约自己都不自洽，测输出没有意义。

## 3. 怎么跑（一次评测）

1. **冻结材料**：把 brief 里的真实材料**逐字**放进一个目录；只给数量、不给原文的 brief 先补材料，再开测；缺的明确标 `absent`。不得临时补编。
2. **干净上下文**：新会话，只给 `SKILL.md` + brief + 材料。不给建稿者的解释。
3. **记录三行**：`Reading this as / Material / Dialect` 必须出现在交付里；没写直接记一项失败。
4. **交付**：源文件 + 导出件 + 完成定义勾选 + 偏离记录。
5. **双人复审**：两个新上下文分别按 `rubric.md` 打分；分歧按 `calibration.md` 处理。
6. **归档**：成品、分数、违规位置、模型元数据放同一目录；下次改动契约后重跑同一组 brief。

## 4. 计分与判定

- **Gate**：`rubric.md` 的五道门，任一失败 → 本次不通过，不看总分。
- **总分**：五个维度各 20 分，满分 100。
- **通过**：≥75，且没有维度低于 10。
- **优秀**：≥88，且屋主测试通过，且无豁免项。
- **自评不产生结论**：自评只用于定位问题；pass 必须由至少一个独立上下文确认。自评与复审差 >10 分时，按 `calibration.md §3` 重审。

## 5. 结果记录模板

```
eval: B03 / poster
date: 2026-10-25
model: <name + version> · temperature <x> · renderer <name>
deliverable: <path>
copy fidelity: 标题 18/18 字 · 讲者 2/2 · 日期地点逐字一致
reviewers: <独立上下文 A 分数> / <独立上下文 B 分数>
gates: G1 pass · G2 pass · G3 pass · G4 pass · G5 fail (无偏离记录)
scores: 读解与形态 16 · 结构 15 · 排印 17 · 三声与图像 14 · 诚实与收尾 13 = 75
floor violations: 无
exemptions: P2 使用了 45% 墨色块（功能分类，已映射）
reviewer verdict: ship
notes: 缩略图第一眼落在标题而非主图；下一版把主图提高 1 行
```

首份记录见 [`run-001.md`](run-001.md)：B03 海报，自评 79，独立复审 63 / 72；失败促使 0.8 冻结材料、修改标题协议与自评规则。

## 6. 不能声称的事

- 不能因为 10 个 brief 通过，就声称"任何 agent 都会做出屋主的品味"。样本小，且审美有分布。
- 不能把机器 lint 通过当作审美通过；lint 只证明地板。
- 不能把一次漂亮成品当作契约有效；要看**同一条契约在缺材料、换介质、被施压时**是否仍成立。
- 不能隐藏失败样本。失败样本是下一版契约的素材，不是仓库的污点。

## 7. 发布门禁（改动契约时）

- L0 全绿；L1 至少 6/8 通过；L2 至少 2/3 通过且无未记录豁免；L3 至少 1 组通过。
- 至少 1 份公开记录包含一次失败、一次复审分歧与一次契约修正（见 `run-001.md`）。
- 与上一版对比：不得出现"为了通过新规则而牺牲可读性"的回归。
- 新增方言 / 表面时，补一条对应 brief 和最难一页的样本，才允许标 `stable`。
