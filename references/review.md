# 复核 —— 交付前的最后一道

## 1. 三条前提

1. **建稿线程不是唯一评审者。** 换一个新上下文（或另一个模型）复审成品，只给它本仓库的 `SKILL.md` 与 DESIGN.md；它能看出的毛病，说明契约没写好。
2. **lint 通过只是底线，不是品质。** 工程门禁无条件服从，审美门禁是启发式意见。
3. **自查评分设上限。** 自己给自己打分 ≥9/10 视为无效信号；只记录"哪里不合格"，不记录"我很满意"。

## 2. 两种门禁

| 类型 | 例子 | 性质 | 处置 |
|---|---|---|---|
| 工程门禁 | 语法错误、溢出、子元素超出父容器、画布尺寸、组件能力上限 | 机器限制，可物理验证 | 无条件修，必须 `ok: true` |
| 审美门禁 | 视觉模型判"过度留白 / 全局失衡 / 建议补充内容" | 启发式偏好，按像素密度猜构图 | 先判定，再决定改不改；**不得用填充换通过** |

不变量里**没有"填满画布"**。品质按本册声明的系统判定，不按通用密度判定。

## 3. 「留白审判」处置协议

### 3.1 先分清两类空白

| | 结构空白（合法，保留） | 塌陷空白（缺陷，修） |
|---|---|---|
| 成因 | 网格轴线、焦点呼吸、刻意的非对称 | 无轴线、无承重、元素漂在半空 |
| 判据 | 空白边界落在列线 / 基线上；围绕明确焦点；20% 缩略图第一眼仍落在计划元素 | 边缘对不上任何轨道；缩略图第一眼落在空处；相邻元素间距无规律 |
| 例 | 封面左侧大标题与右侧指标列之间的负空间 | 标题右下方一块无理由的空洞；页脚被 `marginTop: auto` 顶到底留下大缝 |
| 处置 | 保留，登记偏离 | 改网格变量 |

### 3.2 五步

1. **读原话，定位区域** —— 把 bbox 归一化坐标换算成页内位置，指出落在哪个网格区。
2. **判类型** —— 判据是轴线、焦点、缩略图第一眼，不是空白面积。
3. **结构空白 → 记录偏离，不改**。若管线强制 `ok: true`，走 §3.3 的结构性换通过。
4. **塌陷空白 → 只改网格变量**：调跨度、移动重物、拉大尺度极差、改垂直起点、加全宽基线 / 发丝线、调图片高度。**一次只改一个变量**。
5. **绝不做的三件事**：加装饰面板填坑；为凑密度编内容；把已成立的论证拆成更多块。

### 3.3 结构性换通过（允许 / 禁止）

允许（改结构，不改内容）：标题或导语提到全宽，压过空白区 · 放大既有视觉锚点让尺度极差承担构图 · 把游离元素吸附到列线与基线 · 延长发丝线给空白一个边界 · 调整内容区高度与页脚锚定。

禁止：加卡片 / 色块 / 图标 / 装饰线来"填" · 新增一段不服务论点的文字 · 把一页拆成两页只为降低空白率 · 为过检把正文调大或缩小，破坏 W(S)。

## 4. 四视角评审

| 视角 | 只问一句 | 不合格的判据 |
|---|---|---|
| **读者** | 这一页要我完成的动作，我完成了吗？ | 看完不知道要记住什么 / 要做什么 |
| **编辑** | 形态成立吗？证据与主张同轴吗？ | 把装饰删掉只剩文字，动作就完不成 |
| **排版** | 网格、排印、色彩有没有系统？ | 元素不吸附列线；出现第四色；一页 6 种字号 |
| **屋主** | 这是我（屋主）会认的东西吗？ | 遮住颜色和字体，就看不出是谁的 |

**屋主视角的硬测试：把颜色与字体换掉，仍应看得出同源。** 看不出 = 那只是皮肤，不是风格。

## 5. 偏离记录格式

任何对铁律、风格、本册 DESIGN.md 的偏离，都必须留痕。写进 DESIGN.md 末尾或交付说明：

```
偏离记录
- P03 折线页：报"99% 空白"[bbox 0,144,1000,733]。
  判定：结构空白 —— 图直接落在纸面、无白板，检测器把透明绘图区读成空白。
  处置：保留；代价：视觉检查不通过，人工目视确认图元与直标齐全。
- P12 词卡页：用了第二信号色（黄 + 蓝）。
  判定：并列类别 5 类 >3，需第二编码色。
  处置：黄=动物类，蓝=交通工具类，已写入 DESIGN.md；代价：三色相纪律收紧为"两信号色 + 语义绑定"。
```

## 6. 起飞检查（详版）

`SKILL.md §3` 的八条，展开判据：

| 检查 | 不合格的判据 |
|---|---|
| 已声明网格 | 说不出列数 / 基线 / 边距；元素位置是"看着差不多"调出来的 |
| 一套阶梯与唯一字重轴 | 出现两套字号系统；同一角色两种字号无页型理由 |
| 三个色相、一个信号色 | 出现独立灰 hex；一页两个强调色 |
| 装饰有构图职责 | 问"删掉它少了什么"，答不上来 |
| 数字有来源或标 illustrative | 有数字无单位 / 无基线 / 无来源，且未标注 |
| 文字可编辑 | 文字烤进图片或整块含字 SVG |
| 对比度与最小字号实测 | 靠"看起来还行"；投影介质正文 <26px |
| 输出与门禁实际验证 | "应该能过"；导出后未回潮检查（白底绘图板 / 图例回潮） |

最后一句：**发现问题只回修受影响的页**，不整册返工——除非问题出在宪法层（网格 / 阶梯 / 色板），那时才是整册。
