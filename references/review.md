# 复核 · 交付前的最后一道

## 1. 五条前提

1. **建稿线程不是唯一评审者。** 换一个新上下文（或另一个模型）复审成品，只给它 `SKILL.md`、DESIGN.md 和成品；它能看出的毛病，说明契约没写好。
2. **lint 通过只是地板，不是品质。** 工程门禁无条件服从；审美门禁是启发式意见。
3. **自查评分设上限。** 自己给自己 ≥9/10 视为无效信号；只记录"哪里不合格"，不记录"我很满意"。
4. **提供的文案是材料，不是草稿。** 标题、日期、地点、数字逐字核对；为版式改写即 G2 失败。
5. **复审问作品好不好，红队问门禁便宜不便宜。** 两者不能互相替代；高风险件先复审，再按 `red-team.md` 攻击门禁。

## 2. 三层审查

| 层 | 查什么 | 性质 | 处置 |
|---|---|---|---|
| **Floor** | `SKILL.md §2` 十六条 | 硬地板 | 任何一条出现即返工 |
| **Reflex** | `anti-patterns.md` 的 `reflex` 条 | 模型默认 | 默认避免；有理由可豁免，必须记录 |
| **Finish** | 网格、排印、图注、来源、导出 | 工艺细节 | 逐条回答；不阻塞，但不许沉默 |

工程门禁（语法错误、溢出、画布尺寸、组件上限）单独列：机器可验证，必须 `ok`。

## 3. 审查顺序

1. **机器检查** — 溢出、对比度、字号、行宽、链接、导出格式。
2. **Floor** — 十六条逐条过；例外看记录。
3. **形态** — 每个单位是否只有一个主形态；形态与内容用途是否一致。
4. **决定性动作** — 能用一句话说出吗？它承担排序、证据还是节奏？说不出，退回 `SKILL.md §3.5`。
5. **方言** — 是否整套采纳；签名动作是否出现；有没有混入第二个方言；母题是否贯穿。
6. **四视角** — 见 §5。
7. **换上下文复审** — 见 §6。
8. **只修受影响单位** — 除非问题出在宪法层（网格 / 阶梯 / 色板）。

## 4. 「留白审判」处置协议

### 4.1 先分清两类空白

| | 结构空白（合法，保留） | 塌陷空白（缺陷，修） |
|---|---|---|
| 成因 | 网格轴线、焦点呼吸、刻意的非对称 | 无轴线、无承重、元素漂在半空 |
| 判据 | 空白边界落在列线 / 基线上；围绕明确焦点；缩略图第一眼仍落在计划元素 | 边缘对不上任何轨道；缩略图第一眼落在空处；相邻间距无规律 |
| 例 | 封面左侧大标题与右侧指标列之间的负空间 | 标题右下方一块无理由的空洞；页脚被 `marginTop: auto` 顶到底留下大缝 |
| 处置 | 保留，登记 | 改网格变量 |

### 4.2 五步

1. **读原话，定位区域** —— 把 bbox 换算成单位内位置，指出落在哪个网格区。
2. **判类型** —— 轴线、焦点、缩略图第一眼，不是空白面积。
3. **结构空白 → 记录，不改。** 若管线强制通过，走 §4.3。
4. **塌陷空白 → 只改网格变量**：跨度、重物位置、尺度极差、垂直起点、全宽基线、图片高度。一次只改一个。
5. **绝不做的三件事**：加装饰面板填坑；为凑密度编内容；把已成立的论证拆成更多块。

### 4.3 结构性换通过（允许 / 禁止）

允许（改结构，不改内容）：标题或导语提到全宽 · 放大既有视觉锚点 · 把游离元素吸附到列线与基线 · 延长发丝线给空白一个边界 · 调整内容区高度与页脚锚定。

禁止：加卡片 / 色块 / 图标 / 装饰线来"填"；新增不服务论点的文字；把一页拆成两页只为降低空白率；为过检调大或调小正文，破坏字重轴。

## 5. 四视角 + 屋主

| 视角 | 只问一句 | 不合格的判据 |
|---|---|---|
| **Müller-Brockmann** | 网格与流动成立吗？ | 元素不吸附列线；视线没有按重要性行进 |
| **Ruder** | 排印经得起近距离读吗？ | 阶梯不成立；行宽失衡；标点与字距粗糙 |
| **Tufte** | 每一滴墨都承担信息吗？ | 图表有装饰无比较；数据无来源；图例替代直标 |
| **Brodovitch** | 有节奏吗？ | 每个单位同一个音量；没有停顿、转折、爆发 |
| **屋主** | 遮住颜色和字体，还认得出吗？ | 认不出 = 只是皮肤，不是风格 |

## 6. 换上下文复审

### 6.1 给复审者的材料

- `SKILL.md`（必给）
- 项目 `DESIGN.md`（必给）
- 成品（图 / 文 / 链接）
- **不给**建稿者的解释与辩护。解释会污染判断。

### 6.2 复审提示词（可直接用）

```
你是 Folio 的复审者。只读 SKILL.md、DESIGN.md 和成品，不读建稿者的说明。
按顺序回答：
1. Floor：§2 十六条有没有出现？逐条 yes/no，出现即指出位置。
2. 形态：每个单位的主形态是什么？与内容用途一致吗？
3. 方言：整套采纳了吗？有没有第二个方言混入？
4. 决定性动作：每个单位能用一句话说出吗？它在承担排序、证据还是节奏？
5. 四视角：Müller-Brockmann / Ruder / Tufte / Brodovitch 各指出一个最强项和一个最弱项。
6. 屋主测试：遮住颜色和字体，还认得出这是同一套系统吗？
7. 内容保真：对照 brief 逐字核对标题、日期、地点、数字；有改写或缩写吗？
8. 只给三个最该修的点，按影响排序；不要给泛泛的赞美。
最后给一个词：ship / fix / rebuild。
```

### 6.3 处置

- `fix` → 只修被指出的单位；修完复看一次。
- `rebuild` → 先检查是不是宪法层出错（网格 / 阶梯 / 色板 / 方言选错），再决定重做范围。
- `ship` → 仍要自己过一遍 Floor；复审者不是免责声明。

## 7. 偏离记录

任何对铁律、方言、DESIGN.md 的偏离，都必须留痕。写进 DESIGN.md 末尾或交付说明：

```
偏离记录
- P03 折线页：报"99% 空白"[bbox 0,144,1000,733]。
  判定：结构空白——图直接落在纸面、无白板，检测器把透明绘图区读成空白。
  处置：保留；代价：视觉检查不通过，人工目视确认图元与直标齐全。
- P12 词卡页：用了功能色（黄 + 蓝）。
  判定：并列类别 5 类 >3，需第二编码色。
  处置：黄=动物类，蓝=交通工具类，已写入 DESIGN.md；代价：三声纪律收紧为"两功能色 + 语义绑定"。
- P07 章节页：破格 07 字里有照片。
  打破：字与图分离；理由：主题是"被看见"；代价：真实标题另置 32px。
```

## 8. 完成定义（详版）

| 检查 | 不合格判据 |
|---|---|
| 读解 / 材料 / 方言三行 | 没写；或写了但与成品不符 |
| 网格已声明 | 说不出列数 / 基线 / 边距；位置是"看着差不多" |
| 一套阶梯与字重轴 | 两套字号系统；同一角色两种字号无理由 |
| 三声、一个信号 | 独立灰 hex；一页两个强调色；功能色无映射 |
| 决定性动作 | 说不出；或只是装饰；或与主张无关 |
| 装饰有职责 | 问"删掉它少了什么"，答不上来 |
| 数字有来源或 illustrative | 有数字无单位 / 无基线 / 无来源，且未标注 |
| 提供的文案 | 为版式改写标题 / 日期 / 地点；或没有逐字对照 brief |
| 文字可编辑 | 正文烤进图片；整块含字 SVG |
| 对比与字号实测 | 靠"看起来还行"；投影正文 <26px |
| 换上下文复审 | 没做；或只让建稿者自己看 |
| 输出实际验证 | "应该能过"；导出后未回看 |

最后一句：**发现问题只回修受影响的单位**，不整册返工——除非问题出在宪法层。
