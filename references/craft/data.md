# Data

A chart supports a question or finding; a table serves lookup. For an argument, the consulting exhibit is a starting voice: Zelazny's *Say It With Charts*, Minto's pyramid, Tufte's data-ink, IBCS notation. Exploratory and reference work follow their own reading tasks.

## Charts

- **The title serves the task, not a formula.** Argument charts state the finding; exploration and lookup name the question or measure. A consulting exhibit reads: action title, unit line, chart, source and notes.
- **The comparison picks the form, not habit.** See the table below.
- **Emphasis follows the reading task, not what is newest or largest.** Color may distinguish categories or encode quantity; context recedes without hiding required comparisons. Keep meanings consistent and provide a non-color cue.
- **Geometry is honest, not dramatic.** Bars from zero; cut axes are marked; shared comparisons use shared scales. Prefer aligned panels to dual axes; any separate axes name their units and scales. Grid lines aid reading without competing with data.
- **Labels minimize lookup, not follow a fixed count.** Prefer direct labels; use a legend when it reads more clearly. Annotate what the question needs; order by value or the reader's lookup logic.
- **Notation is declared, not reinvented per chart.** When IBCS is selected: actual solid, earlier periods lighter, plan outlined, forecast hatched. Sequential data steps lightness; diverging data separates around a midpoint; never red–green alone.
- **Precision serves the decision, not the source dump.** Percent is not percentage points; rates name their denominator; missing is not zero; demo numbers say `illustrative`.

| Question | Use | Not |
|---|---|---|
| Which is bigger | Bars (long labels), columns (short) | Pie, donut, 3D |
| How it changed | Line; area when magnitude from zero matters | Unmarked scale changes, invented smoothing |
| How it is distributed | Histogram, box, strip plot | A lone average |
| Whether two things relate | Scatter | Correlation sold as cause |
| What it is made of | Stacked or 100% bar | Pie, treemap without hierarchy |
| How a total moved | Waterfall, signed variance bars | Two pies |
| Share and size at once | Marimekko | Bubble clouds |
| How far from a baseline | Diverging bar | Gauge |
| How uncertain | Intervals, error bars | Bare points |
| Many small groups | Small multiples | Twelve lines in one plot |

## Tables

Align numbers on the decimal, name units in the header, and distinguish totals. Space and rules expose the relationships; the theme sets their treatment. Reference tables keep stable widths, order, and repeated headers.

## Dashboards

A dashboard is a ranked scan, not a gallery of cards: what one objective needs, on one screen, at a glance (Few, *Information Dashboard Design*).

- **Salience follows the reader's priorities, not equal tiles.** Rank the questions first; position, size, and accent then spend themselves in that order.
- **The task picks the encoding, not the template.** A value someone acts on is a number; a direction or pattern is a chart; a value without a comparison is noise. A row of big-number cards is a default, not a hierarchy.
- **A measure and its comparison are one module, not neighbors.**
- **Modules take the width their content needs, not an equal share.**
- **Attention follows real exceptions, not every module.** Status has explicit labels and a redundant code; precise comparisons use aligned positions or lengths.
- **A narrative leads with one question; a monitor holds a layout that never moves.** Both show source and as-of time, and design empty, loading, stale, and error states.

Exemplars: Hilfiker's SBB station clock, the Swiss FOPH Covid-19 dashboard (Interactive Things), Tufte's *Beautiful Evidence*, the *Financial Times* and *NZZ* data desks.
