# 色彩

颜色不是装饰，是语义。三种声音：纸、墨、一个信号。

## 1. 三种声音与面积

| 声音 | 角色 | 典型面积 | 说明 |
|---|---|---|---|
| **纸** Paper | 底 | ≥50% | 阅读发生的地方 |
| **墨** Ink | 字、线、场 | 结构 | 可以是字，也可以是满版 |
| **信号** Signal | 标点 | 常规 ≤10%，主张 ≤20% | 一个构图只有一个 |

超过这个面积，信号就不再是信号，而是第二种纸。整页红、整页蓝，只有在破格 01/05 里成立，且要付出代价。

**面积复算**：信号占比 = 信号像素面积 ÷ 画面面积。deck 上一条 8×600px 的红线 = 4,800 ÷ 921,600 ≈ 0.5%；一块 200×100px 的色块 = 2.2%。10% 是上限，不是目标。

## 2. 中间调：墨的透明度

不写独立灰 hex。用墨的透明度派生：

| 名称 | 值 | 用途 |
|---|---|---|
| Muted | Ink + 0.62 | 次级标签、来源、注释 |
| Secondary | Ink + 0.78 | 浅底上的强次级；深底换成 White 0.78 |
| Rule | Ink + 0.12–0.16 | 发丝线、表格线 |
| Disabled | Ink + 0.38 | 禁用态（web） |
| Hover | Ink + 0.08 | hover 底（web） |

深底上：White 1.0 主张 / 0.78 正文 / 0.62 次级。不要把 Ink 叠在深底上，那不是"深色文字"，是消失。

**白纸复算（派生结果，只用于验收，不得写成 token）**：Muted = `#6B6B6B`（5.3:1）；Secondary = `#454545`（9.6:1）；Disabled = `#A5A5A5`（2.5:1，仅禁用）；Rule = `#D9D9D9`–`#E2E2E2`（1.3–1.4:1，仅结构线）。Muted 是正文次级的下限，再低只能用于非文字。

**深底复算**：White 0.62 压 `#111` 约 7.8:1；White 0.78 约 11.4:1；White 1.0 为 18.9:1。

## 3. 信号色怎么选

按内容气质，不按心情；一个项目只选一次。

| 气质 | 值 | 注意 |
|---|---|---|
| 主张、风险、宣言 | `#C83024` | 默认；低质投影可提到 `#D5231E`，实测 |
| 理性、数据、机构 | `#0057FF` | 慎用于低龄，易读成 SaaS 蓝 |
| 活力、儿童、公共活动 | `#FFD400` | 墨字压黄 13.2:1；只做块面，不做小字 |
| 生长、自然、科学 | `#00693E` | 块面 + 白字 |

**一个项目一个信号。** 第二个色相只能是：纸的暖冷（材料）、功能类别色（有映射）、或破格里的叠印（有记录）。三者都要在 DESIGN.md 写清楚。

**信号上的字（实测）**：`#C83024` 上白字 5.4:1，墨字 3.5:1（只大字）；`#0057FF` 上白字 5.5:1；`#00693E` 上白字 6.8:1；`#FFD400` 上墨字 13.2:1，白字不可用。

## 4. 纸是材料

纸的暖冷不是第四个色相，是介质。

- 屏幕默认纯白 `#FFFFFF`；暖白需要理由，并重新测对比。
- 印刷可用 `#F7F5F0`（暖纸）、`#F2F0EB`（石色）、`#F7F3E8`（米纸）；必须在 DESIGN.md 声明"这是纸"。
- 投影、低质屏不用暖白：会被洗掉，白字也会脏。
- 纸的颜色会影响所有印刷色；打样才算数。

## 5. 对比度

| 内容 | 最低 | 目标 |
|---|---|---|
| 正文（<24px / <18.66px bold） | 4.5:1 | 7:1 |
| 大字（≥24px / ≥18.66px bold） | 3:1 | 4.5:1 |
| 非文字（线、图标、焦点框） | 3:1 | 4.5:1 |
| 信号块上的黑字 | 7:1 | 10:1 |

**测试方法**：用实际值算，不靠眼睛；再做一次灰度测试——去掉色相，层级还成立吗？不成立，说明你在靠颜色做层级。

## 6. 功能色

只在真实需要分类 / 状态时使用（默认限 `public-info` / 导视场景），最多三色，必须有映射：

```
红 = 禁止 / 危险
绿 = 通行 / 安全
蓝 = 信息 / 方向
```

规则：
- 没有映射表，不许用功能色。
- 功能色不承担装饰；不做图标底色；不做标题颜色。
- 不使用颜色作为唯一编码：同时给文字、形状或位置。
- 红绿色盲测试：红/绿必须能被明度或形状区分。

## 7. 印刷

- CMYK；总墨量 ≤300%（ coated 常用 280–300%，uncoated 更低）。
- 小字与细线用 100K 单黑，不用四色黑，避免套印虚边。
- 大面积黑用 rich black：`60C 40M 40Y 100K`；总墨量按纸与厂规调整。
- 信号色如果是品牌色，优先专色；四色近似要在打样后确认。
- 3mm 出血；5mm 安全区；大面积实地色要检查墨杠与透背。
- 不在 CMYK 里用 RGB 霓虹（`#00FFFF`、`#FF00FF` 一类），印不出来。

## 8. 屏幕

- sRGB 为准；不要用 P3 才有的荧光色做信号。
- 颜色写成 token：`--paper` / `--ink` / `--signal` / `--muted` / `--rule`；不写散落 hex。
- 暗色模式是场的反转，不是第二套色板：纸 ↔ 墨，信号不变；对比重新测。
- 焦点框用信号色或墨，2px，`focus-visible` 立即出现，不用动画。
- 渐变禁用（除功能性 scrim）；不要用 `filter: drop-shadow` 做"层次"。

## 9. 数据色

- 类别 ≤5；超过 5 类，合并或改用位置/直接标注。
- 顺序数据用单色阶（墨的透明度或信号色的明度阶）；发散数据用双色阶，中点为纸。
- 不用彩虹色阶；不用红绿作为唯一对比。
- 强调一个系列：用信号色；其余用墨的透明度。不要把每个系列都涂成不同颜色。
- 直接标注优先于图例；颜色只是辅助。

## 10. 失败样本：信号色变成层级色

一页里红色同时用于标题、当前项、按钮和一条图表线。四个红色互相竞争，观者不知道哪个是"例外"；灰度测试后层级完全消失。

修正：只保留一个红色语义（当前项）；标题回墨；按钮用墨底白字；图表线用墨的透明度。信号从 4 处降到 1 处，面积仍 <1%。

## 11. 检查

- [ ] 只有纸、墨、一个信号；功能色有映射
- [ ] 中间调全部由墨派生；没有独立灰 hex
- [ ] 信号面积在预算内；一个构图一个信号
- [ ] 对比度实测；灰度测试层级仍成立
- [ ] 纸的暖冷已声明；屏幕 / 印刷分开
- [ ] 印刷总墨量、rich black、专色已确认
- [ ] 暗色模式是场反转，不是第二套色板
- [ ] 数据色 ≤5 类，颜色不是唯一编码
