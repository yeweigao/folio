# brutalist — structure as content

Brutalist web design, 2014–: Pascal Deville's brutalistwebsites.com, with Craigslist and the Drudge Report as raw precedents; after the *béton brut* of Le Corbusier and Alison and Peter Smithson. It inherits the [mother tongue](../mother-tongue.md) and replaces only these rules, across the whole piece:

- **Defaults are honest, not unfinished.** System fonts, monospace for code and values, browser-blue links, native controls.
- **Structure shows, not hides.** Grid, borders, and container edges drawn at one weight; a box is allowed when it is the real structure.
- **Dense, not airy.** Tables, specs, versions, and raw screenshots; nothing styled to impress.

**Test:** Every visible line and box is a real boundary.

**Caricature:** Terminal cosplay: green on black, scanlines, noise; ugliness on purpose; broken layouts called raw.
