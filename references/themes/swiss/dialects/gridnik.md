# gridnik — type built from the grid

Wim Crouwel and Total Design, Amsterdam, 1963–1980s: the Stedelijk Museum posters and catalogues, the New Alphabet (1967), the *Vormgevers* poster (1968). It inherits the [mother tongue](../mother-tongue.md) and replaces only these rules, across the whole piece:

- **Letters are built from the grid, not set on it.** Display letters assemble from the page's cells: one stroke, square corners or one radius; the word also stands as live text.
- **The grid prints, not hides.** It shows faintly on display units; every edge lands on it.
- **System outranks familiarity at display size, not in reading text.** Words still break where their syllables do, not where the cells run out.

**Test:** Overlay the grid, and every stroke and text edge lands on it.

**Caricature:** Neon wireframes, dot-matrix on black, synthwave gradients; a word split wherever the cells run out.
