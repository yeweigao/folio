# ulm — the system decides

The Hochschule für Gestaltung Ulm, 1953–68: Max Bill, Otl Aicher, Inge Aicher-Scholl, Tomás Maldonado, Hans Gugelot; Braun's products with Dieter Rams, Aicher's Lufthansa identity (1962) and Munich 1972 Olympics. It inherits the [mother tongue](../mother-tongue.md) and replaces only these rules, across the whole piece:

- **The system is the design, not the page.** Rules for every case come first; each unit is one application another designer could extend.
- **Function justifies every difference, not taste.** Same function, same treatment; each difference in size, color, or position has a nameable reason.
- **Color and pictograms are codes, not accents.** A few mapped colors in a legend, never the only cue; one pictogram set of solid figures built on a modular grid at 0°, 45°, and 90°.
- **Instruction, not expression.** One grotesque, after Univers; short unambiguous lines; the primary language above, the second below, never in one line.

**Test:** A stranger knows what to do next, and a designer could apply the rules to a new case.

**Caricature:** Sports pictograms and the Munich palette pasted onto an ordinary page; UI line icons; three kinds of arrow.
