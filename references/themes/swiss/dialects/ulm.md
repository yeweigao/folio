# Ulm — the system decides

**Invocation:** 乌尔姆设计学院 HfG Ulm — Make work as Aicher made the Munich 1972 system: write the rules before drawing any case, color only as a labelled code, pictograms on one modular grid that a stranger could extend; never a difference without a nameable reason.

The HfG Ulm, 1953–68: Max Bill, Otl Aicher, Tomás Maldonado, Hans Gugelot; then Braun with Dieter Rams, and Aicher's Lufthansa identity and Munich 1972 Olympics. Spoken in Swiss, Ulm moves the decision from the page to the system: one set of rules, applied to every case.

- **The system is the design, not the page.** The rules for every case come first; each unit is one application another designer could extend.
- **Function justifies every difference, not taste.** Same function, same treatment; each difference in size, color or position has a nameable reason.
- **Color and pictograms are codes, not accents.** A few mapped colors, decoded by direct labels or a legend and never the only cue; one pictogram set of solid figures on a modular grid at 0°, 45° and 90°.
- **Instruction, not expression.** Short, unambiguous lines; the primary language above, the second below, never in one line.

**Hands in this school.** One governs; the others visit as single moves.
- **Otl Aicher — the Munich 1972 system.** Write the manual first: the color code and its legend, the grid the pictograms are drawn on, the path the visitor walks. Then generate every case from it. Suits events, places and instructions that a stranger must use. Never: three kinds of arrow.
- **Max Bill — concrete art, the Ulm building (1953–57).** State one law, and produce every form as a systematic variation on it. Suits series and identities that must extend. Never: a shape whose rule cannot be stated.
- **Tomás Maldonado — the Ulm model (1958–66).** Model the problem's structure (users, tasks, decisions) before any surface, and let the layout follow the model. Suits complex information and data. Never: styling applied to an unstructured brief.

**Swiss keeps:** the grid, one neo-grotesque, asymmetry, and the rule, now used as a code.

**Test:** A stranger knows what to do next, and a designer could apply the rules to a new case.

**Caricature:** Sports pictograms and the Munich palette pasted onto an ordinary page; UI line icons; three kinds of arrow.
