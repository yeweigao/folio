# isotype — statistics as pictures

*A dialect of the Swiss theme: it inherits [the mother tongue](../mother-tongue.md) and changes only what it names.*

Otto Neurath and Gerd Arntz's International System of Typographic Picture Education (Vienna, 1920s–40s): quantities shown by repeating a symbol, so a reader who barely reads can still compare. "Words divide, pictures unite." For education, public reports, parent communications, reviews for non-specialists, at 0.5–5 m; not for precise analysis on axes, fashion, or manifestos.

## What makes it isotype

- **More means more symbols, not bigger symbols.** Every symbol is the same size and stands for a stated quantity; a partial quantity cuts a symbol, never shrinks it.
- **One pictogram family, not a set of styles.** Flat, frontal or profile, on a square module.
- **Owner's test:** a ten-year-old can say which row is bigger and roughly by how much.

## House values

- Rows read left to right on a shared baseline; a key states what one symbol equals; exact values at row ends.
- Ink for all symbols; the accent for the row under discussion; at most three mapped category colors, with a legend.
- Type in the mother tongue's heavy mode.
- Voice: plain, concrete, child-readable.

## Caricature

Icon salad: mixed 3D icon styles, one icon scaled up for a big number, donuts and gauges beside clip art, decorative arrows. Refuse it; scaling area exaggerates the value.

## Latitude

Free: the unit per symbol, row order, which row takes the accent. Say so for a second family, perspective, or more than three category colors.
