# isotype — statistics as pictures

Isotype, the Vienna Method, 1925–1940s: Otto Neurath, Marie Neurath, Gerd Arntz; *Gesellschaft und Wirtschaft* (1930). "Words divide, pictures unite." It inherits the [mother tongue](../mother-tongue.md) and replaces only these rules, across the whole piece:

- **Pictures count, not axes.** A quantity is a row of equal symbols on a shared baseline; a key says what one stands for; exact values close each row.
- **More means more symbols, not bigger ones.** A partial quantity cuts a symbol, never shrinks it.
- **One family drawn like Arntz, not icons.** Flat frontal or profile silhouettes on a square module, in ink; color only names a category, three at most.
- **Words a child reads, not jargon.** The picture carries the comparison.

**Test:** A ten-year-old can say which row is bigger and roughly by how much.

**Caricature:** Icon salad: mixed 3D icon styles, one icon scaled up for a big number, donuts beside clip art.
