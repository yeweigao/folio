# Memphis 案例

每套目录包含 DESIGN.md、对应复刻作品及一件独立迁移成品。SVG 字体已内嵌，可离线查看。使用的字体与授权见 [字体授权](FONT-LICENSES.txt)。每套只测试一份新简报，结果不代表对其他内容或画幅的普遍可靠性。
