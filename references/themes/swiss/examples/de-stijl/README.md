## 怎样复刻

先按共享构造区分作品，再重画线、色面、标题、正文、表格、图表和时间线；照片与少量线描仅从用户参考的物象区域裁取，没有把整页截图贴入成品。截图的手机界面、拼图背景、展示阴影与外部水印不属于作品版面。

参考里的可读主文案与构图得到重建，未知原字体使用授权替代。低清缩略图中的微小占位文案、特殊字标、构字细节及局部照片裁切存在近似，不能声称逐像素或逐字一致。课程截图缺少第 3/5 组，没有补造那组原作。17 张参考分别含有多页作品，69 指可见页面数，不是原始 PPT 文件页数鉴定。

这些是现代 De Stijl-inspired 应用。圆、三角、照片、暖纸底或多种字体来自各自参考，不因此归为蒙德里安本人的方法。部分参考带“大杯冰美PPT出品”等署名；完整原作者、摄影者、原字体与源 PPT 未确认，本项目不声称这些版式为原创。字体声明合并在 [FONT-LICENSES.txt](FONT-LICENSES.txt)。

## 验证了什么

每套冻结一份 DESIGN.md，另给全新上下文同一份新简报及一张预先声明的概念材质图。制作者没有参考图片、旧作品或绘图组件；新内容为完整双段正文、四行数据表和五阶段时间线，共三页。数据明确标为模拟数据，概念材质图不作为实物证据。

主流程独立渲染并检查采用稿。完整段落、固定文字、数据行、字级、字体、画幅边界和可见遮挡分别核对。参考中的极小正文没有作为未来 PPT 的默认下限；新作正文至少 20 px。每套只用一份简报，不代表所有主题、语种、密度或幅面均可靠。

测试暴露并修正了两项交接问题：提案的大圆母题与时间线小节点应分别定尺寸，粗／细线的量级应与复刻相符；画册拼片内部应明确只用原色与黑，白场属于拼片外的阅读区。现有新作由主流程按澄清后的规则调整并重渲染，最初生成稿留在本地记录中；这些最终澄清尚未用另一个新上下文再次生成。构字封面的原参考只有一页，它的三页新报告验证的是推导出的内页扩展，不是复刻了未提供的原作内页。

独立制作者在末轮遇到服务使用额度限制：已生成的五组 SVG 由主流程完成最终检查，未完成独立身份／审美盲评，也未完成旧方言、候选方言与无方言的三路生成／盲排。固定简报位于仓库 `tests/de-stijl-report.md`。因此这里只说明已做到的构造迁移与可读性检查，不宣称新版审美或平均可靠性优于旧版。
