# Apple + Bento style — many features in one glance

**Invocation:** Apple + Bento — Make the grid as the homepage's is made: many features on one page, tiles sized by importance, one claim per tile, specifications as small posters; never a wall of equal cards, or a table in disguise.

Bento is the community's name for the grid Apple popularised after 2022, not Apple's term. It is a layout method, not a dialect: it visits any dialect or surface for a unit with many features to show at once. The page becomes a grid, the tile a card sized to its claim.

- **One tile, one claim, sized by importance.** The lead takes the wide tile; supporting features, small tiles; a specification, a number tile — display number, small muted label, one quiet line of context. A tile that needs a legend, a footnote or a second claim is a slide.
- **Specifications are posters, not rows.** Never a table row inside the grid; numbers at one size across tiles, so the grid scans by number alone.
- **An index, not proof.** Each tile's claim is proved in a following unit, or the tile carries its checkable figure.
- **Locally dense, globally loose.** A tight grid in generous air, judged by whether every tile still reads at a glance.
- **Rounding follows the surface.** Homepage promo tiles sharp and full bleed in a white gutter; feature cards inside a page on the ladder, images clipped to them.
- **Showroom takes it on range units only:** one object and one price per tile, never on a single-object hero.

**Hands in this school.** One governs; the others visit as single moves.
- **The homepage hand — the promo grid.** Full-width heroes over two-column tiles, grounds alternating; the grid itself argues that the range is one family. Suits landings and overviews. Never: every tile shouting at one size.
- **The gallery hand — the feature gallery.** Equal cards in a scrolling row, a wide card after them for the feature that earns more room. Suits walkthroughs and highlights. Never: a gallery that must be read in order.
- **The data hand — the number tile.** One number at display size, label beneath, context in one line, comparable across tiles without a table. Suits specs and proof. Never: a number without a label.

**Apple keeps:** the single accent, the ramp with weight as hierarchy, parchment and near-black grounds, the product shadow inside a card, the radius ladder.

**Test:** Cover the numbers: the tiles still read as features, in order of importance. Cover the photographs: claims and numbers still compare without a table.

**Caricature:** equal cards with equal claims; a rainbow tile; a table disguised as a grid; a gradient wallpaper behind the tiles; a number with no label; a mosaic read like a spreadsheet.
