# Apple + Developer style — the tool proving itself

**Invocation:** Make work as a developer tool's homepage is made: Apple as the base, then one brand from this industry as the governing hand, chosen by what the input actually does; the interface proves the claim, the headline states the action, and the technical voice never speaks for the whole page; never a photograph hero, never a gradient wallpaper, never a second accent.

The developer industry, from deployment platforms to issue trackers to databases to design and workspace tools. What separates it from other industries is that its proof is not a photograph or a price but a working interface: a deployment, a list of work, a table, a canvas, a document. Spoken in Apple, it keeps the single-accent discipline, the weight-led hierarchy and one lead per screen, and turns the gallery into a front door where the visitor can see the tool working before being asked to act.

Choose this dialect when the input is software a developer, designer or team uses to make something: a platform, a tool, a workflow, a database, a canvas, a workspace. Then choose one brand inside it as the governing hand, by what the input does — not by which brand is most famous, and not by picking two at once.

- **The industry is the router; the brand is the look.** Industry names the kind of proof — an interface, a list, a table, a canvas — and the brand hand supplies the philosophy: ground, accent, type voice, button shape, decoration. A developer dialect that names no brand has no look; a brand used without the industry's proof has no reason.
- **One governing hand per work.** The chosen brand governs the whole work; other brands in this industry visit only as single moves, one detail each. Two governing brands on one unit — Vercel's gradient words over Linear's dark panels, for example — is two dialects, not one.
- **The interface is the hero, in some form.** A deployment preview, an issue list, a database table, a design canvas, a workspace document — the form changes with the brand, but the proof never becomes a lifestyle photograph or an abstract illustration.
- **A technical voice exists, and it stays technical.** Mono, labels, shortcuts, states and code appear where the tool is named or shown working, never as the headline, the tagline or the body. The technical voice proves; it does not speak for the page.
- **No values are specified here.** Ground, accent, type and button shape are drawn from the chosen brand's own knowledge, checked against that brand's philosophy below. A value that contradicts the philosophy is wrong even if it matches a remembered brand detail.

**Hands in this school.** One governs; the others visit as single moves.
- **Vercel — the developer's front door.** A light ground, gradient words on the headline's verbs at hero scale, the product interface below as proof, mono only for technical labels, a full pill for the marketing action and small square-ish controls for tools. Suits deployment platforms, dev tools and anything whose claim is an action performed by software. Never: a dark page, a gradient on a button or a card, a photograph hero.
- **Linear — the engineering document.** A dark canvas in surface steps separated by hairlines, one lavender accent used only for action and focus, the interface itself in charcoal panels as the hero, modest rectangular buttons never pill. Suits issue trackers, workflows, queues and any tool whose claim is that a system works well. Never: a light section, a gradient wash, a pill button, a photograph hero.
- **Supabase — the database as proof.** One green as the only chromatic event against greyscale, product interface and code shown working, soft rectangular buttons never pill, dark code blocks. Suits databases, backends and APIs. Never: a second accent, a pill primary, a hero without a table or a code block in it.
- **Figma — the canvas as rhythm.** A monochrome black-and-white core, pastel colour blocks as the page's rhythm, a variable sans at fine weight steps with tight tracking, mono uppercase labels, pill as the only button shape, the design canvas with collaboration cues as hero. Suits design tools and collaborative canvases. Never: a single accent pretending to be the system, a saturated colour block where a pastel one belongs, a hero without a canvas.
- **Notion — the workspace as hero.** A deep navy hero band, a purple pill call to action, pastel feature cards, a neutral Inter-based sans with modest buttons that are not pill, a workspace interface as hero. Suits workspaces, documents and team knowledge. Never: a white-only hero that loses the navy band, a black button pretending the purple pill does not exist, pastel cards treated as decoration rather than features.

**Master edition rules.** Internal padding is never zero: text never touches its box edge, and title boxes are taller than their type so descenders clear. A gradient verb lives at hero scale only, on the verb itself, never as a wallpaper and never on a button or card; a technical label alone may use the mono face, never body copy. An interface crop shows the whole frame, letterboxed rather than cut at its edges; an abstract placeholder-bar interface is not proof, because proof must be readable. A figure that overflows in one renderer is checked in the other renderer as well, not assumed safe. Where tabular setting is unavailable, figures align in a right-aligned column so decimals line up, and tabular setting is never claimed from a file that cannot set it.

**Alignment and accent, restated.** When a hand from this dialect governs, its single accent replaces every Apple blue role for that work, and Apple blues retire for that work. Body, leads, captions, card names and prices are flush left, ragged right, in every surface and format; only a hero, vista or cover headline may centre.

**continuous corner:** A hand may choose square forms; every nonzero radius uses Apple continuous corner. Radius sets size, not contour. Nested corners share their centre and subtract the gap from the outer radius for the inner one. Use the theme's native API or continuous corner path; plain circular rounding and a superellipse are forbidden. Write this construction into the standalone DESIGN.md.

**Apple keeps:** the single-accent discipline, weight doing the hierarchy, whitespace as divider, one lead per screen, the product or its interface as the visual focus.

**Test:** Cover the brand name: the industry proof — interface, list, table or canvas — still reads, and the philosophy of the chosen hand still holds. Swap the governing hand: the same input must look like a different brand, not the same page with a colour changed.

**Caricature:** a photograph hero for a tool; two governing brands on one page; a gradient wallpaper; mono body copy; a pill on every control in a Linear work, or a square button on a Vercel hero action; a second accent colour.
