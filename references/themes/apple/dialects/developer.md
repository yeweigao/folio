# Apple + Developer style — the tool proving itself

**Invocation:** Apple + ‹brand› style — Make the page as ‹brand›'s front door is made: the tool seen working is the proof, and the headline says what it does; never a photograph hero or a second accent.

Software people make things with: deployment, issues, databases, canvases, workspaces. Its proof is neither a photograph nor a price but the tool at work.

**What the industry overturns in Apple**
- **The interface replaces the product photograph.** Real, readable, shown whole at gallery scale; placeholder bars prove nothing.
- **The headline is the action** the software performs, short and large above the proof.
- **A technical voice exists** — mono, shortcuts, states, code — inside the proof only, never in headline or body.

**Brands.** One governs; the name carries its look, the signature anchors it.

- **Notion — the page you build.** Signature: black type on white; the workspace page mid-assembly as hero, its blocks visible; black ink-line drawings of people beside the proof; its blue on the one action. Goes wrong as: an emoji on every heading; a beige document with a sidebar and no claim; the drawing as the hero; a grid of equal feature cards.
- **Vercel — the deploy in front.** Signature: black and white with a geometric sans; gradient only on one hero-scale word; the terminal and the live preview as proof. Goes wrong as: a gradient mesh wallpaper; a glowing grid behind everything; gradient on buttons; a link blue posing as its accent.
- **Linear — the engineering document.** Signature: a near-black canvas in surface steps; the app itself at full width as hero; one restrained indigo accent; modest rectangular buttons. Goes wrong as: purple glow and blur on every section; floating cards as hero; pills.
- **Supabase — the database as proof.** Signature: dark, one green the only chromatic event; tables and code shown working. Goes wrong as: green spent on fields; a hero with no table or code in it.
- **Figma — the canvas as rhythm.** Signature: a black-and-white core paced by saturated colour blocks; the canvas with live cursors as hero; pill the only button. Goes wrong as: rainbow on every unit; cursors as decoration with no canvas under them.

**Apple keeps:** one lead per screen, weight as hierarchy, the change of ground as divider, the single accent.

**Test:** Cover the brand name: a designer still names the brand. Swap the brand: the same input becomes another site, not the same page recoloured.

**Caricature:** a photograph hero for a tool; mono body copy; a dark gradient hero with three icon cards; two governing brands.
