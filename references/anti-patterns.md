# 反模式登记册

`SKILL.md §2` 是禁令的**一行版**（机械执行用）；本文件是每条的**为什么与替代程序**（撞墙时查）。

## 读法

- `banned` = 出现即返工；`warned` = 需要显式理由才能用，理由写进 DESIGN.md 偏离记录。
- `data-backed` = 有可验证危害（可读性、可访问性、工程限制）；`owner-taste` = 屋主口味禁令。**两者必须区分标注**，不把口味伪装成数据。
- 替代给的是**程序**（先做什么、再做什么），不是"换个更好看的 X"。

---

## AP-001 · 白卡片 / KPI 磁贴 — `banned` · `owner-taste` · 全表面

**症状**：圆角白底卡片 + 阴影浮起；六个指标各占一格瓷砖；卡片内再套灰底。
**背叛**：铁律 1（网格被盒子取代）、铁律 4（圆角与阴影无构图职责）。
**替代程序**：① 去掉盒子，只留网格跨度；② 分区改用实色块 / 3px 墨线 / 1px 墨线三档；③ 主次靠面积与线宽排，不靠"浮起"。

## AP-002 · 渐变 / 阴影 / 发光 / 3D — `banned` · `data-backed`

**症状**：紫蓝霓虹渐变背景、卡片投影、发光按钮、伪 3D 图表。**紫蓝渐变是 AI 生成内容的视觉签名**，一眼即识别。
**背叛**：铁律 4；且渐变文字底实测对比度不稳（data-backed）。
**替代程序**：① 要分区 → 实色块或墨线；② 要层次 → 字号与字重级差；③ 要纵深 → 换场（纸 / 墨 / 信号色满版）。

## AP-003 · 独立灰 hex 分区 — `banned` · `owner-taste`

**症状**：`#6B6B6B`、`#E5E5E5`、`#D4D4D4`、`#0B2E4A`（深蓝黑）用作次级文字或分区底。
**背叛**：铁律 3。写一个灰 hex 就是引入第四色，纸面立刻变卡片。
**替代程序**：中间调一律 `ink + opacity`（muted 0.62 / rule 0.12 / 深底正文 white 0.78）。

## AP-004 · 三张同构卡片排一行 — `banned` · `owner-taste`

**症状**：三个等宽等高、同结构的块，各装一个图标 + 标题 + 两行字。
**背叛**：铁律 1（没有主次）、形态路由（并列 ≠ 等分）。
**替代程序**：① 先判是并列还是推进；② 并列 → 跨列不等模块网格，槽 20；③ 推进 → 单轴编号，一项一行。

## AP-005 · 图标墙 — `banned` · `owner-taste`

**症状**：每条要点配一个小图标；六个彩色圆形图标排一排装饰。
**背叛**：铁律 4（装饰无职责）、铁律 2（用图形替代层级）。
**替代程序**：① 纯文本页不配图标；② 只有"需跨语言快速识别动作"（导视、公共信息）才用系统符号，且全册同一套。

## AP-006 · 饼图 / 圆环 / 仪表盘 — `banned` · `data-backed`

**症状**：占比用饼图；进度用圆环；指标用仪表盘铬件。
**背叛**：铁律 5（角度不可读，人眼比较长度远准于角度 —— data-backed）。
**替代程序**：① 占比 → 条 / 柱，同一基线；② 进度 → 数字 + 刻度条；③ 记分 → 排版账本（值 / 基线 / 进度 / 目标 / 负责人 + 发丝线）。

## AP-007 · 双轴图表 — `banned` · `data-backed`

**症状**：左右两个量纲共用一个图，靠颜色区分。读者会把交点当成结论。
**背叛**：铁律 5、形态"对照"（不同量纲不同尺度）。
**替代程序**：① 拆成两个同基准的裸条并排；② 或改成指数化（统一基线 = 100）。

## AP-008 · 居中对称的默认构图 — `banned` · `owner-taste`

**症状**：所有页标题居中、正文居中、元素左右对称；没有理由就居中。
**背叛**：铁律 1（瑞士式 flush-left，对称是缺席的默认）。
**替代程序**：① 默认左齐；② 要非对称 → 让非对称落在网格上（大块 + 小块的跨度差）；③ 居中必须是显式构图决策。

## AP-009 · 蛇形分栏 — `banned` · `data-backed`

**症状**：有先后顺序的内容被排成两栏 Z 字阅读（1→2 上排，3→4 下排）。
**背叛**：形态"推进"（前后依赖被视觉打断）。
**替代程序**：① 有依赖 → 单轴、一页一个方向；② 真的要分栏 → 栏内自洽，跨栏不承载顺序。

## AP-010 · 假数据 — `banned` · `data-backed`

**症状**：编造客户数、好评、奖项、"99.9% 可靠性"、"提升 300%"。
**背叛**：铁律 5。这是**欺骗**，不是审美。
**替代程序**：① 没有数据 → 用结构（空白占位 + 待补标注）；② 用真数据并附来源；③ 必须给量级时标 `illustrative`。

## AP-011 · 演示数据不标 illustrative — `banned` · `data-backed`

**症状**：示例数字排版得像实测值，读者当真。
**背叛**：铁律 5。
**替代程序**：数值旁或来源行标 `illustrative`，与真数据同样显眼。

## AP-012 · 为通过检查而填充内容 — `banned` · `data-backed`

**症状**：检测器/评审说"留白过多、失衡"，于是加装饰面板、加一段不服务论点的文字、把一页拆成两页。
**背叛**：铁律 4、铁律 5。留白是结构。
**替代程序**：① 先分结构空白 / 塌陷空白（见 `review.md`）；② 结构空白 → 保留并登记偏离；③ 塌陷 → 只改网格变量（跨度 / 尺度极差 / 垂直起点 / 全宽基线），一次改一个。

## AP-013 · 文字烤进图片或整块含字 SVG — `banned` · `data-backed`

**症状**：图表标题、节点名、数值画进图片；整块 SVG 含 `<text>`。
**背叛**：铁律 5（不可编辑）、工程可维护性。
**替代程序**：形状层与文字层分离——SVG 只画几何，文字用独立文本元素叠加。

## AP-014 · 填充动词与装饰符号 — `banned` · `owner-taste`

**症状**：`elevate / seamless / unleash / 赋能 / 一站式 / 打造`；文案里塞 emoji；大量 em dash（—）。
**背叛**：铁律 5（用修辞替代信息）；emoji 与 em dash 是机器生成感的标识。
**替代程序**：① 删掉形容词，只留可验证的动作与对象；② 断句用句号或重组句子；③ 需要强调 → 字号 / 字重 / 块面。

## AP-015 · 暖纸 / 米白底 — `warned` · `data-backed`

**症状**：`#F7F5F0`、米色、奶油底当默认纸面。
**背叛**：投影与低质屏会洗掉暖白（data-backed）；暖纸同时是"复古"皮肤，与瑞士底座冲突。
**替代程序**：① 投影类表面用纯白；② 印刷品确实要用暖纸时，在 DESIGN.md 声明理由与介质（印刷不是投影）。

## AP-016 · 白色绘图板 + 色块图例 — `banned` · `owner-taste`

**症状**：图表垫一块白底板 + 边框；系列用色块图例而不是末端直标。
**背叛**：铁律 4（白板是卡片）、铁律 7（读图要看两处）。
**替代程序**：① 绘图区透明，直接落在纸面或信号色底；② `showLegend=false`，系列名 + 终值在末端直标 16–18px Bold。

## AP-017 · 九宫格等分 — `banned` · `owner-taste`

**症状**：并列内容排成 3×3 或 2×3 等分格，每格同样大。
**背叛**：铁律 1（无主次）、形态"并列"（扫读变成逐格读）。
**替代程序**：① 按重要性给不同跨度（12 / 6 / 4 / 3 列整数倍）；② 块数 4–7，超过就该拆页。

## AP-018 · 排印无系统（Inter 默认 / 换字体做层级） — `banned` · `owner-taste`

**症状**：默认 Inter；靠换字体家族区分层级；靠彩色小字做强调；一页 6 种字号。
**背叛**：铁律 2。
**替代程序**：① 声明一套阶梯 + 一个 W(S)；② 层级只靠字号与字重；③ 强调改用块面反白 / 加粗 / 加大字号。
