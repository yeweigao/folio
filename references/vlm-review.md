# VLM「留白审判」处置协议

内置视觉检查（`lint --visual`）会用视觉模型判"过度留白 / 全局失衡"，并建议"补充内容、放大主体或收紧留白"。这是**启发式审稿意见，不是设计不变量**。本文件规定怎么接、怎么驳、怎么改。

## 1. 先分清两种门禁

| 类型 | 例子 | 性质 | 处置 |
|---|---|---|---|
| 工程门禁 | 语法错误、溢出、子元素超出父容器、画布 1280×720、组件能力上限 | 机器限制，可物理验证 | 无条件修，必须 `ok: true` |
| 审美门禁 | visual-vlm 的"留白 / 失衡 / 建议补充内容" | 启发式偏好，按像素密度猜构图 | 先判定，再决定改不改；不得用填充换通过 |

依据：本包的不变量只有六条（可读、无损、真实、语义、可编辑、推进），**没有"填满画布"**；品质按本册声明的系统判定，不按通用密度判定。

## 2. 两类空白：结构空白 vs 塌陷空白

| | 结构空白（合法，保留） | 塌陷空白（缺陷，修） |
|---|---|---|
| 成因 | 网格轴线、焦点呼吸、刻意的非对称 | 无轴线、无承重、元素漂在半空 |
| 判据 | 空白边界落在列线/基线上；围绕一个明确焦点；20% 缩略图第一眼仍落在计划元素 | 边缘对不上任何轨道；缩略图第一眼落在空处；相邻元素间距无规律 |
| 例 | 封面左侧大标题、右侧指标列之间的负空间；瀑布图浮动柱下方的基线空间 | 标题右下方一块无理由的空洞；页脚被 `marginTop: auto` 顶到底部留下大缝 |
| 处置 | 保留，记录偏离 | 改网格变量 |

## 3. 处置协议（五步）

1. **读原话，定位区域**：把 bbox 归一化坐标换算成页内位置，指出它落在哪个网格区。
2. **判类型**：按 §2 判"结构空白"还是"塌陷空白"；判据是轴线、焦点、缩略图第一眼，不是空白面积。
3. **结构空白 → 记录偏离，不改**：在 DESIGN.md 末尾登记（页号 / 原话摘要 / 判定 / 理由 / 代价）。若管线强制要求 `ok: true`，见 §4 的"结构性换通过"。
4. **塌陷空白 → 只改网格变量**：调跨度（8 列↔12 列）、移动重物、拉大尺度极差、改垂直起点、加全宽基线/发丝线、调图片高度。一次只改一个变量。
5. **绝不做的三件事**：加装饰面板填坑；为凑密度编内容；把已经成立的论证拆成更多块。

## 4. 结构性换通过（允许清单 / 禁止清单）

允许（改的是结构，不是内容）：
- 把标题或导语提到全宽，让阅读动线压过空白区；
- 放大既有视觉锚点（数字、图表、图版），让尺度极差承担构图；
- 把游离元素吸附到列线与 8px 基线；
- 延长发丝线/基线到全宽，给空白一个边界；
- 调整内容区高度与页脚锚定，消掉"auto 顶出来的洞"。

禁止：
- 加卡片、色块、图标、装饰线来"填"；
- 新增一段不服务论点的文字；
- 把一页拆成两页只为降低单页空白率；
- 为过检把正文调大或缩小，破坏 W(S)。

## 5. 记录格式（交付说明 / DESIGN.md 末尾）

```
VLM 偏离记录
- P03 折线页：报"99% 空白"[bbox 0,144,1000,733]。判定：结构空白——图直接落在纸面、无白板，绘图区与页底同色，检测器把"透明绘图区"读成空白。处置：保留；代价：视觉检查不通过，人工目视确认图元与直标齐全。
- P01 封面：报"右下留白"[bbox 66,596,648,713]。判定：塌陷——左栏提前结束、右列未压基线。处置：右列改 stretch + space-between，底部对齐；内容未增。
```

## 6. 一句话原则

**VLM 能看见密度，看不见网格。** 它说"空"，先问"这块空白有没有轴线、有没有焦点、第一眼有没有落错"；三个答案都对，就留白并记录；有一个不对，改网格，不改内容。
