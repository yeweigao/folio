# 讲课 PPT 设计体系 —— 从英语教材语汇到投影纪律

> 依据：`Grammar Explorer 1`（国家地理 Learning，500 页）与 `Think Level 3`（剑桥，130 页）的页面拆解，累计抽样 26 页。
> 结论先说：**像的是信息架构，不是视觉系统**。架构要学，视觉不学。

---

## 1. 对比：教材语汇 vs 本体系语汇

| 层 | 教材做法（Explorer / Think） | 我们的做法 | 判断 |
|---|---|---|---|
| 课时循环 | EXPLORE → LEARN → PRACTICE → REVIEW / SPEAKING / WRITING，一课一循环 | 三章 Reading / Grammar / Words，章内 内容 → 练习 → 答案 | **学**：阶段词显式化 |
| 语法规则 | 三件套：表格 + 编号规则 1.2.3.4. + 例句（含 ✓/✗ 对照） | 表格已有，规则与例句散在页内 | **学**：✓/✗ 对照 |
| 页眉 | Explorer 黄底 LESSON 条；Think 左上模块字母标（C / PHOTOSTORY 斜切色块） | 12 格刻度尺 | 已有等价物，不换 |
| 每页色彩锚点 | Explorer 页眉黄条 + REAL ENGLISH 角标；Think 左上模块标 + 右上 Workbook 引用箭头 + 蓝色功能标题（Giving advice） | **kicker 黄标签**（改造 8） | **学**：每页必须有主题色锚点 |
| 考试/答案页 | **Think 的 THINK EXAMS 页是全黄底** | 答案页墨满版 + 黄 KEY 色条 | 异曲同工；墨底的"盖住"信号更强，不改 |
| 词库 | Explorer 浅色填充底条；Think 描边方框 | 墨 5% 淡面容器 + 黄标签 | **学**（Explorer 式） |
| 焦点词 | **italic**（*her* · *his* · *too*） | italic（改造 6） | **学**：零色相成本 |
| 字重三声部 | bold 指令 / regular 题干 / bold 选项字母 | 同左（改造 6） | **学** |
| 交叉引用 | Workbook page 35（黄标签 + 箭头） | (p. 12) | 同构，已有 |
| 连续叙事 | Think 的 PHOTOSTORY 四格照片漫画 | 单张大图 + 单轴编号行 | 不硬搬：素材不支持时不造 |
| 对话排版 | 角色名粗体 + 对话 regular（MUM / GEMMA） | 无对话页需求 | 备而不用 |
| 字体 | Humanist 无衬线，8–10pt 纸质小字 | 无衬线巨字，26–96px | **不学**：载体不同 |
| 摄影 | 全彩真实摄影，占页 30–50% | 黑白摄影，仅 5 页 | **不学**：全彩冲破 3 hex |
| 色彩 | Explorer teal / 红强调；Think 蓝 + 黄；均配全彩 | 黑 / 白 / 柠檬黄 | **不学**：教材靠色相区分信息，我们用位置与字重 |
| 纸面 | 暖白 / 米色（防眩） | 纯白 | **不学**：投影仪会洗掉暖白 |

## 2. 八条改造

### 改造 1：阶段词进 kicker

教材每页顶部都告诉学生"这一页在干什么"。我们的 kicker 从 `PART 1 · READING / 01` 升级为带动作的阶段词：`READ / LOOK / LEARN / PRACTICE / CHECK / WORDS`。

### 改造 2：✓/✗ 对照

Explorer 每课都有 `✓ The rooms are big. ✗ The rooms are bigs.`——对错并置是教语法边界最快的方式。纪律禁红绿，用**浓淡**：✓ 墨色实心，✗ 45% 墨。色相一致，信息不减。

### 改造 3：表头黄底

语法表格头（BASE / COMPARATIVE / SUPERLATIVE）改黄底黑字。黄仅块面，表头正是块面。

### 改造 4：示例题 00

教材所有练习从 0 题开始，第 0 题是已完成样例。投影课件同样需要——老师指着 00 说"像这样做"。

### 改造 5：SAY IT 固定互动位

语言课不张嘴等于没上。内容页右下固定一个黄标签 + 一句指令（`SAY IT · Ask your partner: which one is higher?`）。练习页不放。

### 改造 6：斜体焦点词（字重三声部）

教材用 italic 标焦点词，不引色相、不加粗、不破坏文字流：

```
bold    = 题号 · 大题标签 · 指令句 · 选项字母（T / F）· 答案行
regular = 题干 · 词库词
italic  = 焦点词（被判断的、被变化的、括号提示的）
```

落到页：P07（*lower* · *first* · *top*）、P13（*taller* · *tallest*）、P17（*(big)* · *(good)*）。

### 改造 7：候选词容器

词库从"白底细线 + 22px"改为**墨 5% 淡面底条 + 内嵌黄标签 + 词 24px**。候选词需要被包住才读得出是原料。

### 改造 8：主题色在场（防白页平淡）

**这是整套体系的防堕落门禁。** 纯白 + 黑字是最容易写出的页，也最不像课件。规矩：

> 每个白底页至少一个**主题色锚点**，且面积 ≥1.5%。

执行方式：**kicker 黄标签**——每页左上角 `PART n · XX / nn` 从灰字改为黄底黑字 bold 标签（高约 34px，面积约 1.1%），叠加页眉刻度尺当前段与页内角标（WHY / WATCH OUT / WORD BANK / SAY IT），轻松过线。场反转规则：

```
白底页 / 墨底页 → 黄标签 + 黑字
黄满版页        → 墨标签 + 黄字（反转，保对比）
```

教材的对应物：Explorer 的 LESSON 黄条、Think 的左上模块色标。**每页一个色彩锚点是教材的共同特征，也是"课件感"的来源。**

**Logo 规格（每页必有，三级尺寸）**：

```
标准版  6 × 15px，间距 3px  —— 21 个内容/练习/答案页，嵌在 kicker 标签内左侧
章扉版  6 × 15px，间距 3px  —— 与标准版同尺寸，嵌在墨标签内（黄三格）
Hero 版 9 × 22px，间距 4px  —— 封面 P01 与封底 P26，嵌在放大的标签内
共同律  三级浓度 35% → 68% → 实色；颜色随场反转
        白/墨底页 → 墨三格；黄满版页 → 黄三格
```

**覆盖率 = 100%（26/26）**：内容页 21 + 章扉 3 + 封面 1 + 封底 1。设计出处是 Explorer 每页左上角的系列标识、Think 的模块字母标——它不是装饰图形，是**页眉 12 格刻度尺的微缩复发**：三级递进即 "Up" 的动作，刻度即全册进度母题。零新元素、零新色相，却让每一页都有了品牌位。

**场分配（26 页终版）**：白底 18 · 黄满版 5（章扉 ×3 + 关键句 + 封底）· 墨满版 3（答案页 ×3）。墨底专属答案页——"盖住别看"的信号不被稀释；收尾用黄满版爆发，与封面白底形成"白起黄收"的弧线。

## 3. 讲课 PPT 页型总纲（形态路由的教材特化）

| 阶段词 | 形态 | 页型 | 版式 | 纪律要点 |
|---|---|---|---|---|
| READ | 推进 | 内容页 | 图 + 单轴编号行 | 一页一个场景组，最多 6 行 |
| LOOK | 展品 | 内容页 | 大图 + 一句提问 | 图占 ≥40%，文字是图注 |
| LEARN | 对照 / 并列 | 内容页 | 表格 + 编号规则 + ✓/✗ | 表头黄底；规则编号 1.2.3. |
| PRACTICE | 演练 | 练习页 | 一页一大题 + 巨字题号 | 选项 ≥24px；示例题 00；斜体焦点词；无分值无卷头 |
| CHECK | 演练 | 答案页 | 墨满版三列 + 黄 KEY 色条 | 黑底白字，场级区分 |
| WORDS | 并列 | 词卡页 | 图左词右闪卡 | 1px 边框；照片灰度 |
| SAY | 宣言 | 互动指令 | 黄标签固定右下 | 一句指令，不超一行 |

每页固定件：**页眉 12 格刻度尺 → kicker 黄标签 → 56px 标题 → 内容 496 → 页脚**。

**节奏**：章内 `内容 → 内容 → PRACTICE → CHECK` 四页一循环；章扉（黄满版）起，答案页（墨满版）收；最长连续 valley ≤5 页。

## 4. 明确不借鉴的（防止下次手滑）

1. **不借字号**：教材 8–10pt 是纸质阅读距离；我们正文 26px 起、题干 28px、题号 48px。把课件字号往教材压 = 把教室最后一排卖出去。
2. **不借多色**：教材靠色相区分信息类型。我们用位置、字重、场（白/黄/墨）区分。全彩摄影进 deck = 纪律破产。
3. **不借一课多练**：教材一页 4–6 练因为纸上可回头看；投影翻页不可逆，所以一页一大题、行高 ≥82px。
4. **不借装饰插图**：Think 的拼贴、Explorer 的色块插图都是纸面甜点。我们的图形只有三种：刻度尺、表格、竖条对比。
5. **不借暖白纸面**：纸上防眩，投影无差别。
6. **不借 PHOTOSTORY 四格**：除非素材真是连续照片；没有图时不造漫画。

## 5. 一页纸版本（贴在每册 DESIGN.md 开头）

```
讲课 PPT = 阶段词（这一页在干什么）+ 巨字（最后一排看得见）+ 三色（黑/白/主题色）
         + 表格化规则 + ✓/✗ 对照 + 示例题 00 + 独立答案页
         + 字重三声部（bold 指令 / regular 题干 / italic 焦点词）
         + 候选词容器 + 每页一个主题色锚点（≥1.5%）
不是：试卷（无卷头无分值）、不是画册（无装饰插图）、不是教材复印（无多色小字）
     不是白纸黑字（没有主题色锚点的页不允许出厂）
```
