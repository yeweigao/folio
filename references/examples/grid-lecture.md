# 示例：一个概念，五个表面

> 示例项目：《网格不是笼子》公开课。讲者、日期、地点、票务均为占位；不对应真实活动，也不含真实数据。
> 没有真实照片，所以全篇不放照片。这个示例只演示判断与重排，不是模板。

## 1. 读解

```
Reading this as: 公开课海报 + 课程 deck + 报名页 + 设计板 + 16 页手册,
for 设计学生与年轻从业者, with a 冷静、克制、略带挑衅 temperament.
Material: real 12 列网格、一个数字 12、一句主张、课程大纲；pictures 无；
absent 讲者照片、现场图、赞助商、真实报名数据.
Dialect: folio — 主题就是网格本身，母体最合适.
```

读者离开时只能记住的一件事：**网格不是笼子，是一张可以演奏的谱。**

## 2. 命名默认（全部划掉）

1. 三张同构卡片：讲师 / 时间 / 地点。
2. 深色渐变 hero + "解锁设计的秘密"。
3. 12 个彩色图标代表 12 条规则。
4. 把 12 列画成 12 张卡片，一行排开。

四个都是"把信息放进容器"，没有一个把网格本身变成主张。全部划掉。

## 3. 材料与形态

- 真实材料：12 列这个数字、一句主张、四段课程大纲、一个日期。
- 没有照片、没有产品截图、没有数据。因此不做图像主导。
- 形态：封面 / 海报 / 首屏是**宣言**；deck 内页是**推进 + 论证**；手册是**序列**；画布是**决策记录**。
- 方言：`folio`；签名动作是"极端尺度差 + 一次场转折"。

## 4. 三个结构

| 结构 | 一句话 | 判定 |
|---|---|---|
| 图像主导 | 一张巨大的网格照片，字压在图上 | 拒绝：没有真实照片，图库照片会变成假材料 |
| 文字主导 | 把"12"做成主图形，竖笔落在网格线上，一条红线标出例外 | **选中**：数字就是证据，不依赖照片 |
| 证据主导 | 12 列剖面图 + 四段大纲 + 日期，全部标注 | 保留给手册第 2 页与 deck 内页，不做封面 |

三个结构都不是"三张卡片"；选中文字主导，因为材料只有文字与数字。

## 5. 主张与决定性动作

**主张**：网格不是笼子，是一张可以演奏的谱；规则越清楚，例外越有力。

**决定性动作**：把 12 做成网格本身——`1` 的竖笔对齐第 3 列左线，`2` 的右弧收在第 7 列右线；第 10 列用一条信号红线标出"被演奏的那一列"。

这个动作承担三件事：排序（数字先被看见）、证据（数字对应 12 列）、节奏（一条红线就是停顿）。它不是装饰；拿掉它，封面只剩一句标题。

## 6. 五个表面

### 6.1 deck · 1280×720

**网格**：外边距 70；内容 1140；12×73 + 11×24 = 1140；基线 8px。第 n 列起点 = `70 + 97n`。

**封面**：

- `12`：112px，占第 1–6 列，顶边落在页眉下沿。
- 标题"网格不是笼子"：60px，占第 1–8 列，底边落在内容区下 1/3。投影 D≥96 时 T≥60。
- 日期与场地：26px，第 10–12 列，右下角。
- 信号：第 10 列一条 8px 红线，从页眉到页脚；全页唯一红色。
- 纸白、墨 `#111`；无照片、无第二色。

**内页（12 列剖面）**：

- 12 条 1px 墨线，列宽 73；第 10 列改成 8px 信号线。
- 标注 18–22px；正文 26px；一页只讲"例外"这一件事。
- 图注写"12 列 = 12×73 + 11×24；第 10 列是本页的例外"。

**场转折**：一章扉页用墨满版，字反白，不用红色满版。理由：课程气质冷静，红色满版会变成口号；`folio` 的 Extension Rule 允许选择场温。

**交付**：投影 16:9；正文 ≥26px；实际打开导出的 PPTX 检查换行、字体回退、红线对齐。

### 6.2 poster · A2

**网格**：420×594；边距 28；内容 364×538；12×23 + 11×8 = 364；基线 8mm。

**构图**：

- `12`：300pt（A2 主标题上限），占第 1–7 列，顶边距 28mm。
- 标题：120pt，第 1–8 列，落在 `12` 下方。
- 日期：48pt，第 10–12 列，底边对齐基线。
- 课程大纲：36pt，第 1–6 列；图注 / 网址：18pt。
- 信号：第 10 列一条 2mm 红线，从顶边到日期上方；全幅唯一红色，面积 <1%。

**3 秒测试**：3m 外读出"12 / 网格不是笼子 / 日期"。读不出，删大纲。

**印刷**：CMYK；3mm 出血；5mm 安全区；300dpi；字体嵌入；PDF/X-4。纸用 `#F7F5F0` 未涂布暖白，已在 DESIGN.md 声明"这是纸，不是第四色相"；屏幕稿仍为 `#FFFFFF`。

### 6.3 web · 1440 视口

**网格**：内容最大宽 1440（视口 ≥1600 才封顶）；12 列；槽 24；边距 `5vw`。
1440 视口：内容 1296，列宽 86；1600+ 视口：内容 1440，列宽 98。

**首屏**：

- `12`：`clamp(80px, 12vw, 112px)`，第 1–7 列；112px 是 `folio` 的展示档。
- H1：64px，第 1–8 列；正文 20px，第 1–6 列；一个主 CTA。
- 第 10 列一条 2px 信号竖线，`aria-hidden="true"`；日期 / 场地 16px。
- 390 宽：4 列，槽 16，边距 24（内容 342）；`12` 降到 80px；竖线改成 H1 下方 2px 横线。

**页面**：6 个 section——首屏、主张、12 列剖面、四讲大纲、讲者占位、报名。每个 section 一个主意；没有照片；剖面用 CSS grid + 可读文字说明，不把文字烤进 SVG。

**可访问性**：一个 H1；跳过链接；`:focus-visible` 2px；报名表单有 label；红色横线是装饰；`prefers-reduced-motion` 下无动效；无 JS 也能读。

**交付**：1440 / 768 / 390 实际打开；无横向滚动；LCP 是 H1 文本；没有图片请求。

### 6.4 canvas · 设计板

**空间网格**：8pt；板面边距 50；同组帧距 160，跨组 240；连接线 2pt，箭头 8pt，正交。

**六帧**：

1. 读解与材料（1440×900）。
2. 三个结构（1440×900）。
3. deck 封面（1280×720）。
4. A2 海报（1240×1754，等比缩览；不是 150dpi 成品）。
5. web 首屏（1440×900）。
6. 手册封面 + 12 列剖面（1240×1754）。

帧标题 32–64；正文 14–16；标签 12–14。25% 总览下只读帧标题与编号；100% 才读正文。

**规则**：帧与帧至少共享一条对齐线；同一组只用一个主导方向；不用彩色分组框，间距差就是分组。

### 6.5 handbook · A4 / 16 页

**网格**：210×297；边距上 18 / 下 21 / 内 21 / 外 15；版心 174×258；12×9 + 11×6 = 174；基线 21pt；正文 10.5pt / 18.4pt。

**排印**：`12` 84pt（D 档上限）；H1 32；H2 18；正文 10.5；图注 9；脚注 8.5。

**页面**：

- 封面：`12` 84pt，标题 32pt，日期 9pt；第 10 列 1pt 红线。
- p2：12 列剖面，12 条 1px 线 + 第 10 列 2pt 红线；标注 9pt。
- p3–10：四讲，每讲一个跨页；每跨页一个主意；页眉 / 页脚 / 页码齐全。
- p11–14：练习、术语、延伸阅读、课程信息；每页一个主意。
- p15：参考与许可；p16：封底，只留标题、日期、网址。

**印刷**：16 页骑马钉；爬移 1–2mm；3mm 出血；5mm 安全区；CMYK；PDF/X-4；暖白未涂布纸。实际打样一次，检查大面积墨与红线套准。

## 7. 什么不变，什么必须重算

| 不变量 | 在五个表面 |
|---|---|
| 一句主张 | 五个表面同一句，不改写 |
| 12 列逻辑 | 每个表面都有自己的列宽 / 槽 / 边距，但都是 12 列 |
| `12` 作为主图形 | 竖笔 / 弧线必须落在列线上；尺寸随表面变 |
| 一条信号红线 | 只标第 10 列；面积 <10%；不承担装饰 |
| 纸 / 墨 / 一个信号 | 印刷可用暖纸；屏幕纯白；不引入第二色相 |
| 无照片 | 没有真实照片，就不放；不用图库图冒充现场 |
| 一套排印 | 一个 grotesque；角色只有展示 / 正文 / 标签 |

| 变量 | deck | poster | web | canvas | handbook |
|---|---|---|---|---|---|
| 尺寸 | 1280×720 | 420×594 | 1440 视口 | 帧 | 210×297 |
| 最小正文 | 26（投影） | 36pt | 20px | 14–16 | 10.5pt |
| 节奏单位 | 页 | 幅 | 屏 | 帧 | 跨页 |
| 交付 | PPTX | PDF/X-4 | 响应式页面 | 画布导出 | 骑马钉 |
| 观看距离 | 3–8m | 3m | 0.5m | 50%–100% | 0.3m |

**不是缩放**：海报不是放大的 deck 页；网页不是会滚动的海报；手册不是打印出来的 deck；画布不是把五张成品撒在板上。每换一个表面，重算网格、字号、裁切、节奏与交付。

## 8. 失败模式

- `12` 只是一个大数字，没有对齐列线：变成装饰，方言失败。
- 红色出现在日期、按钮、图表、下划线上：信号失去"例外"语义。
- 课程大纲变成 12 张卡片：退回命名默认。
- 网页用一张图库网格照片当 hero：假材料，违反诚实。
- 手册把海报缩到 A4：只缩放，没重排，正文过小。
- 画布帧随意散布：没有对齐线，是情绪板，不是决策板。
- deck 每页同一个音量：没有场转折，像 PDF 而不是课。
