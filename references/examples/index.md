# Visual cases

Studies from earlier work, not certified pages. Each names what to transfer and what to reject; demonstration content is never evidence.

| Decision to study | Case | What it makes visible |
|---|---|---|
| Carry a constraint through different compositions | [One measure, two appearances](brand-measure/note.md) | A mark's proportions become the page's crop logic; identity survives changes of scale and exposure |
| Make related content readable together | [Rows create relationships](paired-reading/note.md) | A decision table and an observation exercise share alignment while serving different reading tasks |
| Compose the frame before filling pages | [One scene across a seam](continuous-frame/note.md) | A continuous image and unequal text roles create a spread; incorrect page order still defeats print production |

## Admitting a case

- **A case teaches one distinct decision, not a look.** State the task, the visible choice, why it helps, and its limits.
- **The result is shown, not described.** A raster preview plus a short note; PNG for type and diagrams, JPEG for photographs, SVG or HTML only when geometry or reflow is the lesson.
- **Rights are cleared, not assumed.** Name the work and image rights; link when reproduction is not permitted. A before/after keeps content and scale comparable.
