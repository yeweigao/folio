# Folio · 设计审美契约

一份让 AI agent 按**你的审美**做设计的契约。它不是风格教程，不是组件库，也不是生成引擎。

- **底座**：瑞士国际主义——网格、非对称、左齐、留白、客观优先。
- **融合**：编辑叙事、公共信息、构成主义、包豪斯、克制粗野、时装编辑、纪实摄影、模块网格、瑞士朋克。
- **表面**：幻灯片、海报、网页 / 落地页、画布设计稿、手册 / 画册。
- **适用**：Claude、Codex、DeepSeek、Gemini、WorkBuddy、Ardot、Slidep，以及任何能读 Markdown 的 agent。
- **不管**：内容生产、数据编造、引擎命令、品牌资产管理。

**当前版本：1.0.0**（发布冻结，见 [`RELEASE.md`](RELEASE.md)）。

> 瑞士的骨架，编辑的呼吸，解构的脾气，粗野的诚实。

## 为什么这么短

`SKILL.md` 是常驻上下文的自足入口：七条铁律、十六条硬地板、七步工作流、十种方言。**只读这一页，审美判断与硬底线已经成立；具体到毫米的数字再按需下潜。**

有数字的深水按需加载，因为视觉品味有两类规则：

- **A 类·负向机械**（禁 emoji、禁紫蓝渐变、禁三等分卡片、禁假数据）→ 一句一条，住 `SKILL.md`。
- **B 类·正向构造**（排印阶梯、网格数学、色彩派生、图表语法）→ 必须有可复算的数字，且能整体替换 → 住 `references/`。

这也是 Hallmark 与 Karpathy 那条路：**硬地板写短，深水写厚，地板之上把页面交还给做设计的人。**

## 装法

把整个目录放进 skill 目录（如 `~/.claude/skills/folio`、`.codex/skills/folio`、`~/.workbuddy/skills/folio`）。

**frontmatter 是唯一的发现契约**：严格 YAML，触发词写全。改坏了不会报错，只会被静默丢弃。

不需要安装任何依赖；没有脚本、没有构建、没有二进制。引擎适配器只是 Markdown 事实表。

## 怎么用（agent 的工作顺序）

1. 写三行：`Reading this as / Material / Dialect`；再写一句读者只能记住的事。
2. 命名默认：写出这类 brief 最容易生成的三个陈词滥调，全部划掉。
3. 盘材料：真实素材 > 真实截图 > 公共收藏照片 > 代码绘制 > 纯文字；没有就不放。判形态，选一个方言，并说出它的签名动作。
4. 写三个结构草案：图像主导 / 文字主导 / 证据主导；不得是第 2 步的三类。只比结构，不比颜色。
5. 选一个主张，指定一个决定性动作：观者能一句话描述，且承担排序、证据或节奏；并列时选更克制、动作更可说的那个。
6. 先做最小单位，同时声明网格、阶梯、三种声音、母题、图像处理。
7. 删一个不承重的元素；过硬地板、换上下文复审、实际打开导出件、记录偏离；高风险件再跑红队。

项目级 `DESIGN.md` 在本项目内是设计判断的最高权威，低于用户明确指令与事实。优先级：**用户明确指令 > 内容与事实 > DESIGN.md / 品牌规范 > 方言 > 本页默认**。用户指令可豁免风格禁令，不可豁免诚实与可读性。

## 当前已有什么

- **10 个方言**：`folio`（瑞士母体）、`editorial`、`public-info`、`fashion`、`documentary`（stable）；`constructivist`、`bauhaus`、`brutalist`、`bento`、`swiss-punk`（experimental）。每个方言有签名动作、失败模式、一句练习。
- **14 种破格**：每种打破一条默认，必须事先声明、留痕、其余部分回默认。
- **5 个表面**：deck（1280×720）、poster（A 系）、web（视口 1440 → 内容 1296，上限 1440）、canvas（8pt 空间网格）、handbook（A4/A5，mm/pt）。
- **1 个跨五表面示例**：《网格不是笼子》同一主张、同一决定性动作，在 deck / A2 / web / 画布 / A4 上各自的数字、不变量与失败模式。
- **3 个引擎适配器 + 1 张跨引擎验收单**：slidep 的字重 / 中文字体 / 容器高度实测；ardot 的设计系统交接；generic 的通用清单；12 项验收、三种结果、五个表面的追加项、可复查的交付回执。
- **12 类红队攻击 + 6 个修复动作**：用“最便宜的通过改动”攻门禁，区分实测与纸面；测量本身也列为攻击面；每条高危攻击必须封堵或登记残余风险。
- **评测套件**：L0 合规、L1 命题、L2 对抗、L3 介质迁移；12 个 brief；100 分评分表；17 个校准判例；1 份真实评分记录（含失败）。
- **7 份工艺算术**：排印、色彩、网格、图像、数据、文案、动效；每份有可复算公式、一组常量、一个失败样本与检查表。
- **1 次真实评分（run-001）**：B03 公共讲座海报；自评 79，两个独立复审 63 / 72，均判不通过；据此冻结材料、加长标题协议、收紧自评规则。
- **1 份发布冻结（RELEASE.md）**：0.1–1.0 版本史、证据索引、五分钟审计、变更政策与未验证项；1.0 只冻结判断顺序与门禁，不冻结手。

这些内容已冻结为 **1.0**。冻结的不是品味，是判断的顺序与门禁的写法：先读解，再命名默认，再三个结构，再一次破格，再验收，再红队；结论必须能指回文件、页面、数值或一次操作。0.9 的红队实测仍作为边界留在仓库里：6pt 免责声明 = 8px，声明色对比度 17.33:1 合成后只有 5.13:1，块级盒宽冒充字面宽，列线检测误判组内流。1.0 没有消除这些问题，它让下一版知道该往哪里修。

**升版纪律**：版本不是标签。每个 minor 必须同时有三样：一个可指认的新能力；一个失败样本或实测证据；一条 `EVOLUTION.md` 记录。缺一条，不升版。1.0 不是文件最多，而是判断最稳。

## 已验证 / 未验证

**已验证的设计输入**：小学三年级英语课件（26 页课堂投影，瑞士网格 × Munich 72）；董事会 / 战略评审 deck；`ppt-master-themes`、`handbook-designer-skill` 与 Folio 2.1 样式总册的长期实践。

**1.0 的诚实边界**：

- 契约与评测套件已具备，但**尚未完成跨模型盲测**；`evals/` 是跑测工具，不是通过证书。
- `slidep` 适配器有 macOS 实测记录；`ardot` 适配器只有公开能力层面的用法约束，标 `unverified`。
- `poster` / `web` / `canvas` / `handbook` 四个表面数字可复算，但尚未在真实项目跑完最难一页，标 `experimental`。
- 五表面示例是纸面推演，不是真实项目；它的价值是暴露矛盾。0.5 据此修正了 web 的“1440 是内容还是视口”、390 边距、投影封面标题下限与画布 DPI 标注。
- 0.6 的七份算术经过人工复算与对比度脚本抽查，不是跨模型验证；它保证数字能对上，不保证每个判断都对。真实项目仍未跑完最难一页。
- 0.7 的回执示例是对五表面示例的纸面演练，未导出任何文件；引擎相关项全部标 `unverified`，不冒充实测。验收单能防止“缩略图通过”，但还没有在一次真实交付中走完。
- 0.8 的评分记录是单模型、两个新上下文，不是跨模型盲测；只有 B03 一件成品；v2 只有屏幕渲染，没有 PDF/X-4、CMYK、出血与打样，印刷项标 `unverified`。自评 79 被独立复审 63 / 72 推翻，正是这一版要留下的失败。
- 0.9 的红队记录只有 A01 / A02 / A04 / A05 / A06 在 B03 v2 上实测；A09 的 web 追加项、A03 的原生打开、A10 的印刷链路仍是纸面条款或未验项。残余风险表仍挂着三项高危：复审同源、印刷无打样、门禁不能代替审美判断。0.9 没有消除它们，只是不再假装它们不存在。
- 1.0 冻结的是判断顺序与门禁，不是品味或零风险。跨模型盲测、Ardot 实测、印刷生产仍未完成；poster / web / canvas / handbook 仍是 experimental；红队残余风险表保留三项高危。它们都写在 `RELEASE.md §4`，不藏在版本号后面。
