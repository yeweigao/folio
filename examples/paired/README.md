# Paired example — same content, two hands

One dataset (quarterly figures; settlement populations; all illustrative)
set twice:

- `basic.html` — the default the skill exists to replace: centered hero,
  three KPI cards, a purple-blue gradient, copy tells ("Empowering
  seamless growth, unlocking value"), a pie where a comparison belongs.
  It fails folio-check's E1 (off-palette gradient colors) and E4 (copy
  tells) against the board-deck DESIGN.md.
- `signature.html` — the same content under the board-deck system:
  graphic scale title (Müller-Brockmann card, ratio > 6:1 against body),
  a generated ledger, a generated Isotype with cut remainders.

This pair is the calibration asset for Inspect's recognition test: the
difference between "correct" and "recognisable" is visible here without
any master's artwork — the pair is Folio's own work, kept in-repo.
