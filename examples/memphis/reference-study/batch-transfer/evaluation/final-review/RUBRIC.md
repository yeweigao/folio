# 同一世界迁移 · 独立审阅

只看指定原组图、新作 PNG、事实简报与本文件，不读 DESIGN、代码、制作者解释、其他评审结论。只认出相同颜色或活动名不够。

每个样本分别判断：

- **身份：** 特征图形的轮廓、内部构造、尺度与文字层级是否属于同一组。
- **构成：** 原组起作用的分区、模块、字形或投影关系是否继续组织新内容；允许新摆放，不要求复制原画面。
- **迁移：** 新内容是否得到重排，未遗漏或虚构事实；能否成为原组的另一件作品。
- **工艺：** 固定文字可读，无错误遮挡/裁切，实际色字分离。图像判断不代替字体和对比度测量。

结论用 **通过 / 部分通过 / 未通过**。部分通过表示有明确亲缘，但关键图形/比例/构成漂移；未通过表示主要靠通用几何或有阻断问题。

每例最多列 3 个能从像素定位的问题；区分世界身份缺漏与普通工艺错误。不要因为未知的 DESIGN 内容替作品辩护，不把无关的个人偏好判成失败。指出哪种关系丢了，不要求作者复刻原图的逐格坐标。

首轮只评基线。修订轮若看两个候选，先分别判断，再盲选更属于原组的一件；不要猜测版本标签。一个样本只提供局部证据。
