# 本案制作决定与边界

## 实际决定

- 采用 470／430 px 的连续绿黑双场，栏宽比约 1.093；所有几何与活字保留为原生 SVG 对象。
- 左场以可辨的「共」「生」两块为骨架：上块保留双竖、双横及向两侧弯出的「八」脚，下块保留撇、直竖和三横；两块用纵向笔连接。日期和中文展名进入连接段的朝右开口，策展信息进入「共」的中央深槽，地点进入「生」的横向断笔。
- 右场用粉色肩弧围出英文展名的宽开口，短弧齿、圆点、短条接续其下沿；时间落在粉色与紫色块之间的横向断笔。紫色是三根同向开尾弯钩，橙色保留上下反向碗、短腰及墨底椭圆内孔。
- 短边缩放系数取 0.9，中文展名 68.4 px，英文 53.1 px，日期与时间 43.2 px，事实 21.6 px。英文按三行换行，策展署名按两行换行。未使用窄体或横向压缩。
- 日期在绿底用大号黄色；中文与小字为墨色，英文与时间为白色。未采用可选外框。
- 使用所供 Inter 400／700／900 与 Noto Sans SC 可变字体，调用中性 helper 子集嵌入。未新增依赖。

## 自查与未覆盖处

- 运行生成脚本，解析 raw.svg 与 poster.svg 的 XML，并校验 900×1200 画幅、全部七组固定活字的完整文字、无 image／foreignObject、四个内嵌字体声明。
- 用所供字体的实际字形边界检查指定阅读开口，文字距开口边均不少于 12 px。该检查是静态几何核对，不是浏览器排版结论。
- 未读取原图、其他版本、旧作、组件、绘制代码、评审、其他技能或外部资源。没有进行浏览器渲染或独立视觉评审，不宣称原图精度或审阅通过。主题路径的识别度与整体视觉质量交由主流程独立渲染评估。
- DESIGN.md 没有指定两场的精确分界、具体曲线路径、每组事实的确切位置；以上为本次基于文字规则作出的构图决定。
