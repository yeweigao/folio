# 制作记录与未覆盖事项

## 实际决定

- 画幅为 900 × 1200；绿色与黑色各占 450 px，不设沟槽。局部主模块取约 405 px，白色连续主笔以约 100 px 为基准。
- 从“共生”提取“共”的双柱、横笔和两支弧脚，以及“生”的竖干和三横，重组为左侧连续白色构字。右侧是同一主题的分节笔画组：五列三层的小拼块、粉色事实切口、三根紫色并列弯钩、橙色带腰双碗体。抽象骨架由完整活字展名确认读法。
- 策展与地点完整放入白色共字两柱间的 134 px 深槽；日期和时间完整放入粉色主笔三面围合、向左开口的断笔区。中文与英文展名共用绿色的宽开口，左侧白色连笔与上下主笔形成边界。
- 所有阅读级别按短边比例 0.9 使用：中文展名 68.4 px / 900，英文展名 53.1 px / 900，日期和时间 43.2 px / 700，小字 21.6 px / 400。英文按语义分为 COEXIST / DESIGN / EXHIBITION 三行，字宽正常；没有压缩或横向拉伸。
- 不使用可选的外框。黄色用于中文展名；蓝色仅用于紧凑拼块；paper、pink、purple、orange 均进入主构字。
- 原生路径、矩形、圆、椭圆与九个可编辑 text 节点组成作品；字体由所给中性 helper 子集内嵌。

## 已完成的有限自查

- raw.svg 与 poster.svg 均经 Python XML 解析，画幅、viewBox、九个固定文字节点和文字逐项检查通过；图中没有 image 节点。
- poster.svg 包含四个内嵌 WOFF2 face：Study Sans 400 / 700 / 900 与 Study CJK 100–900。400 Latin face 由 helper 按 family 自动一起嵌入。
- 用实际字体轮廓计算每组文字墨迹边界与预留切口边距，最小边距为 12.71 px。中文展名、三行英文、署名、地点、日期、时间均处于各自单色阅读区。
- 没有进行浏览器渲染、图像审阅或独立评审；没有声称原图精度或独立评审通过。抽象构字的辨识度、缩略图观感、色块节奏和完整视觉效果留待主流程独立渲染检查。

## 文件没有规定而自行决定的事项

- 左右场的分工、两个主题字在左侧的连笔方式、标题三行英文的换行、日期不额外添加连接词，以及小拼块的具体排列。
- 紫色弯钩选三根：竖干厚 74 px，外弯半径 126 px、内弯半径 52 px；相邻竖干深槽约 48 px。橙色上碗平口宽 416 px、腰宽 128 px，下体内孔为 102 × 44 px 的横椭圆。
- 未增添简报外的活动信息、来源归属或导览文案。
