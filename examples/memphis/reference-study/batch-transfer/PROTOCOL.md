# 九套迁移与修订验证

## 授权范围
用户要求完成剩余九套的独立迁移，逐一修改 DESIGN.md，再修改生成这些文件的 skill，重点为孟菲斯方言；修改与验证完成后交付。第十套已测出的缺漏也一并修。

## 基线
9 个新上下文，各读取自己的未经修改 DESIGN、全新简报、指名字体及中性嵌字工具。不读取参考、旧作品、旧绘制代码、其他上下文。输入逐字冻结并计算指纹。报告用一页新横版，其余为新竖版海报；本轮优先固定已有画幅，只改内容。

## 评审
输入和首件成品冻结后，独立审阅只看成品、原组、新简报、rubric，不读 DESIGN 或制作解释。分别检查世界身份、结构迁移、事实与工艺。只保留像素可见的问题。制作结果不因事后改图而重写基线。视觉 reference.png 使用已交付的原生复刻组；原始 JPG/复刻对照在上层 previews 保留，不能把本项描述为原字库或逐像素一致性验证。提取 skill 的三组实验另直接使用同一原始 JPG。

## 修订
先把可见问题定位为规则缺漏、规则矛盾或执行偏离，修各自系统；保留原输入不覆盖。修订稿使用同一简报交给全新上下文复测，仍不给参考图与旧作品。第十套沿用此前的同一新简报。

## Skill 修改
从多套证据提炼少量通用改动：提取/创作路由、可独立执行的构造与尺度关系、场形选择、条件与变量。逐格坐标和品牌专有形状留在各自 DESIGN，不进入方言。保留修改前 skill；以同一提取简报比较旧版、新版与无 skill。盲评检查提取文件的独立可执行性，不冒称完整视觉质量优势。

## 结果边界
每个系统只有一件新样本，判断为通过 / 部分通过 / 未通过，不作普遍可靠性结论。交付原作/基线/修订版对照、问题定位、更新后的十份系统、实际修改的 skill 文件和检查记录。
