# Steering — named moves for refinement turns

After delivery, a refinement names one move. The move changes the skeleton first, then the units, then the floors are re-run. No steering word moves a floor.

| Move | Changes in DESIGN.md | Never changes |
|---|---|---|
| **Quieter** | Accent uses drop (fewer units carry it, accent area toward the theme floor); scale contrast narrows one step; one variation is retired to continuity | Facts, the lead of each unit, type floors |
| **Bolder** | Scale contrast widens one step; the leading move grows (graphic scale for type, closer crop for image); one named variation is added at the strongest turn | Reading text treatment; more than one break per unit |
| **Ledger** | Loose numbers and KPI-style figures are re-set as ledger rows: value, baseline, period, change, aligned on the decimal (craft, Data) | The numbers themselves |
| **Densify** | Spacing steps compress one declared step; reference treatment spreads to suitable units; empty fields are given a job or removed | Measure (line length) floors and size floors |
| **Open up** | Spacing steps widen one declared step; one Pause variation is placed before the climax; secondary material recedes to muted | Content: nothing is deleted to make room |
| **Field turn** | The strongest statement unit moves to an accent or dark field with its complete foreground palette (theme, Variations: Accent field) | More than one field turn per sequence |
| **Retype** | The hierarchy mode changes (weight leads ↔ scale leads, craft, Type) and the ramp is re-declared; faces stay unless the brief changes | The faces' scripts coverage: a new face still needs its CJK pair resolved |

An unnamed request is read for the move it describes.

## Client language — aesthetic adjectives, translated

Clients rarely name a move; they point at a dial (colour, type size, whitespace, alignment) with a fuzzy word. The word is a direction without parameters: translate it into declared changes in the skeleton before anything is made, grant the translatable part, and refuse, with a reason, what conflicts with the Philosophy or the governing dialect.

| The client says | It points at | The translation (declared, with numbers) | Folio's keeping |
|---|---|---|---|
| 高级一点 · more premium | Colour, whitespace, weight | Cut decoration and secondary elements toward one lead + apparatus; display weight to the face's light class where the subject is quiet (a lineage swap, 700→300), one class lighter where it must still project — a step is one class on the declared ramp; display tracking opened; saturation down — palette toward ink, paper, one accent; paper share up | Quiet is made by removal and weight, never by gold, gradients, or grey luxury clichés |
| 大气一点 · grander | Size, whitespace | The hero (image or title) owns a field — the block it commands, its air included — of at least half the frame by area; exactly one focus; every other element retreats one step — smaller, muted, toward the edges | One focus means one: a second hero is a refusal, recorded |
| 再活泼一点 · livelier | Colour, alignment | One collision accent at full saturation in a small share; ONE named variation breaks ranks (a rotation, a shifted baseline) at a turn; the display face may go rounder | Liveliness is a cited variation, not a mood smeared over every unit |
| 要有呼吸感 · breathing room | Whitespace | Body leading ×1.5; margins up one step on the surface's own spacing ladder; every gap unified onto the spacing scale — mixed gap sizes are what "cramped" usually names | Nothing is deleted to make the room; the content stays, the air is added |
| 要有冲击力 · more impact | Size, colour | The palette's strongest contrast pair (ink on paper, or a reversed field); display at graphic scale, bleeding off the frame if the surface allows; accent count exactly one | Impact is contrast + scale, not more colours or more elements |
| logo 再大一点 · logo bigger | Hierarchy | The mark moves up one hierarchy class, declared as a size (e.g. logo height against the title's cap height); if it must lead, the title steps down a class; where the mark and the title are one object (the small-shop case), the class is measured against the largest remaining element | A class change or nothing — "slightly bigger" is not a decision |
| 干净一点 · cleaner | Alignment, colour | Decoration deleted; every element on the declared axes; one typeface family; colour roles no more than paper / ink / one accent; equal things given equal spacing | Clean is a count (elements, colours, axes), checked, not a feeling |
| 清楚一点 · clearer, easy to look up | Alignment, whitespace | Every fact becomes a labelled row on one shared axis (label → value), in the reader's question order; one reading order is declared and visible; a repeated fact is set identically everywhere it appears; groups are separated on the spacing scale so each is found at a glance | Clarity is apparatus, not simplification — nothing is cut to make it "clear", and density is welcome in a reference form; what goes is anything that competes with the entry points |
| 年轻一点 · younger | Colour, type | Palette lightness up; display face to a rounder or humanist cut; amplitude up one step | A dialect signal first — Punk or Memphis amplitude, or a guest move; never stickers and doodles pasted onto a mother-tongue page |
| 要有质感 · more texture, less "computer feel" | Colour (material) | A real photograph replaces illustration or rendered stock; palette desaturated toward the paper's tone; the paper itself becomes a colour (the soft field) | No applied grain or noise filters: texture is photographed or printed, never faked on screen; on paper it is the printer's stock |
| 要有设计感 · more "designed" | Alignment | A grid system is declared from the roster and governs; the asymmetry is of MASSES (the fields themselves unequal, not merely flush-left text); and the title is treated as a figure that PARTITIONS the field — its glyphs carve the zones, and the other elements answer them (an image steps around the title, a fact block keys to its measure, a colour field ends where a glyph ends) | The complaint means "placed, not composed" — and a declared grid is not evidence: the test is removal. Delete the title in proof; if the layout still stands, the title was placed, not composed, and the translation has not happened. Structure must be visible with the DESIGN.md closed. |

- **Each adjective moves only its own dials.** Where two contest one dial, the adjective whose primary dial it is wins.
- **Another school is another world.** A request that needs a different dialect rewrites the skeleton from the invocation down; it is never patched in as a guest look.
- **No dial, no change.** "你懂的，弄好看点" delegates taste: exercise it through the dialect, invent nothing in its name.
