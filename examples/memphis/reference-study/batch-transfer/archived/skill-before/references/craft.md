# Craft

Technique shared by every school. The theme sets relationships, the surface sets sizes. Where the theme or a dialect names a technique, its rule wins; the rest holds here.

## Grid

- **Solve the grid from the format.** Content = n × column + (n − 1) × gutter; column k starts at margin + k × (column + gutter).
- **Tracks are construction lines, not columns to fill.** Equal spans for real peers, unequal for real priority; an unused track is not a vacancy.
- **Axes are shared.** Image edges, title starts, captions and sources repeat the alignments their relationships need.
- **Spacing has declared steps:** within a group, between groups, between sections.
- **Alignment is optical.** Round forms overshoot; quotes and points hang.

| Reading need | Composition | Invariant |
|---|---|---|
| Compare peers | Equal spans, criteria in shared rows | Row alignment, units, scales |
| Read with evidence | Unequal spans | Text and evidence share an anchor |
| Annotate | A narrow note track | Each note beside its passage |
| Survey | Contact sheet | Comparable crops, shared caption baseline |

## Type

- **Three roles carry the reading:** display, body, label. Add a level only for a real navigation task.
- **When type leads, start at graphic scale.**
- **One hierarchy per deliverable.** Weight leads, scale leads, or one weight. Declare size and weight together.
- **Weight is judged by eye.** One family's 700 is not another's; small text needs stroke, not bold.
- **Measure follows the reader.**

| Role | Latin chars | CJK chars | Leading |
|---|---|---|---|
| Body | 45–75 | 25–40 | 1.5–1.75 |
| Display | 8–20 | 4–12 | 0.95–1.12 |
| Caption | 30–50 | 18–28 | 1.4–1.5 |

- **Lines break by meaning.** No widows or orphans; CJK breaks are set by hand at phrase boundaries.
- **Spacing is designed.** Body keeps the font's spacing; display tracking follows the letterforms; the CJK–Latin gap is 1/8–1/4 em, set once.
- **Punctuation is exact.** English: curly quotes, en dash for ranges, true minus. Chinese: one quotation style, ——, ……, 《》 for works only. Tabular figures in tables.
- **Faces come from the hand's lineage.** A CJK–Latin pair is one voice: matched size, density and baseline. Where the lineage leaves the choice open, use Source Han Sans with a grotesque, or Source Han Serif with a text serif. Substitutions are reported.

## Color

- **Roles, not swatches.** Ground, text, muted, emphasis and line, each defined once; foreground lightness chosen per ground.
- **Color comes from the subject or the brand, not a topic cliché.**
- **Measure the composite, not the opacity.**
- **Hierarchy survives greyscale.**
- **Print:** the printer's profile and stock govern; 100K for small text and hairlines; proof out-of-gamut accents.

Named colors, as screen approximations. A signature color used in its owner's category reads as imitation.

## Copy

- **Words come before layout.** An argument is claim, evidence, implication and action.
- **Verbatim means verbatim.** Where editing is allowed, edit for the message, never to rescue a layout.
- **An argument title states a judgment, not a topic.** Read in order, the titles form the summary.
- **Concrete, not inflated.** Replace each tell with the action, object, quantity or date.
  - Words: elevate, seamless, unleash, empower, revolutionize, cutting-edge, game-changing, unlock; 赋能, 一站式, 打造, 引领, 闭环, 抓手, 颠覆.
  - Shapes: "not just X, it's Y"; three adjectives in a row; rhetorical questions; "Imagine a world where".
  - Buttons: "Learn more", "Get started", "Submit".
- **Languages follow their readers, not decorative rank.**

## Data

A chart answers a question; a table serves lookup. For an argument, use the consulting exhibit (Zelazny, Minto, Tufte, IBCS): an action title, a unit line, the chart, then source and notes.

| Question | Use | Not |
|---|---|---|
| Which is bigger | Bars, columns | Pie, donut, 3D |
| How it changed | Line | Invented smoothing |
| How it is distributed | Histogram, box, strip | A lone average |
| Whether two things relate | Scatter | Correlation sold as cause |
| What it is made of | Stacked bar | Pie |
| How a total moved | Waterfall | Two pies |
| How far from a baseline | Diverging bar | Gauge |
| Many small groups | Small multiples | Twelve lines in one plot |

- **Geometry is honest.** Bars start at zero; cut axes are marked; dual axes are replaced by aligned panels.
- **Label directly.** A legend only where it reads more clearly.
- **Precision serves the decision.** Percent is not percentage points; missing is not zero.
- **A dashboard is a ranked scan, not a gallery of cards** (Few).

## Imagery

| Job | Must carry |
|---|---|
| Evidence | A caption (who, what, where, when, source) and a traceable origin |
| Explanation | One drawing style; labels as live text |
| Atmosphere | Honesty that it is atmosphere |

- **One strong image, not four weak ones.**
- **The crop serves the subject.** Faces, hands and marks are never cut by accident.
- **Separate the foreground, preserve the image.** Check every text region on the final composite.
- **Resolution is computed:** pixels = mm ÷ 25.4 × dpi; 300 dpi at placed size for print.
- **People never become fabricated evidence.**
