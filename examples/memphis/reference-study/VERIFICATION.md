# 实际验证记录

日期：2026-11-04–05。范围：复刻、十套 DESIGN 独立迁移与修订、生成规则修改。逐例视觉结论见 [RESULTS](batch-transfer/RESULTS.md)，实际画面见 [对照图库](batch-transfer/index.html)。

## 复刻阶段

28 件原生 SVG 均由本机 Chrome / Playwright 渲染；三组预览来自这些 PNG。XML 解析通过，无嵌入参考图片，401 个活字文本元素，所需字体已内嵌。本地图库打开过：28 件作品、7 个 face/weight 条目加载、0 字体错误、0 页面脚本错误、0 重复裁切 ID；1440px 视口无横向溢出。证据为 render-audit.json、gallery-audit.json、artifact-checks.json。

三组原图/复刻并排图和全部渲染拼图均查看过。三个独立上下文的早期评论促成方砖轮廓、字面遮挡及小尺寸重组修正；最后复刻由主制作上下文复查，不能称最终复刻的独立盲评。原字体、微小文案、字距与部分建筑比例仍有差异。

最初十套草稿的 folio-check 是 6 通过、4 失败，共五组低对比配对。skeleton-checks.json 保留原始失败。原组复刻仍保留参考关系，没有把修复新作品的配色倒灌成历史复刻。原稿边界检查的七处字盒标记也保留，不能声称没有任何裁切。

## 独立迁移与复测

十套各有一件新内容基线。第十套沿用此前测试，其余九套独立新建；修订后全部交给全新上下文复测。制作者只收对应冻结 DESIGN、新简报、授权字体及中性字体嵌入工具，不收参考图、旧图形、旧绘制代码或评审结论。字体是生产素材，未提供身份图形组件。完整隔离范围见 [PROTOCOL](batch-transfer/PROTOCOL.md)。

基线与修订成品都实际渲染，10 套修订版累计 90 条固定字符串全部通过 factcheck，0 缺失、0 警告。可见换行的 Latin tspan 以空格衔接；跨行中文及中文标点相接后检查；audit.json 保留未经衔接的 rawText。文字检查不能证明未漏掉图形语义，另由像素评审判断。

修订版 CDP 字形记录均来自内嵌自定义字体，0 字体错误、0 系统字体回退；SVG 不含 raster image。逐文本实际墨迹与去文本底图取样均有样本，最低文字对比度 3.24:1（对应大字，满足 3:1）；各文字按实际字号和字重分别核对 3:1／4.5:1 阈值，0 失败；第七套独立承担数字 0 的圆盘是图形，另查其实际填色配对为 3.11:1，不混入文字结果。没有降低检查器阈值。

修订版仅第七套 TAIPEI 的字体外接盒超过上缘。已查看实际 PNG，字面从 y=26 开始，完整可读；这是字盒留边标记，没有作为实际裁切计。其他九套没有越界字盒。独立工艺评审另查墨迹间距和遮挡。

三名全新评审分别检查身份、构成和工艺；只读参考、匿名 P/Q、简报与 rubric，不收 DESIGN 或制作者解释。各自先判断候选，再比较；匿名映射在评审完成后解码。不同构图不自动判失败。视觉评审的 reference.png 来自已交付的原生复刻组；原始 JPG 与复刻并排图另行保留。因此这项评审直接验证与复刻世界的亲缘，不是对原始照片的逐像素验证。Skill 提取三组对照则直接读取同一原始 JPG。

随后直接用原始三张 JPG 复评，并对仍有问题的世界继续修订。最终选用版本为：01/04/06/08/10 的 v2，02/07 的 v3，05/09 的 v4，03 的 v6。各自最终身份、构成、工艺判断均通过，逐例证据见 final-review-summary.json。共 29 次独立生成，修订间沿用同一新简报；未把重复生成当成不同内容的覆盖。03 的 v6 由 v5 同三位独立于制作者的评审复查，知道自己的前轮意见，不称另一次全新盲评。

最终离线对照图库在本机 Chrome 打开：10 个区块、39 张图片全部加载、全部链接存在、0 页面脚本错误；1440px 与 390px 视口均无横向溢出，截图与结果见 batch-transfer/evaluation/gallery-audit.json。

## 规则与留存检查

十份最终 DESIGN 的 folio-check 均通过，声明的大小字配对达到相应阈值。原草稿低对比项的修正在各自规则中，未改检查器。revised-system-checks.json 是当前结果。

最终施工正文中九份与实际使用的冻结输入逐字相同，仅 Record 回写结果。02 的箭头独立宽度与其他几何条件矛盾，最终改为推导式；四支实际箭头已独立量测，吻合最终配方，但澄清后未启动新制作者，详见 accepted-body-checks.json 与 02-arrow-clarification.json。

输入及成品指纹见各例 manifest。多轮共 58 个清单逐项校验，全部原始字节保留，0 校验错误；第十套 v2 的制作者同名 poster.png 在首次独立渲染时被覆盖，已从仍与原指纹一致的输出保留为 maker-poster.png，原清单未改，render-provenance.json 记录了路径和独立渲染。规则、简报、源 SVG 与制作代码均保留；未把新图覆盖成基线。frozen-integrity.json 明示该路径迁移。

实际运行历史 extract_systems.py 后，十份已修订 DESIGN 的 SHA 均未变化，见 generator-preservation.json。旧版、新版、无 skill 的提取比较是另一项文字交接实验，见 [SKILL-ITERATION](SKILL-ITERATION.md)，不将其排名当作视觉成品排名。

仓库 release-check 与最终检查输出存于 batch-transfer/evaluation。通用 host quick_validate 在旧版和当前版均拒绝原有顶层 version 字段；host-validator.json 保留两者错误。仓库规范要求该字段且 release-check 校验它，本轮未为消除这个既有兼容问题改动元数据协议。

## 提交前检查

将新增文件纳入 Git 暂存后，`git diff --cached --check` 返回 2：仅 63 份原始字体授权 TXT 的换行／尾空白提示，共 2916 项。为保留授权源文与冻结指纹，未改写这些文件；维护代码与说明没有此类提示。详情见 staged-whitespace-check.json。旧的初始 ZIP 导出包未纳入提交，完整可编辑源文件、对照与验证证据已纳入。

## 没有验证

每套只有一个新简报，未重复抽样，也未覆盖所有画幅、超长内容和未来所有 CJK 字形。初始复刻与新作的原字库/原作者身份、逐像素一致性没有验证。没有验证印刷色、实体打样、PDF/X、PPTX 或其他软件兼容性。本轮交付为离线 HTML、原生 SVG、PNG 和可检查的文本规则。
