# 独立审阅标准

## 问题
新海报能否被识别为与参考视觉身份属于同一个世界？同时需要看见新内容确实经过重新构成。品牌名相同和颜色近似本身不算证据。

## 审阅边界
只读指定参考图片、新作图片、新内容简报及本文件。不要读取 DESIGN.md、制作代码、制作者解释、其他评审的结论。

## 判断
1. 同一身份：特征图形的轮廓、内部构造、比例，以及中英文字形和层级有稳定亲缘。配色只作辅助证据。
2. 同一构成：模块形成有高低的边缘景观，保留连续阅读场；图案不是通用页面底部的一条装饰。
3. 真正迁移：新标题、日期、正文和画幅经过重组，不是把某张原作等比缩放换字。
4. 完整可读：事实精确无遗漏、无错误遮挡；正文对比度≥4.5:1，大字≥3:1。

输出：通过 / 部分通过 / 未通过；给出最多 4 条可从像素直接定位的证据，区分身份漂移与普通工艺问题。不得根据未见过的制作规则替作品辩护。只下判断，不建议直接改新稿来回避对规则的验证。

这是单件作品的定性小样本验证，不证明普遍可靠性。
