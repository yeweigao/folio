# Brief — poster in a named style

A poster for a design school's open studio night, in the Bauhaus style.
It hangs on the school's street windows and around the city.

## Facts

Every string below must appear in the deliverable exactly as written.

- `Hochschule für Gestaltung Basel`
- `Open Studio Night`
- `Thursday 19 November 2026`
- `18:00–22:00`
- `Studios, workshops and the print room are open to everyone.`
- `Free entry`
- `Freilager-Platz 1, Münchenstein`

## Deliverable

One self-contained HTML file. The poster is one element with class
`unit`, exactly 1000 × 1414 px (A-series proportion). Web fonts from
Google Fonts are allowed; no other external assets.
