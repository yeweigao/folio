# Tests

Fixed briefs for judging a change to the skill. Each has a `## Facts` section of strings that must appear verbatim.

| Brief | Surface | Probes |
|---|---|---|
| `board-deck.md` | 5 slides | Data, argument, rhythm |
| `event-poster.md` | Poster | One lead at 3 m |
| `event-poster-2.md` | Poster | The skeleton test: made from `event-poster`'s DESIGN.md alone |
| `product-web.md` | Web section | Proof without invention |
| `bauhaus-poster.md` | Poster | A named movement: method or costume |
| `hara-poster.md` | Poster, Chinese | A named master with no material supplied |
| `editorial-lines.md` | Two read-alone slides | Ordinary separators and lookup only; insufficient coverage for structural editorial lines |
| `editorial-line-figures.md` | Four read-alone slides | Cross-region connection, common-origin entries, exact annotation and order-plus-state, with a paired line-removal view |
| `design-handoff.md` | Two slides and an A5 flyer | Three fresh world writers, then three separate DESIGN-only makers; optical grouping, lead authority and image/frame decisions |

**A run.** Three arms on the same briefs: no skill, the previous version, the new one. Each maker is a fresh agent on a light model (Sonnet). Render every output, fact-check it, and lay the arms side by side on contact sheets. Then a fresh, stronger judge reviews them blind, labelled neutrally and shuffled, against the rubric in references/review.md (Comparing versions). A change ships if it wins.

[Native image-scaling regression](image-scaling.md) checks the deterministic PPTX audit against the actual distorted and repaired decks. It is a tool check, not a three-arm design-quality comparison.
