# Brief — event poster, second evening

A poster for the next concert evening of the same ensemble. It hangs in
tram shelters and concert-hall foyers in Zürich, read from about three
metres while walking past.

## Material

Ensemble Lumen plays three works about silence and bells. The evening is
called Bells and Silence.

## Facts

Every string below must appear in the deliverable exactly as written.

- `Ensemble Lumen`
- `Bells and Silence`
- `Saturday 23 January 2027`
- `19:30`
- `Tonhalle Zürich, Kleiner Saal`
- `Arvo Pärt — Cantus in Memory of Benjamin Britten`
- `John Cage — 4′33″`
- `Pauline Oliveros — Bye Bye Butterfly`
- `CHF 25 / 15 reduced`
- `ensemble-lumen.ch`

## Deliverable

One self-contained HTML file. The poster is one element with class
`unit`, exactly 1000 × 1414 px (A-series proportion). Web fonts from
Google Fonts are allowed; no other external assets.
