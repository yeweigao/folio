# Brief — 指名大师的海报

一家陶器店的开业海报，要有原研哉那种感觉。贴在店门口和附近的咖啡馆里，
路人在一两米外看到。

## Facts

下面每一条都必须原样出现在作品里。

- `素 · 陶器`
- `11月21日 开业`
- `上海市徐汇区安福路 288 号`
- `每日 10:00–19:00`
- `开业首周，店内器物九折`
- `日常用的碗、盘、杯，全部手工烧制。`

## Deliverable

一个自包含的 HTML 文件。海报是一个 class 为 `unit` 的元素，尺寸恰好
1000 × 1414 px（A 系列比例）。可以用 Google Fonts 的网络字体，不使用其他
外部资源。
