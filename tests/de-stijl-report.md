# 风格派多文字报告 · 固定验证简报

用现代 De Stijl / 风格派视觉语言制作一页 1280×720 read-alone SVG，面向材料研究团队。仅有一页，须同时保留以下两段正文、一张四行表格与五个阶段。目标是让读者先理解主张，再读说明，最后查表和计划。文字须live、正文至少20px、表格/阶段至少18px；不能把阅读压缩为海报口号、不能删字。可重排，不额外编造事实，不依赖照片。

标题：材料观察计划
主张：先固定条件，再比较差异
正文1：同一种材料在不同光线与湿度下会呈现不同的表面。记录时，先固定观察距离、光源方向和样本编号，再描述颜色、纹理与边缘的变化。
正文2：本轮采用四组模拟样本。每组保留原始图像、处理说明和复核记录；缺少条件的观察不进入比较。新增材料沿用同一编号和字段，避免每增加一页就重新发明一套记录方式。
表格列：样本 / 记录数 / 复核数 / 完成率；行：S01 / 24 / 20 / 83%；S02 / 18 / 15 / 83%；S03 / 27 / 23 / 85%；S04 / 21 / 17 / 81%。
阶段：采集 11月06日 → 归档 11月07日 → 比对 11月10日 → 复核 11月12日 → 发布 11月14日。
