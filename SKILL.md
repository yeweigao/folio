# Folio

Design is deciding what is seen first, what recedes, and what never appears. This file sets the target and the limits; the route is yours.

## Philosophy

- **A unit has a lead, not a crowd.** One element is read first and everything else queues behind it, whatever the unit holds.
- **The eye's path is designed, not discovered.** Guide reading in logical order; give lookup clear entry points and a predictable order.
- **The decisive move comes from the subject, not from a style.** Every unit that speaks carries one, said in a sentence; units for reference stay quiet.
- **Layout serves the content, not the other way round.** Change the composition or edit within scope; never hide content or shrink type to make it fit.
- **Measure is shared, not improvised.** Columns, spacing, and baselines belong to one system, fitted to the surface.
- **Space is placed, not left over.** Judge it by its job, not its amount: group, separate, or focus. Fix accidental gaps with scale or placement, never filler.
- **Hierarchy is steps, not slopes.** Few faces, few levels, wide gaps, one treatment per role, sized for the reader's distance.
- **Color is a role, not a decoration.** The accent comes from the brand or the subject and stays the exception.
- **A deliverable has rhythm, not monotony.** Dense, quiet, and loud units follow the content; repeat to orient, break to signal a change.
- **Information is encoded, not decorated.** Data takes a readable form; decoration never poses as evidence, and information never depends on color alone.
- **An image is information, not filler.** Evidence, explanation, or declared atmosphere; keep only the images whose removal would lose something.
- **Style is structure, not skin.** Strip away the colors and fonts, and the piece is still recognizable.

## Constraints

Truth and legibility are floors; everything else serves the brief.

- **Truth.** Never present invented facts, figures, identities, or images as real. Demo numbers say `illustrative`; missing evidence stays visible.
- **Facts are fixed; wording is design.** Names, dates, numbers, places, quotations, and required statements stay exact. Edit other copy only within scope; preserve wording when asked and disclose substantive edits.
- **Legibility.** Text contrast ≥ 4.5:1, size at or above the surface minimum, text kept live. Prose measures target 45–75 Latin or 25–40 CJK characters.
- **Precedence.** User scope and content first, then brand. Surface sets dimensions and legibility floors; dialect overrides mother tongue in style. Refinement preserves the existing system; redesign may replace it.

## Themes

A theme is a visual language: a mother tongue every piece speaks, dialects that fuse it with one movement, and variations that break it on purpose. Read the theme's mother tongue before designing.

The mother tongue holds the piece together; choose at most one primary dialect from the reader and the evidence. Use variations or one move from a guest dialect where the content earns a break. Whole dialects mixed on one page read as costume.

### Swiss (default)

[Mother tongue](references/themes/swiss/mother-tongue.md): Swiss structure, heavy or thin type, rules instead of boxes. [Variations](references/themes/swiss/variations.md): the deliberate breaks.

| Dialect | Reach for it when | Signature move |
|---|---|---|
| [editorial](references/themes/swiss/dialects/editorial.md) | Argument, board review, deep reporting | Action title, one exhibit, a full-width decision band |
| [public-info](references/themes/swiss/dialects/public-info.md) | Teaching, wayfinding, mixed-language readers | One grotesque, mapped function colors, one pictogram set |
| [documentary](references/themes/swiss/dialects/documentary.md) | Evidence-dense, photo-led research | One real photograph leads; captions say who, where, when, source |
| [fashion](references/themes/swiss/dialects/fashion.md) | Fashion, exhibitions, lookbooks | Bodoni-scale type colliding with a cropped image |
| [constructivist](references/themes/swiss/dialects/constructivist.md) | Manifestos, posters that mobilize | One diagonal, condensed giant type, red and black |
| [bauhaus](references/themes/swiss/dialects/bauhaus.md) | Geometry, education, product structure | One primitive shape repeated at changing scale; one primary color |
| [brutalist](references/themes/swiss/dialects/brutalist.md) | Technical work where structure is the content | Grid and containers drawn in plain view; system type |
| [bento](references/themes/swiss/dialects/bento.md) | Product overviews, canvases, dashboard narratives | Unequal modules, one dominant |

## Avoid

Named, because "less generic" alone swaps one default for another; vague taste ("more premium", "less AI") becomes a visible change you can name. Use these only when the brief, brand, or theme asks.

- Centered hero, three equal cards, gradient button, logo wall; KPI tiles; an icon per bullet; equal grids that flatten priority
- Floating rounded cards, drop shadows, glow, glass, purple-blue gradients, fake 3D
- Emoji and decorative symbols; numbering on content with no order
- A colored eyebrow above every heading; extra fonts or colored text as hierarchy
- Pie, donut, gauge, and dual-Y-axis charts; legends where direct labels fit
- Cream backgrounds on screen; decorative English on Chinese pages
- Filler copy: elevate, seamless, unleash, 赋能, 一站式
- The theme's own habit. If the plan could be described without naming this brief's subject, it is a default

## Done means

- A new multi-unit design was calibrated on a rendered, representative hard unit before extending the system.
- The real export was viewed at intended size, every unit; contrast measured on the real composite. Revisions were rechecked; critique alone reports findings on the supplied work.
- Each unit has a clear lead and reading or lookup order; expressive units have a nameable move. The delivery names the system, substantive copy edits, and anything unverified.
